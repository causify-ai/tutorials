### Project Brief: Real-Time Bitcoin Data Ingestion using Ax

- **Title**: Real-Time Bitcoin Data Ingestion with Ax
- **Difficulty**: 2 (Medium - approximately 10 days to complete)
- **Tech Description**: Ax is a powerful framework for building and managing data pipelines, enabling seamless integration and real-time data processing. It can be utilized to ingest, process, and analyze Bitcoin market data efficiently.
- **Project Idea**: Develop a Python application that uses Ax to ingest real-time Bitcoin price data from various APIs, process it, and store it in a database for further analysis and visualization.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `SQLAlchemy` (for database interaction)
  - `Ax` (for pipeline management)
- **Is it Free?**: Yes, Ax is open-source and free to use.
- **Relevant tool (Ax) related Resource Links**:
  - [Ax Documentation](https://ax.dev/)
  - [Ax GitHub Repository](https://github.com/facebook/Ax)
  - [Ax Tutorial on Data Pipelines](https://ax.dev/tutorials/pipelines.html)
