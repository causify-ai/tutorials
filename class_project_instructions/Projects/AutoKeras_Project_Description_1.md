### Project Brief: Real-Time Bitcoin Price Prediction with AutoKeras

- **Title**: Real-Time Bitcoin Price Prediction using AutoKeras
- **Difficulty**: 3
- **Tech Description**: Utilize AutoKeras for automated machine learning model selection and hyperparameter tuning to predict Bitcoin prices based on real-time data ingestion from various sources.
- **Project Idea**: Develop a system that ingests real-time Bitcoin price data from multiple cryptocurrency exchanges and news sentiment analysis to predict future price movements using deep learning models automatically generated by AutoKeras.
- **Python libs**: 
  - `AutoKeras`
  - `pandas`
  - `numpy`
  - `requests` (for API calls)
  - `BeautifulSoup` (for web scraping news)
  - `matplotlib` (for visualization)
  - `scikit-learn` (for data preprocessing)
- **Is it Free?**: Yes, AutoKeras and the associated libraries are open-source and free to use.
