**Title**: Automated Image Classification for Wildlife Conservation

**Difficulty**: 3

**Tech Description**: AutoKeras is utilized in this project to automate the process of building and tuning deep learning models for image classification tasks, specifically focusing on wildlife images.

**Project Idea**: The goal of this project is to develop an automated system that classifies images of wildlife species from a publicly available dataset. By leveraging AutoKeras, we will create a model that can identify different species from images taken in natural habitats. The project will involve scraping images from the iNaturalist API, which provides a rich dataset of wildlife observations. The classification model will help conservationists monitor biodiversity and track species populations effectively. The project will also include data augmentation techniques to improve model robustness.

**Python libs**: AutoKeras, TensorFlow, Requests, NumPy, Matplotlib, OpenCV

**Is it Free?**: Yes, all tools and datasets used in this project are free.
