### Project Brief: Real-Time Bitcoin Data Ingestion using CausalNex

- **Title**: Real-Time Bitcoin Price Prediction with CausalNex
- **Difficulty**: 2
- **Tech Description**: CausalNex is a Python library for probabilistic graphical models that can be used to model causal relationships and perform inference. It allows for the integration of real-time data streams to build and update causal models dynamically.
- **Project Idea**: Develop a system that ingests real-time Bitcoin price data and other relevant features (e.g., trading volume, social media sentiment) to create a causal model that predicts future Bitcoin prices. The model will be updated continuously as new data comes in.
- **Python libs**: 
  - CausalNex
  - Pandas
  - NumPy
  - Requests (for API calls)
  - Matplotlib (for visualization)
- **Is it Free?**: Yes, CausalNex is open-source and free to use.
