### Project Brief: Real-Time Bitcoin Price Prediction with Apache Airflow

- **Title**: Real-Time Bitcoin Price Prediction Pipeline using Apache Airflow
- **Difficulty**: 3
- **Tech Description**: Apache Airflow is an open-source platform to programmatically author, schedule, and monitor workflows. It allows for complex data pipelines with dependencies and scheduling.
- **Project Idea**: Build a real-time data ingestion and prediction pipeline for Bitcoin prices. Use Airflow to orchestrate tasks that scrape live price data from multiple cryptocurrency exchanges, preprocess the data, and feed it into a machine learning model for price prediction. The model's predictions can be stored in a database and visualized in a dashboard.
- **Python libs**: 
  - `apache-airflow`
  - `requests` (for scraping data)
  - `pandas` (for data manipulation)
  - `scikit-learn` (for machine learning)
  - `SQLAlchemy` (for database interactions)
  - `matplotlib` or `plotly` (for visualization)
- **Is it Free?**: Yes, Apache Airflow is an open-source tool and free to use.
