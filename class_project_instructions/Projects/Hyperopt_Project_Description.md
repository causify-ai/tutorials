### Project Brief: Real-Time Bitcoin Data Ingestion with Hyperopt

- **Title**: Optimizing Real-Time Bitcoin Data Ingestion using Hyperopt
- **Difficulty**: 2
- **Tech Description**: Hyperopt is a Python library for optimizing hyperparameters using various algorithms like random search, TPE (Tree-structured Parzen Estimator), and annealing. It can be integrated into a data ingestion pipeline to optimize parameters for data fetching and processing.
- **Project Idea**: Create a real-time Bitcoin data ingestion system that fetches data from a cryptocurrency API, optimizes the data fetching parameters (like frequency and volume) using Hyperopt, and stores the data in a database for analysis.
- **Python libs**:
  - `hyperopt` for hyperparameter optimization
  - `requests` for API calls
  - `pandas` for data manipulation
  - `SQLAlchemy` or `pymongo` for database interaction
- **Is it Free?**: Yes, Hyperopt is an open-source library and free to use.
