### Project Brief: Real-Time Bitcoin Price Prediction with MLflow

- **Title:** Real-Time Bitcoin Price Prediction and Model Management with MLflow
- **Difficulty:** 3
- **Tech Description:** Utilize MLflow for tracking experiments, managing models, and deploying a real-time Bitcoin price prediction system using historical and live market data.
- **Project Idea:** Build a machine learning pipeline that ingests real-time Bitcoin price data from multiple sources (e.g., exchanges, news sentiment analysis) and predicts future prices. Use MLflow to log experiments, compare models, and manage the deployment of the best-performing model.
- **Python libs:** 
  - `mlflow` (for experiment tracking and model management)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `scikit-learn` (for model building)
  - `requests` (for API calls)
  - `statsmodels` (for time series analysis)
  - `matplotlib`/`seaborn` (for visualization)
- **Is it Free?** Yes, MLflow is open-source and free to use.
- **Relevant tool (MLflow) related Resource Links:**
  - [MLflow Documentation](https://www.mlflow.org/docs/latest/index.html)
  - [MLflow GitHub Repository](https://github.com/mlflow/mlflow)
  - [MLflow Examples](https://github.com/mlflow/mlflow/tree/master/examples)
