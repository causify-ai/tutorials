- **Title**: Predicting Movie Success Using MLflow and Social Media Sentiment Analysis

- **Difficulty**: 2

- **Tech Description**: MLflow will be utilized for tracking experiments, managing models, and deploying the machine learning pipeline for predicting movie success based on social media sentiment.

- **Project Idea**: This project aims to predict the box office success of upcoming movies by analyzing sentiment from social media platforms like Twitter. We will collect tweets related to upcoming movie releases using the Twitter API and perform sentiment analysis using Natural Language Processing (NLP) techniques. The sentiment scores will be used as features in a regression model to predict box office earnings. MLflow will help manage the model lifecycle, including versioning and deployment, ensuring reproducibility and scalability of the project.

- **Python libs**: Tweepy, TextBlob, scikit-learn, pandas, MLflow

- **Is it Free?**: Yes, the libraries used are open-source and free to use. The Twitter API has a free tier for basic access.
