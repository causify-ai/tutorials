### Project Brief: Real-Time Bitcoin Data Ingestion with Dask

- **Title**: Real-Time Bitcoin Data Ingestion Using Dask
- **Difficulty**: 2
- **Tech Description**: Dask is a flexible parallel computing library for analytics that enables scalable data processing in Python. It allows for handling large datasets and real-time data streams efficiently.
- **Project Idea**: Develop a system that ingests real-time Bitcoin price data from a public API, processes it using Dask for parallel computation, and stores it in a database for further analysis and visualization.
- **Python libs**: 
  - Dask
  - Requests (for API calls)
  - Pandas (for data manipulation)
  - SQLAlchemy (for database interaction)
- **Is it Free?**: Yes, Dask is open-source and free to use.
- **Relevant tool (Dask) related Resource Links**:
  - [Dask Official Documentation](https://docs.dask.org/en/latest/)
  - [Dask GitHub Repository](https://github.com/dask/dask)
  - [Dask Tutorial on Real-Time Data Processing](https://docs.dask.org/en/latest/tutorials/real-time.html)
