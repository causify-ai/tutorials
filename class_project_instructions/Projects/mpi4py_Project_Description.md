### Project Brief: Real-Time Bitcoin Data Ingestion with mpi4py

- **Title**: Real-Time Bitcoin Data Ingestion using mpi4py
- **Difficulty**: 2
- **Tech Description**: Utilize mpi4py for parallel processing to efficiently ingest and process real-time Bitcoin market data from multiple sources.
- **Project Idea**: Develop a Python application that leverages mpi4py to distribute data ingestion tasks across multiple processes, allowing for real-time updates and analysis of Bitcoin price movements and trading volume.
- **Python libs**: 
  - mpi4py
  - requests (for API calls)
  - pandas (for data manipulation)
  - numpy (for numerical operations)
- **Is it Free?**: Yes, mpi4py is open-source and free to use.
