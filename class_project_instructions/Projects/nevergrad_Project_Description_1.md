### Project Brief: Real-Time Bitcoin Price Optimization with Nevergrad

- **Difficulty:** 3
- **Tech Description:** Nevergrad is an open-source library for derivative-free optimization, which can be used to optimize trading strategies based on real-time Bitcoin price data.
- **Project Idea:** Develop a trading bot that uses real-time Bitcoin price data to optimize a trading strategy through hyperparameter tuning. The bot will utilize Nevergrad to find the best parameters for entry and exit points in trading based on historical performance and real-time data.
- **Python libs:** 
  - `nevergrad` (for optimization)
  - `pandas` (for data manipulation)
  - `requests` (for API calls to fetch real-time Bitcoin data)
  - `matplotlib` (for visualization)
  - `numpy` (for numerical operations)
- **Is it Free?** Yes, Nevergrad is free and open-source.
