**Title**: Optimizing Hyperparameters for Stock Price Prediction using Nevergrad

**Difficulty**: 2

**Tech Description**: Nevergrad is a Python library for derivative-free optimization, which can be utilized to optimize hyperparameters for machine learning models without requiring gradient information.

**Project Idea**: This project aims to predict stock prices using historical trading data while optimizing the hyperparameters of a regression model using Nevergrad. The dataset will be sourced from the Alpha Vantage API, which provides real-time and historical stock market data. The project will involve preprocessing the data, selecting relevant features, and implementing a regression model (e.g., Random Forest or XGBoost). Nevergrad will be employed to fine-tune the hyperparameters of the chosen model to enhance prediction accuracy. The unique aspect of this project is the focus on stock price prediction, which is a highly relevant domain in finance, and the use of a derivative-free optimization approach to improve model performance.

**Python libs**: pandas, numpy, scikit-learn, xgboost, requests, nevergrad, matplotlib

**Is it Free?**: Yes, both the Alpha Vantage API (with a limited number of requests) and Nevergrad are free to use.
