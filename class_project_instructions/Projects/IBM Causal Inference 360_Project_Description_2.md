### Project Brief: Real-Time Bitcoin Price Anomaly Detection with IBM Causal Inference 360

- **Title**: Real-Time Anomaly Detection in Bitcoin Pricing Using Causal Inference
- **Difficulty**: 3
- **Tech Description**: Utilize IBM Causal Inference 360 to analyze real-time Bitcoin price data for detecting anomalies that may indicate market manipulation or external shocks. This involves causal modeling to understand the relationships between various factors affecting Bitcoin prices.
- **Project Idea**: Develop a system that ingests real-time Bitcoin price data from multiple cryptocurrency exchanges and applies causal inference techniques to identify significant anomalies. The project will also visualize these anomalies and their potential causes.
