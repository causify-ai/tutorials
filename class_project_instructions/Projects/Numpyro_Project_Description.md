### Project Brief: Real-Time Bitcoin Data Ingestion Using Numpyro

- **Title**: Real-Time Bitcoin Price Prediction with Numpyro
- **Difficulty**: 2
- **Tech Description**: Numpyro is a probabilistic programming library built on NumPy and JAX, enabling efficient Bayesian inference and modeling. It leverages automatic differentiation for scalable and flexible probabilistic modeling.
- **Project Idea**: Develop a real-time data ingestion system that collects Bitcoin price data from an API, processes it, and uses Numpyro to build a Bayesian model for price prediction. The system will continuously update the model with new data to improve accuracy.
- **Python libs**: 
  - `numpy`
  - `jax`
  - `numpyro`
  - `pandas`
  - `requests`
  - `matplotlib` (for visualization)
- **Is it Free?**: Yes, Numpyro and the associated libraries are open-source and free to use.
