### Project 1: Bayesian A/B Testing for Marketing Campaigns
- **Difficulty**: 1
- **Tech Description**: Numpyro will be used to implement Bayesian inference for analyzing A/B test results, allowing for uncertainty quantification in marketing decisions.
- **Project Idea**: This project aims to evaluate the effectiveness of two different marketing campaigns using A/B testing. The student will collect user engagement data from a public dataset, such as the "Online Retail" dataset from UCI Machine Learning Repository. Numpyro will facilitate the Bayesian analysis to estimate the conversion rates of each campaign, providing credible intervals for decision-making. The results will help identify which marketing strategy yields a higher return on investment.
- **Python libs**: NumPy, Pandas, Numpyro, Matplotlib, Seaborn
- **Is it Free?**: Yes, the project uses freely available datasets and libraries.
- **Relevant tool (Numpyro) related Resource Links**: [Numpyro Documentation](https://numpyro.readthedocs.io/en/latest/), [UCI Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 2: Hierarchical Modeling of Student Performance
- **Difficulty**: 2
- **Tech Description**: Numpyro will be utilized to build a hierarchical Bayesian model to analyze student performance across different schools and demographics.
- **Project Idea**: This project focuses on understanding the factors influencing student performance in standardized tests. Using the "National Assessment of Educational Progress (NAEP)" data, the student will create a hierarchical model to account for variations in performance based on school characteristics and student demographics. Numpyro will be employed to estimate the parameters of the model, allowing for insights into which factors are most significant in affecting student outcomes. The findings can inform educational policy and resource allocation.
- **Python libs**: NumPy, Pandas, Numpyro, Statsmodels, Matplotlib
- **Is it Free?**: Yes, both the dataset and libraries are freely accessible.
- **Relevant tool (Numpyro) related Resource Links**: [Numpyro Documentation](https://numpyro.readthedocs.io/en/latest/), [NAEP Data](https://nces.ed.gov/nationsreportcard/)

### Project 3: Anomaly Detection in Time Series Data
- **Difficulty**: 3
- **Tech Description**: Numpyro will be employed to model time series data for anomaly detection using Bayesian methods.
- **Project Idea**: This project aims to detect anomalies in financial time series data, such as stock prices or trading volumes. The student will utilize the "Yahoo Finance" API to collect historical stock price data. A Bayesian structural time series model will be constructed using Numpyro to identify unusual spikes or drops in the data, which may indicate market anomalies or events. The project will involve model fitting, posterior predictive checks, and visualization of detected anomalies to provide actionable insights for investors.
- **Python libs**: NumPy, Pandas, Numpyro, Matplotlib, yfinance
- **Is it Free?**: Yes, the dataset can be accessed freely via the Yahoo Finance API and the libraries are open-source.
- **Relevant tool (Numpyro) related Resource Links**: [Numpyro Documentation](https://numpyro.readthedocs.io/en/latest/), [Yahoo Finance API](https://pypi.org/project/yfinance/)
