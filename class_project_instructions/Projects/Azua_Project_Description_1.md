### Title
Real-Time Bitcoin Price Anomaly Detection Using Azure Stream Analytics

### Difficulty
3

### Tech Description
Azure Stream Analytics is a real-time analytics service designed for processing large streams of data. It can ingest data from various sources, including IoT devices, and perform complex event processing.

### Project Idea
Develop a real-time system to monitor Bitcoin price feeds and detect anomalies (e.g., sudden price spikes or drops) using Azure Stream Analytics. The project will utilize streaming data from cryptocurrency exchanges and apply anomaly detection algorithms to identify unusual price movements.

### Python libs
- `azure-stream-analytics`
- `pandas`
- `numpy`
- `scikit-learn` (for anomaly detection algorithms)
- `matplotlib` (for visualization)

### Is it Free?
