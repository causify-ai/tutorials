### Project Brief: Real-Time Bitcoin Data Ingestion with Apache Arrow (PyArrow)

- **Title:** Real-Time Bitcoin Data Ingestion Using PyArrow

- **Difficulty:** 2

- **Tech Description:** 
  - Apache Arrow is a cross-language development platform for in-memory data. PyArrow is the Python implementation that enables efficient data processing and interoperability with other data formats.

- **Project Idea:** 
  - Develop a Python application that ingests real-time Bitcoin price data from a public API (e.g., CoinGecko or Binance) and stores it in an Arrow table for efficient querying and analysis. The application will update the data every minute and allow users to perform real-time analytics.

- **Python libs:** 
  - `pyarrow` for data handling
  - `requests` for API calls
  - `pandas` for data manipulation
  - `numpy` for numerical operations
  - `asyncio` for handling asynchronous data ingestion

- **Is it Free?** 
  - Yes, Apache Arrow and its Python library PyArrow are open-source and free to use.
