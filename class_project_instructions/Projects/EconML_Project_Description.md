### Project Brief: Real-Time Bitcoin Data Ingestion with EconML

- **Title**: Real-Time Bitcoin Price Prediction Using EconML
- **Difficulty**: 2
- **Tech Description**: EconML is a Python library designed for estimating causal effects and performing machine learning tasks. It can be utilized to analyze the impact of various features on Bitcoin price movements in real-time.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, processes the data, and uses EconML to model the causal relationships between market indicators and Bitcoin price fluctuations. The application will provide insights and predictions based on the data ingested.
- **Python libs**: 
  - `EconML`
  - `pandas`
  - `numpy`
  - `requests`
  - `matplotlib` (for visualization)
- **Is it Free?**: Yes, EconML is an open-source library and is free to use.
