### Project Brief: Real-Time Bitcoin Price Anomaly Detection with Kats

- **Title**: Real-Time Anomaly Detection in Bitcoin Prices using Kats
- **Difficulty**: 3
- **Tech Description**: Kats is a toolkit for time series analysis that provides various functionalities for forecasting, anomaly detection, and change point detection. It is particularly suited for real-time data processing and analysis.
- **Project Idea**: Implement a real-time anomaly detection system for Bitcoin prices using Kats. The system will ingest streaming price data from a cryptocurrency exchange API, apply Kats' anomaly detection algorithms, and visualize detected anomalies in real-time.
- **Python libs**: 
  - `kats` (for anomaly detection)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `matplotlib` or `plotly` (for visualization)
  - `requests` (for API calls)
  - `streamlit` (for real-time dashboard)
- **Is it Free?**: Yes, Kats is an open-source library and free to use.

  - [Kats Documentation](https://facebookresearch.github.io/Kats/)
