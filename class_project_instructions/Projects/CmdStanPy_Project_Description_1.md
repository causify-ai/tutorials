### Title
Real-Time Bitcoin Price Prediction Using CmdStanPy

### Difficulty
3

### Tech Description
CmdStanPy is a Python interface to CmdStan, which allows users to fit Bayesian models using Stan. It is suitable for real-time data analysis and can handle complex probabilistic models.

### Project Idea
Develop a real-time Bitcoin price prediction model using Bayesian inference. The project will ingest live Bitcoin price data from multiple cryptocurrency exchanges, preprocess the data, and use CmdStanPy to fit a Bayesian regression model that predicts future prices based on historical trends and external factors (e.g., news sentiment, trading volume).

### Python libs
- CmdStanPy
- Pandas
- NumPy
- Requests
- Matplotlib/Seaborn (for visualization)
- Scikit-learn (for preprocessing)

### Is it Free?
Yes, CmdStanPy and the other libraries mentioned are open-source and free to use.
