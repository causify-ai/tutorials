### Project Brief: Real-Time Bitcoin Data Ingestion with Luigi

- **Title**: Real-Time Bitcoin Data Ingestion Pipeline using Luigi

- **Difficulty**: 2

- **Tech Description**: Luigi is a Python package that helps build complex data pipelines by managing dependencies and scheduling tasks. It is particularly useful for orchestrating ETL (Extract, Transform, Load) processes.

- **Project Idea**: Create a data pipeline that ingests real-time Bitcoin price data from a cryptocurrency API, processes it, and stores it in a database for further analysis. The pipeline will be modular, allowing for easy updates and maintenance.

- **Python libs**:
  - `luigi` - for building the pipeline
  - `requests` - for API calls to fetch Bitcoin data
  - `pandas` - for data manipulation and processing
  - `SQLAlchemy` - for database interaction (e.g., PostgreSQL, SQLite)

- **Is it Free?**: Yes, Luigi is an open-source tool and is free to use.
