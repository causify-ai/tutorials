### Project Brief: Real-Time Bitcoin Data Ingestion Using CausalInference

- **Title**: Real-Time Bitcoin Price Analysis with Causal Inference

- **Difficulty**: 2

- **Tech Description**: CausalInference is a Python library designed for estimating causal effects from observational data. It can be utilized to analyze the impact of various factors on Bitcoin price movements in real-time.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data and applies causal inference techniques to identify and analyze the effects of external factors (e.g., news events, social media sentiment) on Bitcoin price fluctuations.

- **Python libs**:
  - `CausalInference`
  - `pandas`
  - `numpy`
  - `requests`
  - `matplotlib` (for visualization)
  - `websocket-client` (for real-time data streaming)

- **Is it Free?**: Yes, CausalInference is an open-source library and free to use.
