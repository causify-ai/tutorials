### Project Brief: Real-Time Bitcoin Data Ingestion Using PyTorch Geometric

- **Title**: Real-Time Bitcoin Price Prediction with Graph Neural Networks

- **Difficulty**: 2

- **Tech Description**: PyTorch Geometric is a library built on PyTorch that facilitates the implementation of graph neural networks (GNNs). It provides tools for working with graph-structured data, making it suitable for analyzing relationships in time-series data like Bitcoin prices.

- **Project Idea**: Develop a system that ingests real-time Bitcoin price data and constructs a graph representation of price movements. Utilize GNNs to predict future price trends based on historical data and market sentiment, enabling better trading strategies.

- **Python libs**:
  - PyTorch
  - PyTorch Geometric
  - Pandas
  - NumPy
  - Requests (for API calls)
  - Matplotlib (for visualization)

- **Is it Free?**: Yes, both PyTorch and PyTorch Geometric are open-source and free to use.
