### Project 1: Predicting House Prices with JAX
- **Difficulty:** 1
- **Tech Description:** JAX will be used for efficient numerical computations and automatic differentiation to build a simple regression model.
- **Project Idea:** The goal is to predict house prices based on various features such as location, size, and amenities using the Boston Housing dataset. Students will preprocess the data, implement a linear regression model using JAX, and evaluate its performance using metrics like RMSE and R². The project will also involve visualizing the results and understanding the impact of each feature on house prices.
- **Python libs:** JAX, NumPy, pandas, Matplotlib, scikit-learn
- **Is it Free?** Yes, JAX and the dataset are freely available for use.
- **Relevant tool (JAX) related Resource Links:** 
  - [JAX Documentation](https://jax.readthedocs.io/en/latest/)
  - [Boston Housing Dataset](https://www.kaggle.com/c/boston-housing)

### Project 2: Time Series Forecasting of Stock Prices
- **Difficulty:** 2
- **Tech Description:** JAX will be utilized to create a more complex time series forecasting model using neural networks for predicting stock prices.
- **Project Idea:** This project aims to forecast the stock prices of a selected company using historical price data from Yahoo Finance. Students will implement a Long Short-Term Memory (LSTM) model using JAX to capture the temporal dependencies in the data. They will preprocess the data, split it into training and testing sets, and evaluate the model's forecasting accuracy using MAE and MAPE. The project will also include visualizations of predicted vs. actual prices.
- **Python libs:** JAX, NumPy, pandas, Matplotlib, yfinance
- **Is it Free?** Yes, Yahoo Finance data and JAX are freely accessible.
- **Relevant tool (JAX) related Resource Links:** 
  - [JAX LSTM Example](https://jax.readthedocs.io/en/latest/notebooks/neural_networks.html)
  - [Yahoo Finance API](https://pypi.org/project/yfinance/)

### Project 3: Image Classification with Pre-trained Models
- **Difficulty:** 3
- **Tech Description:** JAX will be used for fine-tuning a pre-trained convolutional neural network (CNN) on a specific image classification task.
- **Project Idea:** The objective of this project is to classify images from the CIFAR-10 dataset using transfer learning. Students will leverage a pre-trained ResNet model and fine-tune it on CIFAR-10 images using JAX for efficient computation. The project will involve data augmentation, model training, and evaluation using accuracy and confusion matrix. Students will also explore the impact of different hyperparameters on model performance.
- **Python libs:** JAX, NumPy, pandas, Matplotlib, torchvision
- **Is it Free?** Yes, CIFAR-10 and JAX are available for free.
- **Relevant tool (JAX) related Resource Links:** 
  - [JAX Image Classification Example](https://jax.readthedocs.io/en/latest/notebooks/neural_networks.html#Image-Classification)
  - [CIFAR-10 Dataset](https://www.cs.toronto.edu/~kriz/cifar.html)
