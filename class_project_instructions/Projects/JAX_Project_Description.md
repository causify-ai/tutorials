### Project Brief: Real-Time Bitcoin Data Ingestion with JAX

- **Title**: Real-Time Bitcoin Price Tracker using JAX
- **Difficulty**: 2
- **Tech Description**: JAX is a high-performance numerical computing library that allows for automatic differentiation and GPU/TPU acceleration. It is particularly useful for fast computations and can handle large datasets efficiently.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes it using JAX for performance optimization, and visualizes the data in real-time.
- **Python libs**:
  - `jax`: For numerical computations and optimizations.
  - `requests`: For API calls to fetch Bitcoin data.
  - `pandas`: For data manipulation and analysis.
  - `matplotlib` or `plotly`: For data visualization.
- **Is it Free?**: Yes, JAX is open-source and free to use.
- **Relevant tool (JAX) related Resource Links**:
  - [JAX Documentation](https://jax.readthedocs.io/en/latest/)
  - [JAX GitHub Repository](https://github.com/google/jax)
  - [JAX Examples](https://github.com/google/jax/tree/main/jax/examples)
