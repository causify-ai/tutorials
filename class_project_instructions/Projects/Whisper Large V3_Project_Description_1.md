**Title**: Automated Transcription and Sentiment Analysis of Podcast Episodes

**Difficulty**: 2

**Tech Description**: Whisper Large V3 will be utilized to transcribe audio from podcast episodes, converting spoken language into text for further analysis.

**Project Idea**: The goal of this project is to automate the transcription of podcast episodes and perform sentiment analysis on the transcribed text. By leveraging the Whisper Large V3 model, we will extract text from a selection of popular podcasts available via a public API. After transcription, we will apply natural language processing techniques to analyze the sentiment of the discussions, identifying trends in topics and emotional tones over time. This project will provide insights into how different themes resonate with audiences, enhancing our understanding of listener engagement.

**Python libs**: Whisper, pandas, nltk, transformers, matplotlib

**Is it Free?**: Yes, Whisper is open-source, and the podcast API is publicly accessible.
