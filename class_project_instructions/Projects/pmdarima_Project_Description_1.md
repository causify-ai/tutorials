### Project Brief: Real-Time Bitcoin Price Forecasting with pmdarima

- **Title:** Real-Time Bitcoin Price Forecasting Using pmdarima
- **Difficulty:** 3
- **Tech Description:** pmdarima is a Python library for auto-ARIMA modeling, which simplifies the process of building ARIMA models for time series forecasting. It automates the selection of the best model parameters based on AIC/BIC criteria.
- **Project Idea:** Develop a real-time Bitcoin price forecasting application that ingests live price data from a cryptocurrency exchange API, applies pmdarima for time series analysis, and predicts future prices. The application should visualize the forecasted prices and actual prices in real-time.
- **Python libs:** pmdarima, requests, pandas, matplotlib, Flask (for web app), NumPy
- **Is it Free?** Yes, pmdarima and the other mentioned libraries are open-source and free to use.
