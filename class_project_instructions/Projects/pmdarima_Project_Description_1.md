**Title**: Time Series Forecasting of Energy Consumption Using pmdarima

**Difficulty**: 2

**Tech Description**: pmdarima is utilized for building and optimizing seasonal ARIMA models for time series forecasting, allowing for automatic parameter selection.

**Project Idea**: The goal of this project is to forecast energy consumption in a specific region using historical energy usage data obtained from the U.S. Energy Information Administration (EIA) API. By leveraging pmdarima, we will automatically identify the best ARIMA model parameters to predict future energy consumption trends. The project will involve data extraction, preprocessing, model fitting, and evaluation of forecasting accuracy. Additionally, we will visualize the forecasted results to provide insights into future energy demands, which can be crucial for energy providers and policymakers.

**Python libs**: pmdarima, pandas, numpy, matplotlib, requests

**Is it Free?**: Yes, all tools and data sources used in this project are free.
