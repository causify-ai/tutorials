### Project Brief: Real-Time Bitcoin Data Ingestion with Autofeat

- **Title**: Real-Time Bitcoin Price Ingestion and Feature Engineering with Autofeat

- **Difficulty**: 2

- **Tech Description**: Autofeat is a Python library that automates feature engineering, allowing users to create new features from existing data efficiently. It can be integrated with real-time data ingestion systems to enhance the quality of features used for analysis or modeling.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, processes the data, and uses Autofeat to generate additional features for predictive modeling or analysis.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `autofeat` (for feature engineering)
  - `numpy` (for numerical operations)
  - `matplotlib` or `seaborn` (for visualization)

- **Is it Free?**: Yes, Autofeat is an open-source library and can be used for free.
