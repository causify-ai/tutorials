### Project Brief: Real-Time Bitcoin Data Ingestion with Optuna

- **Title**: Optimizing Real-Time Bitcoin Data Ingestion Using Optuna
- **Difficulty**: 2
- **Tech Description**: Optuna is an automatic hyperparameter optimization framework designed for machine learning. It can be utilized to optimize the parameters of a data ingestion pipeline for real-time Bitcoin data, enhancing performance and efficiency.
- **Project Idea**: Build a Python application that ingests real-time Bitcoin price data from a public API. Use Optuna to optimize the parameters of the ingestion process, such as batch size, frequency of data fetching, and data storage options.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `optuna` (for hyperparameter optimization)
  - `sqlite3` or `SQLAlchemy` (for data storage)
- **Is it Free?**: Yes, Optuna is an open-source library and free to use.
- **Relevant tool (Optuna) related Resource Links**:
  - [Optuna Documentation](https://optuna.readthedocs.io/en/stable/)
  - [Optuna GitHub Repository](https://github.com/optuna/optuna)
  - [Optuna Examples](https://github.com/optuna/optuna/tree/main/examples)
