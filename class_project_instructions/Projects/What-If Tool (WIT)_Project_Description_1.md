### Project Brief: Real-Time Bitcoin Sentiment Analysis with What-If Tool (WIT)

- **Title**: Real-Time Bitcoin Sentiment Analysis Using WIT
- **Difficulty**: 3
- **Tech Description**: Utilize the What-If Tool (WIT) to visualize and analyze the impact of sentiment data on Bitcoin price predictions in real-time. This project integrates natural language processing (NLP) for sentiment extraction from social media and news articles.
- **Project Idea**: 
  - Scrape real-time tweets and news articles related to Bitcoin.
  - Perform sentiment analysis to classify the sentiment (positive, negative, neutral).
  - Use WIT to visualize how different sentiment levels affect Bitcoin price predictions using a regression model.
- **Python libs**: 
  - `tweepy` (for Twitter API)
  - `BeautifulSoup` (for web scraping)
  - `nltk` or `TextBlob` (for sentiment analysis)
  - `scikit-learn` (for regression modeling)
  - `witwidget` (for integrating WIT)
- **Is it Free?**: Yes, most libraries are open-source, but Twitter API access may have limitations based on usage.

  - [WIT GitHub Repository](https://github.com/PairLab/what-if-tool)
