### Project Brief: Real-Time Bitcoin Data Ingestion Using HMMlearn

- **Title**: Real-Time Bitcoin Price Prediction with Hidden Markov Models

- **Difficulty**: 2

- **Tech Description**: HMMlearn is a Python library for Hidden Markov Models (HMMs), which can be used for time series analysis and prediction. It allows for modeling sequential data, making it suitable for predicting Bitcoin price movements based on historical data.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes the data using HMMlearn to identify hidden states in price movements, and predicts future price trends. The application will visualize the predictions and provide insights into potential price changes.

- **Python libs**:
  - `hmmlearn` (for Hidden Markov Models)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `matplotlib` or `plotly` (for data visualization)
  - `requests` (for API calls)

- **Is it Free?**: Yes, HMMlearn and the other mentioned libraries are open-source and free to use.
