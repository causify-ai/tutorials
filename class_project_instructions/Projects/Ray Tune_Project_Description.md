### Project Brief: Real-Time Bitcoin Data Ingestion with Ray Tune

- **Title**: Real-Time Bitcoin Data Ingestion and Hyperparameter Tuning using Ray Tune

- **Difficulty**: 2

- **Tech Description**: Ray Tune is a scalable hyperparameter tuning library that integrates seamlessly with Ray, allowing for efficient distributed computing. It can be used to optimize models while ingesting real-time data streams.

- **Project Idea**: Build a Python application that ingests real-time Bitcoin price data from a public API, processes the data, and uses Ray Tune to optimize a predictive model's hyperparameters based on the ingested data.

- **Python libs**:
  - `ray[tune]`: For hyperparameter tuning.
  - `requests`: For making API calls to fetch Bitcoin data.
  - `pandas`: For data manipulation and analysis.
  - `numpy`: For numerical operations.
  - `scikit-learn`: For building predictive models.

- **Is it Free?**: Yes, Ray Tune is an open-source library and free to use.

  - [Ray GitHub Repository](https://github.com/ray-project/ray)
