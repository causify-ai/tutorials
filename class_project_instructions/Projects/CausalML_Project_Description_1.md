### Project Brief: Real-Time Bitcoin Price Impact Analysis using CausalML

- **Title**: Analyzing the Impact of News Sentiment on Bitcoin Prices using CausalML
- **Difficulty**: 3
- **Tech Description**: Utilize CausalML to analyze the causal relationship between news sentiment and Bitcoin price fluctuations in real-time. This involves data ingestion, sentiment analysis, and causal inference to determine how news affects market behavior.
- **Project Idea**: 
  - Ingest real-time news articles related to Bitcoin using web scraping.
  - Perform sentiment analysis on the news articles to quantify sentiment scores.
  - Use CausalML to model the causal impact of sentiment on Bitcoin prices, identifying significant predictors and estimating treatment effects.
- **Python libs**: 
  - `CausalML` for causal inference
  - `BeautifulSoup` or `Scrapy` for web scraping
  - `TextBlob` or `VADER` for sentiment analysis
  - `pandas` for data manipulation
  - `matplotlib` or `seaborn` for visualization
- **Is it Free?**: Yes, all mentioned libraries are open-source and free to use.
