### Project 1: Hyperparameter Optimization for a Random Forest Classifier
- **Difficulty:** 1
- **Tech Description:** Nevergrad will be utilized to optimize hyperparameters of a Random Forest model to enhance its classification performance.
- **Project Idea:** The goal of this project is to improve the accuracy of a Random Forest classifier on the Iris dataset. By employing Nevergrad for hyperparameter optimization, students will explore various parameters such as the number of trees, maximum depth, and minimum samples per leaf. The project will involve splitting the dataset into training and testing sets, optimizing the hyperparameters using Nevergrad's optimization algorithms, and evaluating the model's performance using accuracy metrics. The final deliverable will include a comparison of the optimized model against a baseline model.
- **Python libs:** nevergrad, scikit-learn, pandas, numpy, matplotlib
- **Is it Free?** Yes, Nevergrad and all mentioned libraries are open-source and freely available.
- **Relevant tool (Nevergrad) related Resource Links:** 
  - [Nevergrad GitHub Repository](https://github.com/facebookresearch/nevergrad)
  - [Nevergrad Documentation](https://facebookresearch.github.io/nevergrad/)

### Project 2: Feature Selection for Customer Segmentation
- **Difficulty:** 2
- **Tech Description:** Nevergrad will be employed to select the most relevant features from a customer dataset to improve clustering results.
- **Project Idea:** This project aims to enhance customer segmentation using the Mall Customer Segmentation dataset. Students will apply Nevergrad to perform feature selection, optimizing the selection of features that lead to better-defined customer clusters. The approach includes preprocessing the dataset, applying a clustering algorithm (like K-means), and using Nevergrad to select features that maximize the silhouette score for the clusters. The outcome will be a detailed analysis of the selected features and their impact on clustering performance.
- **Python libs:** nevergrad, pandas, scikit-learn, seaborn, matplotlib
- **Is it Free?** Yes, all libraries used are open-source and available for free.
- **Relevant tool (Nevergrad) related Resource Links:**

### Project 3: Time Series Forecasting with Bayesian Optimization
- **Difficulty:** 3
- **Tech Description:** Nevergrad will be used to optimize the parameters of a time series forecasting model using Bayesian optimization techniques.
- **Project Idea:** The project focuses on forecasting stock prices using the Yahoo Finance API to retrieve historical stock data. Students will implement a time series forecasting model (e.g., ARIMA) and use Nevergrad for optimizing its parameters to minimize forecasting error. The approach involves data preprocessing, model fitting, and using Nevergrad's Bayesian optimization to find the best parameters for the ARIMA model. The final deliverable will include an evaluation of the model's forecasting accuracy and a comparison with a baseline model.
- **Python libs:** nevergrad, pandas, statsmodels, yfinance, matplotlib
- **Is it Free?** Yes, all the libraries and the Yahoo Finance API are freely accessible.
- **Relevant tool (Nevergrad) related Resource Links:** 
  - [Nevergrad GitHub Repository](https://github.com/facebookresearch/nevergrad)
  - [Nevergrad Documentation](https://facebookresearch.github.io/nevergrad/)
