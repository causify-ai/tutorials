### Project Brief: Real-Time Bitcoin Data Ingestion Using Nevergrad

- **Title**: Real-Time Bitcoin Price Monitoring with Nevergrad

- **Difficulty**: 2

- **Tech Description**: Nevergrad is an open-source optimization library that can be used for hyperparameter tuning and optimization tasks. In this project, it will be utilized to optimize parameters for a real-time Bitcoin data ingestion pipeline.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, optimizes the data processing parameters using Nevergrad, and stores the data in a database for further analysis.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `nevergrad` (for optimization tasks)
  - `SQLAlchemy` (for database interaction)
  - `matplotlib` (for visualization, if needed)

- **Is it Free?**: Yes, Nevergrad is an open-source library and is free to use.
