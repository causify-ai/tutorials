### Project Brief: Real-Time Bitcoin Data Ingestion with IBM Causal Inference 360

- **Title**: Real-Time Bitcoin Price Analysis Using IBM Causal Inference 360

- **Difficulty**: 2

- **Tech Description**: IBM Causal Inference 360 is an open-source library designed for causal inference and analysis. It can be utilized to analyze the impact of various factors on Bitcoin prices in real-time.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, processes it using IBM Causal Inference 360 to identify causal relationships, and outputs insights on price movements based on external factors (e.g., news sentiment, trading volume).

- **Python libs**:
  - `pandas` for data manipulation
  - `requests` for API calls
  - `matplotlib` for data visualization
  - `ibm-causal-inference` for causal analysis

- **Is it Free?**: Yes, IBM Causal Inference 360 is open-source and free to use.
