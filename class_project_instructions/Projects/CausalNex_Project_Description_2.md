**Title**: Causal Analysis of Social Media Sentiment on Stock Market Performance

**Difficulty**: 3

**Tech Description**: CausalNex is utilized to model causal relationships between social media sentiment and stock market performance, enabling insights into how public perception can influence stock prices.

**Project Idea**: This project aims to investigate the causal impact of social media sentiment on the stock prices of major companies. We will gather real-time sentiment data from Twitter using the Twitter API and correlate it with historical stock price data from a financial API such as Alpha Vantage. By employing causal inference techniques with CausalNex, we will build a causal graph to analyze how fluctuations in public sentiment can predict stock price movements. This project will not only enhance understanding of market dynamics but also provide actionable insights for investors.

**Python libs**: CausalNex, Tweepy, Alpha Vantage, Pandas, NumPy, Matplotlib, Scikit-learn

**Is it Free?**: Yes, both the Twitter API (with some limitations) and Alpha Vantage (free tier available) are accessible for free.
