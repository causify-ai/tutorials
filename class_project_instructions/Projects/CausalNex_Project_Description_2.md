### Title
Real-Time Bitcoin Price Prediction using CausalNex

### Difficulty
3

### Tech Description
Utilize CausalNex to model causal relationships in Bitcoin market data and predict future price movements based on real-time data ingestion from multiple sources.

### Project Idea
- Ingest real-time Bitcoin price data and related economic indicators (e.g., trading volume, social media sentiment, macroeconomic factors).
- Construct a causal graph to identify relationships and dependencies between different variables affecting Bitcoin prices.
- Implement a forecasting model to predict future Bitcoin prices based on the causal structure.

### Python libs
- CausalNex
- Pandas
- NumPy
- Requests (for data ingestion)
- Matplotlib/Seaborn (for visualization)
- Statsmodels (for statistical analysis)

### Is it Free?
Yes, CausalNex and the other mentioned libraries are open-source and free to use.
