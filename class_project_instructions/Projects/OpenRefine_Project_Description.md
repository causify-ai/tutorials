### Project Brief: Real-Time Bitcoin Data Ingestion with OpenRefine

- **Title**: Real-Time Bitcoin Data Ingestion and Cleaning using OpenRefine
- **Difficulty**: 2
- **Tech Description**: OpenRefine is a powerful tool for working with messy data, allowing users to clean, transform, and explore large datasets. It can be integrated with Python for data ingestion tasks.
- **Project Idea**: Develop a Python script that fetches real-time Bitcoin price data from a cryptocurrency API, then uses OpenRefine to clean and transform the data for analysis and visualization.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `json` (for handling JSON data)
  - `openrefine-py` (for integrating OpenRefine with Python)
- **Is it Free?**: Yes, OpenRefine is an open-source tool and is free to use.
