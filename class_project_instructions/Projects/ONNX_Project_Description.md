### Project Brief: Real-Time Bitcoin Data Ingestion Using ONNX

- **Title**: Real-Time Bitcoin Price Prediction with ONNX
- **Difficulty**: 2
- **Tech Description**: ONNX (Open Neural Network Exchange) is an open-source format for AI models that allows interoperability between various machine learning frameworks. It can be used to deploy pre-trained models for real-time inference.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, preprocesses the data, and uses an ONNX model to predict future prices. The application will visualize the predictions in real-time.
- **Python libs**: 
  - `onnx`
  - `onnxruntime`
  - `pandas`
  - `numpy`
  - `matplotlib`
  - `requests`
- **Is it Free?**: Yes, ONNX and its libraries are open-source and free to use.
