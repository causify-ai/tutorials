### Project 1: Predicting House Prices with Regression Models
- **Difficulty**: 1
- **Tech Description**: PyTorch Lightning will be used to streamline the training and validation of regression models for house price prediction.
- **Project Idea**: The goal of this project is to predict house prices based on various features such as location, size, and amenities using the Boston Housing dataset. Students will preprocess the data, create a regression model using PyTorch Lightning, and evaluate its performance using metrics like RMSE and R². The project will also involve visualizing the results to understand the model's predictions better.
- **Python libs**: PyTorch Lightning, pandas, scikit-learn, matplotlib, seaborn
- **Is it Free?**: Yes, the Boston Housing dataset is publicly available and can be easily downloaded from various sources like UCI Machine Learning Repository.
- **Relevant tool (pytorch-lightning) related Resource Links**: 
  - [PyTorch Lightning Documentation](https://pytorch-lightning.readthedocs.io/en/stable/)
  - [Boston Housing Dataset](https://www.kaggle.com/c/boston-housing)

### Project 2: Sentiment Analysis on Movie Reviews
- **Difficulty**: 2
- **Tech Description**: PyTorch Lightning will facilitate the training of a pre-trained NLP model (like BERT) for sentiment analysis on movie reviews.
- **Project Idea**: This project aims to classify movie reviews from the IMDb dataset as positive or negative. Students will leverage a pre-trained BERT model and fine-tune it using PyTorch Lightning for better performance. The project will involve data preprocessing, model training, and evaluation using accuracy and F1-score. Additionally, students will visualize the distribution of sentiments in the dataset.
- **Python libs**: PyTorch Lightning, transformers, pandas, scikit-learn, matplotlib
- **Is it Free?**: Yes, the IMDb dataset is freely available through the Kaggle platform.
- **Relevant tool (pytorch-lightning) related Resource Links**: 
  - [PyTorch Lightning NLP Tutorial](https://pytorch-lightning.readthedocs.io/en/stable/misc/nlp.html)
  - [IMDb Dataset on Kaggle](https://www.kaggle.com/utathya/imdb-review-dataset)

### Project 3: Anomaly Detection in Network Traffic
- **Difficulty**: 3
- **Tech Description**: PyTorch Lightning will be employed to build and evaluate a complex autoencoder model for detecting anomalies in network traffic data.
- **Project Idea**: The objective of this project is to identify unusual patterns in network traffic that may indicate security threats using the UNSW-NB15 dataset. Students will implement an autoencoder model in PyTorch Lightning to learn the normal behavior of network traffic and detect anomalies. This project will involve extensive data preprocessing, model tuning, and evaluation metrics like precision, recall, and the F1-score to assess the model's performance.
- **Python libs**: PyTorch Lightning, pandas, scikit-learn, matplotlib, NumPy
- **Is it Free?**: Yes, the UNSW-NB15 dataset is publicly available for research purposes and can be downloaded from the UNSW website.
- **Relevant tool (pytorch-lightning) related Resource Links**: 
  - [PyTorch Lightning Autoencoder Example](https://pytorch-lightning.readthedocs.io/en/stable/notebooks/lightning_examples/autoencoder.html)
  - [UNSW-NB15 Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset-2015)
