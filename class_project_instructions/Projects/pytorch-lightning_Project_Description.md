### Project Brief: Real-Time Bitcoin Data Ingestion with PyTorch Lightning

- **Title**: Real-Time Bitcoin Data Ingestion and Processing

- **Difficulty**: 2

- **Tech Description**: PyTorch Lightning is a lightweight wrapper for PyTorch that helps organize PyTorch code and streamline the training process. It is particularly useful for building complex models while maintaining readability and modularity.

- **Project Idea**: Develop a real-time data ingestion pipeline that fetches Bitcoin price data from a live API, processes the data using PyTorch Lightning, and prepares it for further analysis or model training. The project will focus on handling streaming data and applying basic preprocessing techniques.

- **Python libs**:
  - `pytorch-lightning`
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `matplotlib` (for visualization)

- **Is it Free?**: Yes, PyTorch Lightning is open-source and free to use.
