### Project Brief: Real-Time Bitcoin Data Ingestion Using sktime

- **Title**: Real-Time Bitcoin Price Monitoring and Analysis

- **Difficulty**: 2

- **Tech Description**: sktime is a Python library designed for time series analysis, providing tools for time series forecasting, classification, and transformation. It can be leveraged to analyze real-time Bitcoin price data for trends and predictions.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes the data using sktime for time series analysis, and visualizes trends and predictions. The application will update in real-time and provide alerts for significant price changes.

- **Python libs**:
  - `sktime` - for time series analysis
  - `requests` - for API calls to fetch Bitcoin data
  - `pandas` - for data manipulation
  - `matplotlib` or `plotly` - for data visualization
  - `numpy` - for numerical operations

- **Is it Free?**: Yes, sktime is an open-source library and is free to use.
