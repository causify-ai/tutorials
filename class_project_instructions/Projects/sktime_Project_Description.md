### Project 1: Time Series Forecasting for Retail Sales
- **Difficulty:** 1
- **Tech Description:** Utilize sktime for time series forecasting to predict future retail sales based on historical data.
- **Project Idea:** The goal of this project is to develop a forecasting model to predict monthly retail sales for a specific product category using historical sales data from the UCI Machine Learning Repository's "Retail Sales Forecasting" dataset. Students will preprocess the data, apply sktime's forecasting algorithms, and evaluate model performance using metrics like Mean Absolute Error (MAE). The project will also include visualizing the forecasted sales against actual sales to assess the model's accuracy.
- **Python libs:** sktime, pandas, numpy, matplotlib, scikit-learn
- **Is it Free?** Yes, the UCI dataset is publicly available and sktime is an open-source library.
- **Relevant tool (sktime) related Resource Links:** 
  - [sktime Documentation](https://www.sktime.org/en/stable/)
  - [UCI Retail Sales Forecasting Dataset](https://archive.ics.uci.edu/ml/datasets/retail+sales+forecasting)

### Project 2: Anomaly Detection in Sensor Data
- **Difficulty:** 2
- **Tech Description:** Use sktime's anomaly detection capabilities to identify unusual patterns in time series sensor data.
- **Project Idea:** This project aims to detect anomalies in time series data collected from IoT sensors in a manufacturing environment. The dataset from the NASA Prognostics Data Repository will be used, which contains sensor readings over time. Students will preprocess the data, implement sktime's anomaly detection algorithms, and visualize detected anomalies. The project will also involve analyzing the impact of these anomalies on production efficiency and proposing potential solutions.
- **Python libs:** sktime, pandas, numpy, matplotlib, seaborn
- **Is it Free?** Yes, the NASA dataset is publicly available and sktime is an open-source library.
- **Relevant tool (sktime) related Resource Links:**
  - [sktime Anomaly Detection Documentation](https://www.sktime.org/en/stable/user_guide/forecasting.html)
  - [NASA Prognostics Data Repository](https://www.nasa.gov/content/prognostics-center-of-excellence-data-set-repository)

### Project 3: Clustering of Financial Time Series
- **Difficulty:** 3
- **Tech Description:** Implement clustering techniques using sktime to group similar financial time series based on historical price movements.
- **Project Idea:** The objective of this project is to cluster various stocks based on their historical price movements to identify patterns and similarities. Using the Yahoo Finance API, students will gather historical stock price data for a selection of companies. They will preprocess the data, extract relevant features, and apply sktime's clustering algorithms to group stocks. The project will also include an analysis of the clusters to interpret the financial implications and potential investment strategies based on the results.
- **Python libs:** sktime, pandas, numpy, matplotlib, yfinance
- **Is it Free?** Yes, Yahoo Finance data is freely accessible through its API, and sktime is an open-source library.
- **Relevant tool (sktime) related Resource Links:**
  - [sktime Clustering Documentation](https://www.sktime.org/en/stable/user_guide/clustering.html)
  - [Yahoo Finance API Documentation](https://pypi.org/project/yfinance/)
