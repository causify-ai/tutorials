### Project 1: Predicting House Prices Using Auto-Sklearn
- **Difficulty**: 1
- **Tech Description**: Auto-sklearn automates the machine learning pipeline, optimizing algorithms and hyperparameters for regression tasks.
- **Project Idea**: The goal of this project is to predict house prices based on various features such as location, size, number of bedrooms, and amenities using the Boston Housing dataset. Students will preprocess the data, apply Auto-sklearn to select the best-performing models, and evaluate their results using metrics like RMSE. The project will involve visualizing the feature importance and providing insights into the housing market.
- **Python libs**: auto-sklearn, pandas, scikit-learn, matplotlib, seaborn
- **Is it Free?**: Yes, Auto-sklearn is open-source and can be installed via pip, and the Boston Housing dataset is publicly available.
- **Relevant tool (XYZ) related Resource Links**: 
  - [Auto-sklearn Documentation](https://automl.github.io/auto-sklearn/master/)
  - [Boston Housing Dataset](https://www.kaggle.com/c/boston-housing)

### Project 2: Customer Segmentation for Retail Using Auto-Sklearn
- **Difficulty**: 2
- **Tech Description**: Auto-sklearn is utilized to automatically select and tune clustering algorithms for customer segmentation based on purchasing behavior.
- **Project Idea**: This project aims to segment customers of a retail store using transaction data from the Online Retail dataset. By employing clustering algorithms, students will analyze customer purchasing patterns and behaviors. The project will involve preprocessing the dataset, running Auto-sklearn to identify the best clustering techniques, and visualizing the results with cluster profiles. Insights derived from the segmentation can help in targeted marketing strategies.
- **Python libs**: auto-sklearn, pandas, scikit-learn, matplotlib, seaborn
- **Is it Free?**: Yes, Auto-sklearn is free to use, and the Online Retail dataset is available for download on UCI Machine Learning Repository.
- **Relevant tool (XYZ) related Resource Links**: 
  - [Auto-sklearn Documentation](https://automl.github.io/auto-sklearn/master/)
  - [Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 3: Sentiment Analysis of Product Reviews Using Auto-Sklearn
- **Difficulty**: 3
- **Tech Description**: Auto-sklearn leverages pre-trained NLP models and automates the selection of the best algorithms for text classification tasks.
- **Project Idea**: This project focuses on performing sentiment analysis on product reviews from the Amazon Product Review dataset. Students will preprocess text data, including tokenization and vectorization, and then use Auto-sklearn to optimize the classification models for sentiment prediction. The project will require evaluating model performance and providing insights into customer sentiment trends over time, using visualizations to present findings effectively.
- **Python libs**: auto-sklearn, pandas, scikit-learn, nltk, matplotlib
- **Is it Free?**: Yes, both Auto-sklearn and the Amazon Product Review dataset are freely accessible.
- **Relevant tool (XYZ) related Resource Links**: 
  - [Auto-sklearn Documentation](https://automl.github.io/auto-sklearn/master/)
  - [Amazon Product Review Dataset](https://registry.opendata.aws/amazon-reviews/)
