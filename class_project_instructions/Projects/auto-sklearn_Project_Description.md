### Project Brief: Real-Time Bitcoin Data Ingestion with auto-sklearn

- **Title**: Real-Time Bitcoin Price Prediction using auto-sklearn

- **Difficulty**: 2

- **Tech Description**: 
  - auto-sklearn is an automated machine learning toolkit that optimizes machine learning pipelines. It can be utilized to build predictive models for Bitcoin price trends based on real-time data ingestion.

- **Project Idea**: 
  - Develop a Python application that ingests real-time Bitcoin price data from an API, preprocesses the data, and uses auto-sklearn to automatically select the best machine learning model for predicting future Bitcoin prices.

- **Python libs**: 
  - `pandas` (data manipulation)
  - `requests` (API calls)
  - `numpy` (numerical operations)
  - `auto-sklearn` (automated machine learning)
  - `matplotlib` or `seaborn` (data visualization)

- **Is it Free?**: 
  - Yes, auto-sklearn is open-source and free to use.
