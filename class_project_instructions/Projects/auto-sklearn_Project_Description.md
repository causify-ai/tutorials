**Title**: Automated Customer Segmentation for E-commerce Using Auto-sklearn

**Difficulty**: 3

**Tech Description**: Auto-sklearn is utilized to automate the machine learning pipeline for clustering customers based on their purchasing behavior, optimizing hyperparameters and model selection without manual intervention.

**Project Idea**: The goal of this project is to segment e-commerce customers into distinct groups based on their purchasing patterns using clustering techniques. By leveraging a dataset from a public e-commerce API, we will extract customer transaction data and utilize Auto-sklearn to identify optimal clustering algorithms and hyperparameters. The project will involve preprocessing the data, applying feature engineering to create meaningful customer profiles, and using unsupervised learning to uncover hidden patterns in customer behavior. The insights gained from this segmentation can help businesses tailor marketing strategies and improve customer satisfaction.

**Python libs**: auto-sklearn, pandas, numpy, scikit-learn, matplotlib, seaborn
