### Project Brief: Real-Time Bitcoin Data Ingestion with PySpark

- **Title**: Real-Time Bitcoin Data Ingestion and Processing using PySpark

- **Difficulty**: 2

- **Tech Description**: PySpark is the Python API for Apache Spark, enabling large-scale data processing and analytics. It allows for distributed computing and can handle real-time data streams effectively.

- **Project Idea**: Develop a real-time data ingestion pipeline that collects Bitcoin price data from a public API (e.g., CoinGecko or Binance), processes it using PySpark, and stores it in a distributed database (e.g., HDFS or Cassandra) for further analysis.

- **Python libs**:
  - `pyspark`
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `json` (for handling JSON data)

- **Is it Free?**: Yes, PySpark is open-source and free to use.
