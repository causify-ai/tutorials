### Project Brief: Real-Time Bitcoin Data Ingestion Using CausalML

- **Title:** Real-Time Bitcoin Price Analysis with CausalML
- **Difficulty:** 2
- **Tech Description:** CausalML is a Python library for causal inference, enabling users to analyze the impact of various factors on Bitcoin price movements in real-time.
- **Project Idea:** Develop a real-time data ingestion pipeline that fetches Bitcoin price data and applies causal inference techniques to identify the impact of external factors (e.g., news sentiment, trading volume) on price fluctuations.
- **Python libs:** 
  - `CausalML` for causal inference
  - `pandas` for data manipulation
  - `requests` for API calls
  - `numpy` for numerical operations
  - `matplotlib` or `seaborn` for visualization
- **Is it Free?** Yes, CausalML is open-source and free to use.

  - [CausalML GitHub Repository](https://github.com/uber/causalml)
  - [CausalML Documentation](https://causalml.readthedocs.io/en/latest/)
