### Project Brief: Real-Time Bitcoin Data Ingestion with CmdStanPy

- **Title**: Real-Time Bitcoin Data Ingestion and Analysis using CmdStanPy

- **Difficulty**: 2

- **Tech Description**: CmdStanPy is a Python interface to Stan, a probabilistic programming language that allows for Bayesian statistical modeling. It can be used to ingest and analyze real-time Bitcoin data for predictive modeling.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, processes the data, and uses CmdStanPy to perform Bayesian analysis and forecasting on Bitcoin price trends.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `cmdstanpy` (for Bayesian modeling)
  - `matplotlib` (for data visualization)
  - `numpy` (for numerical operations)

- **Is it Free?**: Yes, CmdStanPy and the associated libraries are open-source and free to use.
