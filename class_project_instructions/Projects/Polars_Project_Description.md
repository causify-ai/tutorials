### Project Brief: Real-Time Bitcoin Data Ingestion with Polars

- **Title**: Real-Time Bitcoin Data Ingestion using Polars
- **Difficulty**: 2
- **Tech Description**: Polars is a fast DataFrame library designed for high-performance data manipulation and analysis. It is particularly well-suited for handling large datasets efficiently in Python.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API (e.g., CoinGecko or Binance) and processes it using Polars for analytics and visualization.
- **Python libs**: 
  - `polars` for data manipulation
  - `requests` for API calls
  - `matplotlib` or `plotly` for visualization
  - `asyncio` for handling real-time data streams
- **Is it Free?**: Yes, Polars and the mentioned libraries are open-source and free to use.
- **Relevant tool (Polars) related Resource Links**:
  - [Polars Documentation](https://pola.rs/docs/)
  - [Polars GitHub Repository](https://github.com/pola-rs/polars)
  - [Real-time Data Ingestion with Python](https://realpython.com/python-data-ingestion/)
