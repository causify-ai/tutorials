### Project Brief: Real-Time Bitcoin Data Ingestion with pmdarima

- **Title**: Real-Time Bitcoin Price Forecasting using pmdarima

- **Difficulty**: 2

- **Tech Description**: pmdarima is a Python library that provides an easy-to-use interface for building ARIMA models for time series forecasting. It automates the process of selecting the best ARIMA parameters and can be integrated with real-time data streams.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, preprocesses the data, and uses pmdarima to forecast future Bitcoin prices. The application will visualize the price trends and forecast results.

- **Python libs**:
  - `pmdarima` (for ARIMA modeling)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `matplotlib` or `plotly` (for data visualization)
  - `requests` (for API data ingestion)

- **Is it Free?**: Yes, pmdarima is open-source and free to use.
