### Project Brief 1

**Title:** Seasonal Demand Forecasting for Retail Products  
**Difficulty:** 1  
**Tech Description:** Utilize pmdarima to implement seasonal ARIMA models for predicting retail product demand.  
**Project Idea:** This project aims to forecast the demand for a specific retail product using historical sales data. By analyzing seasonal trends, students will apply the pmdarima library to build a seasonal ARIMA model that captures both trend and seasonality in the data. The project will involve data preprocessing, model fitting, and evaluation using metrics like RMSE and MAE. The final deliverable will be a demand forecasting model that can help retailers optimize inventory management.  
**Python libs:** pmdarima, pandas, numpy, matplotlib, statsmodels  
**Is it Free?** Yes, pmdarima is open-source and can be freely installed via pip.  
**Relevant tool (pmdarima) related Resource Links:**  
- [pmdarima Documentation](https://pmdarima.readthedocs.io/en/latest/)  
- [pmdarima GitHub Repository](https://github.com/alkaline-ml/pmdarima)

### Project Brief 2

**Title:** Energy Consumption Forecasting in Smart Homes  
**Difficulty:** 2  
**Tech Description:** Leverage pmdarima to develop time series models that predict energy consumption based on historical usage patterns.  
**Project Idea:** The goal of this project is to forecast future energy consumption in smart homes using publicly available energy usage datasets. Students will utilize the pmdarima library to identify optimal ARIMA parameters and forecast future energy usage. The project will involve data cleaning, exploratory data analysis, and model validation through backtesting. The insights gained can assist homeowners and energy providers in better managing energy consumption.  
**Python libs:** pmdarima, pandas, numpy, seaborn, scikit-learn  
**Is it Free?** Yes, the project can be built using freely available datasets like the UCI Machine Learning Repository's "Appliances energy prediction" dataset.  
**Relevant tool (pmdarima) related Resource Links:**  
- [UCI Energy Dataset](https://archive.ics.uci.edu/ml/datasets/Appliances+energy+prediction)  
- [pmdarima Documentation](https://pmdarima.readthedocs.io/en/latest/)

### Project Brief 3

**Title:** Anomaly Detection in Financial Time Series Data  
**Difficulty:** 3  
**Tech Description:** Use pmdarima to model financial time series data and detect anomalies in stock price movements.  
**Project Idea:** This advanced project aims to utilize historical stock price data to detect anomalies indicative of market irregularities or fraud. Students will apply the pmdarima library to fit ARIMA models to the stock price time series, identifying outliers based on the residuals of the fitted model. The project will include thorough statistical analysis and visualization of detected anomalies, providing insights into potential market disruptions. The analysis can be beneficial for financial analysts and investors.  
**Python libs:** pmdarima, pandas, numpy, matplotlib, scipy  
**Is it Free?** Yes, the project can be conducted using freely available financial data from sources like Yahoo Finance or Alpha Vantage.  
**Relevant tool (pmdarima) related Resource Links:**  
- [Alpha Vantage API](https://www.alphavantage.co/)  
- [pmdarima Documentation](https://pmdarima.readthedocs.io/en/latest/)
