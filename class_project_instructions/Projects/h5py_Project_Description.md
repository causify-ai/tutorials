### Project Brief: Real-Time Bitcoin Data Ingestion with h5py

- **Title**: Real-Time Bitcoin Data Ingestion and Storage using h5py

- **Difficulty**: 2

- **Tech Description**: h5py is a Python library that provides an interface to the HDF5 binary data format, allowing for efficient storage and retrieval of large datasets. It is particularly useful for handling structured data in a hierarchical format.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API (e.g., Binance, Coinbase) and stores it in an HDF5 file using h5py. The application should update the dataset at regular intervals and allow for querying historical price data.

- **Python libs**:
  - `h5py` - for handling HDF5 files
  - `requests` - for making API calls to retrieve Bitcoin data
  - `pandas` - for data manipulation and analysis
  - `time` - for scheduling data ingestion intervals

- **Is it Free?**: Yes, h5py is an open-source library and free to use.
