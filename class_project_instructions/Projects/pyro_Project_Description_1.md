### Project Brief: Real-Time Bitcoin Price Prediction using Pyro

- **Title**: Bayesian Bitcoin Price Prediction with Pyro
- **Difficulty**: 3
- **Tech Description**: Pyro is a probabilistic programming library built on PyTorch, enabling flexible and scalable Bayesian modeling. It allows for the creation of complex probabilistic models and inference algorithms.
- **Project Idea**: Develop a real-time Bitcoin price prediction model using Bayesian inference. The model will ingest live market data, including price, volume, and sentiment analysis from social media, to forecast future prices and quantify uncertainty in predictions.
- **Python libs**: Pyro, PyTorch, Pandas, NumPy, Requests, Matplotlib, Seaborn, Tweepy (for sentiment analysis).
- **Is it Free?**: Yes, Pyro and the associated libraries are open-source and free to use.
