### Project Brief: Real-Time Bitcoin Data Ingestion Using Orbit

- **Title**: Real-Time Bitcoin Data Ingestion with Orbit
- **Difficulty**: 2
- **Tech Description**: Orbit is a powerful tool for managing and processing time-series data, making it suitable for real-time data ingestion and analysis. It can handle streaming data efficiently and integrates well with Python.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from various APIs, processes it using Orbit, and stores it for further analysis or visualization.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `orbit` (for time-series data processing)
  - `matplotlib` or `plotly` (for visualization)
- **Is it Free?**: Yes, Orbit is open-source and free to use.
- **Relevant tool (Orbit) related Resource Links**:
  - [Orbit GitHub Repository](https://github.com/OrbitDB/orbit-db)
  - [Orbit Documentation](https://orbitdb.org/docs/)
  - [Orbit API Reference](https://orbitdb.org/docs/api/)
