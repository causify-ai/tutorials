### Project 1: Analyzing Seasonal Trends in Retail Sales  
- **Difficulty:** 1  
- **Tech Description:** Utilize the Orbit library to model and forecast seasonal trends in retail sales data.  
- **Project Idea:** The goal of this project is to analyze and predict seasonal sales trends for a retail company by using historical sales data. Students will gather data from the UCI Machine Learning Repository's "Online Retail" dataset. Using Orbit, they will fit a Bayesian time series model to capture seasonal patterns and forecast future sales. The project will also involve visualizing the results to identify peak shopping periods and informing inventory management strategies.  
- **Python libs:** pandas, numpy, matplotlib, seaborn, orbit  
- **Is it Free?** Yes, all required libraries and datasets are freely available.  
- **Relevant tool (orbit) related Resource Links:** [Orbit Documentation](https://orbit.readthedocs.io/en/latest/), [UCI Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 2: Customer Churn Prediction in Subscription Services  
- **Difficulty:** 2  
- **Tech Description:** Implement the Orbit library to model customer churn over time using subscription service data.  
- **Project Idea:** This project aims to predict customer churn in a subscription-based service by analyzing user activity data. Students will use the publicly available "Telco Customer Churn" dataset from Kaggle. They will apply Orbit to develop a time series model that captures the dynamics of user engagement and churn rates. The project will involve feature engineering from user activity logs and visualizing churn predictions to identify at-risk customers and recommend retention strategies.  
- **Python libs:** pandas, numpy, scikit-learn, matplotlib, orbit  
- **Is it Free?** Yes, the dataset and libraries are free to use.  
- **Relevant tool (orbit) related Resource Links:** [Orbit Documentation](https://orbit.readthedocs.io/en/latest/), [Kaggle Telco Customer Churn Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

### Project 3: Anomaly Detection in Network Traffic  
- **Difficulty:** 3  
- **Tech Description:** Use the Orbit library to detect anomalies in network traffic data over time.  
- **Project Idea:** The objective of this project is to identify anomalies in network traffic data, which could indicate security threats or unusual behavior. Students will utilize the "UNSW-NB15" dataset, which contains a variety of network traffic data. By employing Orbit, they will create a time series model to monitor traffic patterns and detect deviations from normal behavior. The project will also include a thorough analysis of detected anomalies and their potential implications for network security.  
- **Python libs:** pandas, numpy, matplotlib, seaborn, orbit  
- **Is it Free?** Yes, the dataset and libraries are freely accessible.  
- **Relevant tool (orbit) related Resource Links:** [Orbit Documentation](https://orbit.readthedocs.io/en/latest/), [UNSW-NB15 Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset-0)
