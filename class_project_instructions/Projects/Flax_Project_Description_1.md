### Project Brief: Real-Time Bitcoin Price Prediction Using Flax

- **Title**: Real-Time Bitcoin Price Prediction with Flax
- **Difficulty**: 3
- **Tech Description**: Flax is a flexible neural network library for JAX that allows for high-performance machine learning model development. It supports dynamic computation graphs and is designed for research and production use.
- **Project Idea**: Develop a real-time Bitcoin price prediction model using Flax. The model will ingest live market data from multiple cryptocurrency exchanges, preprocess the data, and utilize a recurrent neural network (RNN) architecture to predict future prices based on historical trends and market sentiment derived from social media scraping.
- **Python libs**: 
  - Flax
  - JAX
  - Requests (for web scraping)
  - BeautifulSoup (for parsing HTML)
  - Pandas (for data manipulation)
  - NumPy (for numerical operations)
  - Matplotlib (for visualization)
- **Is it Free?**: Yes, Flax and the associated libraries are open-source and free to use.
