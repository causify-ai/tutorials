### Project 1: Predicting Housing Prices with AutoGluon
- **Difficulty:** 1
- **Tech Description:** AutoGluon simplifies the model selection and hyperparameter tuning process for regression tasks.
- **Project Idea:** The goal of this project is to predict housing prices based on various features such as location, size, and amenities using the California housing dataset. Students will leverage AutoGluon's automated machine learning capabilities to quickly explore different models and find the best-performing one. The project will include data preprocessing, feature engineering, and evaluation of model performance using metrics like RMSE.
- **Python libs:** AutoGluon, pandas, scikit-learn, matplotlib, seaborn
- **Is it Free?** Yes, AutoGluon is open-source and can be installed via pip.
- **Relevant tool (XYZ) related Resource Links:** 
  - [AutoGluon Documentation](https://autogluon.mxnet.io/)
  - [California Housing Dataset](https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html)

### Project 3: Sentiment Analysis of Product Reviews Using AutoGluon
- **Difficulty:** 3
- **Tech Description:** AutoGluon provides pre-trained models for natural language processing tasks, simplifying sentiment analysis.
- **Project Idea:** The objective of this project is to perform sentiment analysis on product reviews from the Amazon Customer Reviews dataset. Students will utilize AutoGluon's text classification capabilities to classify reviews as positive, negative, or neutral. The project will involve data cleaning, feature extraction, and model evaluation, including an analysis of sentiment trends over time to provide insights into customer satisfaction.

- **Relevant tool (XYZ) related Resource Links:**
