### Project Brief: Real-Time Bitcoin Data Ingestion with AutoGluon

- **Title**: Real-Time Bitcoin Price Prediction using AutoGluon
- **Difficulty**: 2
- **Tech Description**: AutoGluon is an open-source AutoML framework that simplifies the process of training machine learning models, making it easier to handle real-time data ingestion and prediction tasks.
- **Project Idea**: Develop a system that ingests real-time Bitcoin price data from a cryptocurrency API, preprocesses the data, and uses AutoGluon to build and update predictive models for Bitcoin price forecasting.
- **Python libs**: 
  - `pandas` (for data manipulation)
  - `requests` (for API calls)
  - `AutoGluon` (for model training and evaluation)
  - `numpy` (for numerical operations)
- **Is it Free?**: Yes, AutoGluon is an open-source library and free to use.
- **Relevant tool (AutoGluon) related Resource Links**:
  - [AutoGluon Documentation](https://autogluon.mxnet.io/)
  - [GitHub Repository](https://github.com/awslabs/autogluon)
  - [AutoGluon Tutorials](https://autogluon.mxnet.io/tutorials/index.html)
