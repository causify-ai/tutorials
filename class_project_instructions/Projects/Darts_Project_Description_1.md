### Project Brief: Real-Time Bitcoin Price Prediction with Darts

- **Title**: Real-Time Bitcoin Price Prediction using Darts
- **Difficulty**: 3
- **Tech Description**: Darts is a Python library designed for time series forecasting that supports various models and allows for easy handling of multiple time series. It integrates seamlessly with other libraries for data manipulation and visualization.
- **Project Idea**: Develop a real-time Bitcoin price prediction system that ingests live market data from multiple cryptocurrency exchanges, processes the data, and predicts future prices using advanced time series forecasting techniques available in Darts. Implement anomaly detection to identify unusual market behavior.
- **Python libs**: Darts, Pandas, NumPy, Matplotlib, Requests, Scikit-learn, Statsmodels
- **Is it Free?**: Yes, Darts is an open-source library and is free to use.
