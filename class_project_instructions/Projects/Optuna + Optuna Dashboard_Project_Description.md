### Project Brief: Real-Time Bitcoin Data Ingestion with Optuna

- **Title**: Real-Time Bitcoin Data Ingestion and Optimization with Optuna

- **Difficulty**: 2

- **Tech Description**: 
  - Optuna is an automatic hyperparameter optimization framework designed for machine learning. It can be used to optimize parameters for real-time data ingestion processes.
  - The Optuna Dashboard provides a visual interface to monitor and analyze the optimization process.

- **Project Idea**: 
  - Develop a Python application that ingests real-time Bitcoin price data from an API (e.g., CoinGecko or Binance) and uses Optuna to optimize the parameters for data processing and storage. The dashboard will visualize the optimization results and performance metrics.

- **Python libs**: 
  - `optuna`
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `matplotlib` or `plotly` (for visualization)
  - `flask` or `streamlit` (for dashboard interface)

- **Is it Free?**: Yes, both Optuna and Optuna Dashboard are open-source and free to use.

- **Relevant tool (Optuna) related Resource Links**:
  - [Optuna Documentation](https://optuna.readthedocs.io/en/stable/)
  - [Optuna GitHub Repository](https://github.com/optuna/optuna)
  - [Optuna Dashboard Documentation](https://optuna.readthedocs.io/en/stable/tutorial/optuna_dashboard.html)
