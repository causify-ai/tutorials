### Project 1: Title: "Sentiment Analysis on Movie Reviews"
- **Difficulty:** 1
- **Tech Description:** Colossal-AI is utilized to leverage pre-trained transformer models for efficient sentiment analysis on large datasets.
- **Project Idea:** The goal of this project is to analyze the sentiment of movie reviews from the IMDb dataset to classify them as positive, negative, or neutral. Students will use Colossal-AI to load a pre-trained BERT model, fine-tune it on a subset of the IMDb dataset, and evaluate its performance. The project will involve data preprocessing, model evaluation, and visualization of sentiment trends over time.
- **Python libs:** Colossal-AI, Transformers, Pandas, Matplotlib, Scikit-learn
- **Is it Free?** Yes, Colossal-AI is open-source and the IMDb dataset is publicly available for download.
- **Relevant tool (Colossal-AI) related Resource Links:** [Colossal-AI Documentation](https://colossalai.org/docs/), [IMDb Dataset](https://www.imdb.com/interfaces/)

### Project 2: Title: "Anomaly Detection in Network Traffic"
- **Difficulty:** 2
- **Tech Description:** Colossal-AI is employed to scale up the training of a pre-trained autoencoder model for identifying anomalies in network traffic data.
- **Project Idea:** This project aims to detect anomalies in network traffic using the UNSW-NB15 dataset. Students will utilize Colossal-AI to implement a pre-trained autoencoder model that can efficiently process and identify unusual patterns in the dataset. The project will include data cleaning, model fine-tuning, and evaluation metrics to assess the model's performance in detecting anomalies.
- **Python libs:** Colossal-AI, TensorFlow, Numpy, Pandas, Matplotlib
- **Is it Free?** Yes, Colossal-AI is free to use, and the UNSW-NB15 dataset is available for public download.
- **Relevant tool (Colossal-AI) related Resource Links:** [Colossal-AI Documentation](https://colossalai.org/docs/), [UNSW-NB15 Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset-0)

### Project 3: Title: "Image Classification with Fine-tuned Vision Transformers"
- **Difficulty:** 3
- **Tech Description:** Colossal-AI is used to efficiently handle large-scale image datasets and fine-tune pre-trained Vision Transformers for image classification tasks.
- **Project Idea:** The objective of this project is to classify images from the CIFAR-10 dataset using Vision Transformers. Students will leverage Colossal-AI to manage the fine-tuning process of a pre-trained Vision Transformer model on the CIFAR-10 dataset, which includes 60,000 images across 10 classes. The project will involve data augmentation, model training, and performance evaluation, as well as visualizing misclassifications to understand model limitations.
- **Python libs:** Colossal-AI, PyTorch, torchvision, Numpy, Matplotlib
- **Is it Free?** Yes, both Colossal-AI and the CIFAR-10 dataset are freely available.
- **Relevant tool (Colossal-AI) related Resource Links:** [Colossal-AI Documentation](https://colossalai.org/docs/), [CIFAR-10 Dataset](https://www.cs.toronto.edu/~kriz/cifar.html)
