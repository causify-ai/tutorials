### Title: Real-Time Bitcoin Price Anomaly Detection using Statsmodels

- **Difficulty:** 3
- **Tech Description:** Utilize Statsmodels for time series analysis and anomaly detection in real-time Bitcoin price data.
- **Project Idea:** Ingest live Bitcoin price data from a cryptocurrency exchange API, apply statistical models to detect anomalies in price movements, and visualize the results in real-time.
- **Python libs:** 
  - `statsmodels` (for time series analysis)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `matplotlib` or `plotly` (for visualization)
  - `requests` (for API calls)
  - `schedule` (for periodic data fetching)
- **Is it Free?** Yes, all mentioned libraries are open-source and free to use.
