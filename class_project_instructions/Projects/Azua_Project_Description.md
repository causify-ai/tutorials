### Project Brief: Real-Time Bitcoin Data Ingestion with Azua

- **Title**: Real-Time Bitcoin Data Ingestion Using Azua

- **Difficulty**: 2

- **Tech Description**: Azua is a cloud-based data ingestion tool that allows for seamless integration and real-time data processing from various sources, including cryptocurrency exchanges.

- **Project Idea**: Develop a Python application that utilizes Azua to ingest real-time Bitcoin price data from multiple cryptocurrency exchanges. The application will store the data in a structured format for further analysis and visualization.

- **Python libs**:
  - `requests` - for making API calls to cryptocurrency exchanges
  - `pandas` - for data manipulation and storage
  - `json` - for handling JSON data formats
  - `azua-python-sdk` - for interacting with Azua's API

- **Is it Free?**: Azua offers a free tier with limited features; additional features may require a subscription.

  - [Azua Official Documentation](https://azua.io/docs)
  - [Azua Python SDK GitHub Repository](https://github.com/azua/azua-python-sdk)
  - [Cryptocurrency API Resources](https://www.coingecko.com/en/api)
