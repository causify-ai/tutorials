### Project 1: Exploring Climate Change Trends
- **Difficulty**: 1
- **Tech Description**: Azua is used to visualize and analyze climate data trends over time.
- **Project Idea**: The goal of this project is to explore climate change trends by analyzing historical temperature and precipitation data. Students will use Azua to create visualizations that highlight significant changes in climate patterns over the last century. The approach involves downloading datasets from the National Oceanic and Atmospheric Administration (NOAA) and using Azua to generate interactive plots that allow users to explore changes by geographic region and time period.
- **Python libs**: pandas, matplotlib, seaborn, requests
- **Is it Free?**: Yes, NOAA provides free access to climate data.
- **Relevant tool (Azua) related Resource Links**: [Azua Documentation](https://azua.io/docs), [NOAA Climate Data](https://www.ncdc.noaa.gov/cdo-web/)

### Project 2: Sentiment Analysis of Global News Articles
- **Difficulty**: 2
- **Tech Description**: Azua will be utilized to analyze and visualize sentiment trends in news articles over time.
- **Project Idea**: This project aims to perform sentiment analysis on global news articles to understand public sentiment regarding significant events. By leveraging the News API to gather articles, students will use pre-trained NLP models to assess the sentiment of articles over a specified period. Azua will help visualize the sentiment trends and correlate them with events, allowing for insights into how news coverage influences public perception.
- **Python libs**: requests, pandas, nltk, matplotlib
- **Is it Free?**: Yes, the News API offers a free tier for limited usage.
- **Relevant tool (Azua) related Resource Links**: [Azua Documentation](https://azua.io/docs), [News API](https://newsapi.org/)

### Project 3: Anomaly Detection in Financial Transactions
- **Difficulty**: 3
- **Tech Description**: Azua will be employed to detect and visualize anomalies in financial transaction data.
- **Project Idea**: The objective of this project is to identify fraudulent transactions by analyzing a dataset of financial transactions. Students will use the Kaggle Credit Card Fraud Detection dataset and apply an anomaly detection algorithm to find outliers in the transaction data. Azua will be utilized to visualize the detected anomalies and present insights on transaction patterns, helping to refine fraud detection strategies.
- **Python libs**: pandas, scikit-learn, numpy, matplotlib
- **Is it Free?**: Yes, the Kaggle dataset is freely available for public use.
- **Relevant tool (Azua) related Resource Links**: [Azua Documentation](https://azua.io/docs), [Kaggle Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/dalpozz/creditcard-fraud)
