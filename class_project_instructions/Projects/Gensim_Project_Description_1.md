**Title**: Topic Modeling for News Articles Using Gensim

**Difficulty**: 2

**Tech Description**: Gensim is utilized for unsupervised topic modeling to extract themes from a collection of news articles, leveraging its efficient algorithms for processing large text corpora.

**Project Idea**: This project aims to analyze a dataset of news articles from the News API to identify prevalent topics over time. By employing Gensim's Latent Dirichlet Allocation (LDA) model, we will preprocess the text data, including tokenization and stopword removal, to extract meaningful topics. The results will be visualized using pyLDAvis to understand the distribution of topics across different time periods, allowing for insights into how news coverage evolves. This analysis can help in understanding media trends and public interest.

**Python libs**: Gensim, pandas, numpy, matplotlib, pyLDAvis, requests

**Is it Free?**: Yes, both Gensim and the News API (with limited usage) are free to use.
