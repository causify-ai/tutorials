**Title**: Automated Feature Engineering for E-commerce Product Recommendations using TPOT

**Difficulty**: 2

**Tech Description**: TPOT is a Python library that automates the process of selecting and optimizing machine learning models and their hyperparameters, making it easier to build robust predictive models with minimal manual intervention.

**Project Idea**: In this project, we will leverage the TPOT library to automate feature engineering and model selection for predicting product recommendations in an e-commerce setting. We will use a dataset from a publicly available e-commerce API that provides user interactions, product details, and purchase history. The goal is to predict which products a user is likely to purchase next based on their browsing history and preferences. By utilizing TPOT, we will explore various feature combinations and automatically select the best-performing model for our recommendation system.

**Python libs**: TPOT, pandas, scikit-learn, requests, NumPy

**Is it Free?**: Yes, TPOT and the other mentioned libraries are open-source and free to use.
