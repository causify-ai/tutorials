### Project Brief: Real-time Bitcoin Price Prediction using PyTorch Geometric

- **Title**: Graph Neural Networks for Bitcoin Price Prediction
- **Difficulty**: 3
- **Tech Description**: Utilize PyTorch Geometric to build a Graph Neural Network (GNN) for predicting Bitcoin prices based on transaction networks and social media sentiment analysis.
- **Project Idea**: 
  - Ingest real-time Bitcoin transaction data and social media sentiment as a graph structure.
  - Use GNNs to learn from the relationships between transactions and sentiment to predict future Bitcoin prices.
  - Implement a streaming data pipeline that continuously updates the model with new data.
- **Python libs**: 
  - PyTorch Geometric
  - Pandas
  - NumPy
  - NetworkX
  - Requests (for API calls)
  - Matplotlib (for visualization)
- **Is it Free?**: Yes, all mentioned libraries are open-source and free to use.
