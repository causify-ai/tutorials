### Project Brief: Real-Time Bitcoin Price Prediction with Horovod

- **Title**: Scalable Real-Time Bitcoin Price Prediction using Horovod
- **Difficulty**: 3
- **Tech Description**: Horovod is a distributed deep learning framework that enables scalable training of machine learning models across multiple GPUs and nodes. It enhances the training speed and efficiency of large-scale models.
- **Project Idea**: Build a real-time Bitcoin price prediction model using LSTM (Long Short-Term Memory) networks. The model will ingest live data from multiple cryptocurrency exchanges and predict future prices based on historical trends and market sentiment.
- **Python libs**: 
  - `horovod`
  - `tensorflow` or `pytorch`
  - `numpy`
  - `pandas`
  - `requests` (for API calls)
  - `websocket-client` (for real-time data streaming)
  - `matplotlib` (for visualization)
- **Is it Free?**: Yes, Horovod is open-source and free to use.
