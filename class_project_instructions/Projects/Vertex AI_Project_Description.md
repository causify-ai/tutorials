### Project Brief: Real-Time Bitcoin Data Ingestion Using Vertex AI

- **Title**: Real-Time Bitcoin Data Ingestion and Analysis with Vertex AI

- **Difficulty**: 2

- **Tech Description**: Vertex AI is a managed machine learning platform by Google Cloud that facilitates the development, deployment, and scaling of ML models. It supports data ingestion, processing, and real-time analytics.

- **Project Idea**: Build a real-time data ingestion pipeline that fetches Bitcoin price data from various APIs, processes it using Vertex AI, and stores it for analysis and visualization. The project will leverage Vertex AI's capabilities to automate data workflows and integrate machine learning for predictive analytics.

- **Python libs**:
  - `google-cloud-aiplatform` (for interacting with Vertex AI)
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `matplotlib` or `seaborn` (for visualization)

- **Is it Free?**: Vertex AI offers a free tier, but usage beyond the free tier may incur costs depending on the resources utilized.
