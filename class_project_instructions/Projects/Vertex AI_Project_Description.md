### Project 1: Predicting House Prices with Vertex AI
- **Difficulty:** 1
- **Tech Description:** Vertex AI is used to create and deploy a regression model that predicts house prices based on various features.
- **Project Idea:** The goal of this project is to build a machine learning model that predicts house prices using the California Housing dataset. Students will preprocess the data, select relevant features, and utilize Vertex AI's AutoML capabilities to train a regression model. The performance of the model will be evaluated using metrics such as RMSE and R², and students will deploy the model using Vertex AI for easy access and predictions.
- **Python libs:** pandas, scikit-learn, google-cloud-aiplatform, matplotlib, seaborn
- **Is it Free?** Yes, with some limitations; Google Cloud offers a free tier for Vertex AI that allows for limited usage, which is suitable for this project.
- **Relevant tool (XYZ) related Resource Links:** 
  - [Vertex AI Documentation](https://cloud.google.com/vertex-ai/docs)
  - [California Housing Dataset](https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html)

### Project 2: Customer Sentiment Analysis on Product Reviews
- **Difficulty:** 2
- **Tech Description:** Vertex AI is leveraged to fine-tune a pre-trained NLP model for sentiment analysis on product reviews.
- **Project Idea:** In this project, students will collect product reviews from the Amazon Product Review dataset and perform sentiment analysis to classify reviews as positive, negative, or neutral. Using Vertex AI, students will fine-tune a pre-trained BERT model for this task. The results will be analyzed to identify key factors influencing customer sentiment, and visualizations will be created to present the findings effectively.

### Project 3: Anomaly Detection in Network Traffic
- **Difficulty:** 3
- **Tech Description:** Vertex AI is utilized to develop and deploy an anomaly detection model for monitoring network traffic patterns.
- **Project Idea:** This project aims to identify anomalies in network traffic data using the UNSW-NB15 dataset. Students will preprocess the dataset and apply unsupervised learning techniques, leveraging Vertex AI’s capabilities to build a model that detects unusual patterns indicative of potential cyber threats. The students will evaluate the effectiveness of the model using precision and recall metrics, and create a dashboard for visualizing the results and alerts.
- **Python libs:** pandas, scikit-learn, google-cloud-aiplatform, matplotlib, seaborn
- **Is it Free?** Yes, with some limitations; Vertex AI provides a free tier that can support the initial stages of model development and deployment.
- **Relevant tool (XYZ) related Resource Links:**
