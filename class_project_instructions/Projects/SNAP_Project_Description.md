### Project 1: Social Network Analysis of Movie Ratings
- **Difficulty**: 1
- **Tech Description**: SNAP will be used to analyze and visualize the relationships between users and their movie ratings in a social network graph.
- **Project Idea**: The goal of this project is to explore the relationships among users based on their movie ratings from the MovieLens dataset. By constructing a user-item bipartite graph, students will apply SNAP to identify communities of users with similar tastes and visualize the network. The project will involve basic graph metrics and clustering algorithms to uncover insights about user preferences and movie popularity.
- **Python libs**: `snap`, `pandas`, `networkx`, `matplotlib`, `numpy`
- **Is it Free?**: Yes, the MovieLens dataset is freely available for research purposes.
- **Relevant tool (SNAP) related Resource Links**: [SNAP Documentation](http://snap.stanford.edu/snap/doc/index.html), [MovieLens Dataset](https://grouplens.org/datasets/movielens/)

### Project 2: Anomaly Detection in Network Traffic
- **Difficulty**: 2
- **Tech Description**: SNAP will be utilized to model and analyze network traffic data for the detection of anomalies and unusual patterns.
- **Project Idea**: This project aims to develop an anomaly detection system using network traffic data from the CAIDA dataset. Students will construct a directed graph representing network flows and apply SNAP's graph algorithms to identify anomalies based on node centrality and edge weight variations. The project includes preprocessing the data, defining normal behavior, and using metrics to flag potential security threats in the network.
- **Python libs**: `snap`, `pandas`, `scikit-learn`, `matplotlib`, `numpy`
- **Is it Free?**: Yes, the CAIDA dataset is publicly accessible for research purposes.
- **Relevant tool (SNAP) related Resource Links**: [SNAP Documentation](http://snap.stanford.edu/snap/doc/index.html), [CAIDA Dataset](https://www.caida.org/data/)

### Project 3: Predicting Protein-Protein Interactions
- **Difficulty**: 3
- **Tech Description**: SNAP will be employed to analyze biological networks and predict interactions between proteins based on their network characteristics.
- **Project Idea**: The objective of this project is to predict protein-protein interactions (PPIs) using the STRING database, which provides a comprehensive network of known and predicted interactions. By constructing a PPI network in SNAP, students will analyze the structural properties of the graph and apply machine learning techniques to predict new interactions based on node features and connectivity. The project will involve feature extraction, model training using a pre-trained model, and evaluation of prediction accuracy.
- **Python libs**: `snap`, `pandas`, `scikit-learn`, `numpy`, `networkx`
- **Is it Free?**: Yes, the STRING database is freely accessible for academic research.
- **Relevant tool (SNAP) related Resource Links**: [SNAP Documentation](http://snap.stanford.edu/snap/doc/index.html), [STRING Database](https://string-db.org/)
