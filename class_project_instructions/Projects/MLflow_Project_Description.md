### Project 1: Predicting Customer Churn in E-commerce
- **Difficulty:** 1
- **Tech Description:** MLflow will be used for tracking experiments and managing the model lifecycle, including versioning and deployment.
- **Project Idea:** The goal of this project is to predict customer churn in an e-commerce platform using historical transaction data. Students will collect data from the publicly available "Online Retail" dataset on UCI Machine Learning Repository. They will preprocess the data, build a classification model using algorithms like Logistic Regression or Random Forest, and track the performance of different models with MLflow. The final model will be deployed using MLflow's model serving capabilities.
- **Python libs:** pandas, scikit-learn, MLflow, matplotlib, seaborn
- **Is it Free?** Yes, all tools and datasets used are freely available.
- **Relevant tool (MLflow) related Resource Links:** 
  - [MLflow Documentation](https://www.mlflow.org/docs/latest/index.html)
  - [UCI Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 2: Sentiment Analysis on Movie Reviews
- **Difficulty:** 2
- **Tech Description:** MLflow will be utilized to log and manage the different experiments and models built for sentiment analysis.
- **Project Idea:** This project aims to perform sentiment analysis on movie reviews using the IMDB dataset, which is available on Kaggle. Students will employ pre-trained models like BERT for transfer learning to classify the sentiment of reviews as positive or negative. MLflow will be used to manage the model training process, log performance metrics, and facilitate model versioning. The final model will be deployed as a web service for further evaluation.
- **Python libs:** pandas, transformers, MLflow, Flask, scikit-learn
- **Is it Free?** Yes, the dataset and all libraries used are freely available.
- **Relevant tool (MLflow) related Resource Links:** 
  - [MLflow Model Management](https://www.mlflow.org/docs/latest/model-registry.html)
  - [Kaggle IMDB Dataset](https://www.kaggle.com/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

### Project 3: Anomaly Detection in Network Traffic
- **Difficulty:** 3
- **Tech Description:** MLflow will be employed for tracking experiments and managing the lifecycle of the anomaly detection models.
- **Project Idea:** The objective of this project is to detect anomalies in network traffic data using the CICIDS 2017 dataset, which is publicly available. Students will preprocess the data and apply unsupervised learning techniques such as Isolation Forest or Autoencoders for anomaly detection. MLflow will be used to log various models, compare their performance, and track hyperparameter tuning. The best-performing model will be deployed for real-time anomaly detection in simulated network traffic.
- **Python libs:** pandas, scikit-learn, MLflow, TensorFlow, matplotlib
- **Is it Free?** Yes, the datasets and libraries used are freely available.
- **Relevant tool (MLflow) related Resource Links:** 
  - [MLflow Tracking](https://www.mlflow.org/docs/latest/tracking.html)
  - [CICIDS 2017 Dataset](https://www.unb.ca/cic/datasets/malmem-2020.html)
