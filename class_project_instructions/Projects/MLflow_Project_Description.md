### Project Brief: Real-Time Bitcoin Data Ingestion with MLflow

- **Title**: Real-Time Bitcoin Data Ingestion and Tracking with MLflow

- **Difficulty**: 2

- **Tech Description**: MLflow is an open-source platform for managing the machine learning lifecycle, including experimentation, reproducibility, and deployment. It can be used to track experiments, log parameters, and manage models.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API (e.g., CoinGecko or Binance), logs the data and relevant parameters using MLflow, and visualizes the data trends over time.

- **Python libs**:
  - `mlflow` for tracking and logging
  - `requests` for API calls
  - `pandas` for data manipulation
  - `matplotlib` or `plotly` for visualization

- **Is it Free?**: Yes, MLflow is open-source and free to use.
