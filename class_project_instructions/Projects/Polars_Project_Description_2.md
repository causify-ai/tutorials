### Title
Real-time Bitcoin Price Anomaly Detection with Polars

- **Difficulty**: 3
- **Tech Description**: Polars is a fast DataFrame library for Python, designed for high-performance data manipulation and analysis. It excels in handling large datasets efficiently, making it suitable for real-time data processing.
- **Project Idea**: Build a real-time system that ingests Bitcoin price data from multiple cryptocurrency exchanges, processes the data using Polars, and implements anomaly detection algorithms to identify significant price fluctuations or irregularities.
- **Python libs**: 
  - Polars (for data manipulation)
  - Requests (for API calls)
  - Scikit-learn (for anomaly detection algorithms)
  - Matplotlib/Seaborn (for visualization)
- **Is it Free?**: Yes, Polars and the other mentioned libraries are open-source and free to use.
