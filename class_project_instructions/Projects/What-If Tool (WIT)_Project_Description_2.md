### Project Brief: Real-Time Bitcoin Sentiment Analysis Using What-If Tool (WIT)

- **Title**: Real-Time Bitcoin Sentiment Analysis with WIT
- **Difficulty**: 3
- **Tech Description**: Utilize the What-If Tool (WIT) to analyze and visualize the impact of social media sentiment on Bitcoin price fluctuations in real-time.
- **Project Idea**: Scrape Twitter data for real-time sentiment on Bitcoin, process it using natural language processing (NLP) techniques, and then use WIT to explore how different sentiment levels correlate with Bitcoin price changes. This will involve building a model that predicts price movements based on sentiment analysis.
- **Python libs**: 
  - Tweepy (for Twitter API)
  - TextBlob or VaderSentiment (for sentiment analysis)
  - Pandas (for data manipulation)
  - Matplotlib or Plotly (for visualization)
  - TensorFlow or Scikit-learn (for model building)
  - What-If Tool (WIT)
- **Is it Free?**: Yes, all libraries mentioned are open-source and free to use.
