### Project Brief: Real-Time Bitcoin Data Ingestion with Stumpy

- **Title**: Real-Time Bitcoin Price Monitoring using Stumpy
- **Difficulty**: 2 (Medium - approximately 10 days to complete)
- **Tech Description**: Stumpy is a Python library designed for time series analysis, particularly for computing matrix profiles. It can efficiently handle large datasets and is useful for detecting patterns and anomalies in time series data.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes it using Stumpy to analyze trends and anomalies, and visualizes the results in real-time.
- **Python libs**: 
  - `stumpy` (for time series analysis)
  - `pandas` (for data manipulation)
  - `requests` (for API calls)
  - `matplotlib` or `plotly` (for visualization)
- **Is it Free?**: Yes, Stumpy is an open-source library and free to use.
