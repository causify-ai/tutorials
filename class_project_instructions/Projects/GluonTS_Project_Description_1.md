### Project Brief: Real-Time Bitcoin Price Forecasting with GluonTS

- **Title**: Real-Time Bitcoin Price Forecasting Using GluonTS
- **Difficulty**: 3
- **Tech Description**: GluonTS is a Python library designed for time series modeling and forecasting, providing tools for building, training, and evaluating forecasting models. It leverages deep learning techniques for accurate predictions.
- **Project Idea**: Develop a real-time Bitcoin price forecasting system that ingests live market data from multiple cryptocurrency exchanges, processes it using GluonTS, and outputs predictions on future price movements. The project will involve creating a data pipeline to handle streaming data, preprocessing it for model input, and implementing a forecasting model to predict price trends.
- **Python libs**: 
  - `GluonTS`
  - `pandas`
  - `numpy`
  - `requests` (for API calls)
  - `matplotlib` (for visualization)
  - `streamlit` (for dashboard)
- **Is it Free?**: Yes, GluonTS and the other mentioned libraries are open-source and free to use.
