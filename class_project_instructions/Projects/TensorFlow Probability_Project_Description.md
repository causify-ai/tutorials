### Project 1: Bayesian A/B Testing for Marketing Campaigns
- **Difficulty:** 1
- **Tech Description:** TensorFlow Probability will be used to model the uncertainty in conversion rates for different marketing strategies through Bayesian inference.
- **Project Idea:** The goal of this project is to analyze the effectiveness of two different marketing campaigns using Bayesian A/B testing. Students will collect data on user conversions from a marketing API (e.g., Google Ads API) and apply a Bayesian approach to estimate the conversion rates for both campaigns. By incorporating prior beliefs about conversion rates, students can update their beliefs based on observed data to determine which campaign is statistically superior. This approach allows for a more nuanced understanding of marketing effectiveness compared to traditional frequentist methods.
- **Python libs:** TensorFlow Probability, NumPy, Pandas, Matplotlib, Seaborn
- **Is it Free?** Yes, TensorFlow Probability is an open-source library, and the Google Ads API provides free access with limited usage.

### Project 2: Probabilistic Time Series Forecasting
- **Difficulty:** 2
- **Tech Description:** TensorFlow Probability will be utilized to build probabilistic models for forecasting future values in time series data.
- **Project Idea:** This project aims to forecast future stock prices using probabilistic time series models. Students will source historical stock price data from a financial API (e.g., Alpha Vantage or Yahoo Finance) and use TensorFlow Probability to implement a Gaussian Process model. The model will provide not only point estimates of future prices but also uncertainty intervals, allowing for better risk assessment in financial decisions. Students will evaluate the model’s performance against traditional ARIMA models and discuss the implications of uncertainty in financial forecasting.
- **Python libs:** TensorFlow Probability, NumPy, Pandas, Matplotlib, Statsmodels
- **Is it Free?** Yes, TensorFlow Probability is open-source, and both Alpha Vantage and Yahoo Finance APIs offer free tiers for data access.

### Project 3: Anomaly Detection in Network Traffic
- **Difficulty:** 3
- **Tech Description:** TensorFlow Probability will be employed to create a probabilistic model for detecting anomalies in network traffic data.
- **Project Idea:** The objective of this project is to identify anomalous patterns in network traffic data, which could indicate potential security threats. Students will use a publicly available dataset like the CICIDS 2017 dataset and apply a Bayesian mixture model through TensorFlow Probability. By modeling the normal behavior of network traffic, students will develop a system that can flag deviations from this behavior as anomalies. The project will include an analysis of the model's effectiveness in reducing false positives and improving detection rates compared to traditional methods.
- **Python libs:** TensorFlow Probability, NumPy, Pandas, Scikit-learn, Matplotlib
- **Is it Free?** Yes, TensorFlow Probability is open-source, and the CICIDS 2017 dataset is freely available for research purposes.
- **Relevant tool (XYZ) related Resource Links:** 
  - [TensorFlow Probability Anomaly Detection Guide](https://www.tensorflow.org/probability/examples/Anomaly_detection)
  - [CICIDS 2017 Dataset](https://www.unb.ca/cic/datasets/malmem-2020.html)
