### Project Brief: Real-Time Bitcoin Data Ingestion using TensorFlow Probability

- **Title**: Real-Time Bitcoin Price Prediction with TensorFlow Probability

- **Difficulty**: 2

- **Tech Description**: 
  - TensorFlow Probability (TFP) is a library for probabilistic reasoning and statistical analysis in TensorFlow. It provides tools for building probabilistic models, conducting Bayesian inference, and performing uncertainty quantification.

- **Project Idea**: 
  - Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes it using TensorFlow Probability to model price distributions, and predicts future price movements with uncertainty estimates.

- **Python libs**: 
  - TensorFlow Probability
  - Pandas
  - NumPy
  - Requests (for API calls)
  - Matplotlib (for visualization)

- **Is it Free?**: Yes, TensorFlow Probability is open-source and free to use.
