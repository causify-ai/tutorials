### Project Brief: Real-Time Bitcoin Data Ingestion with GluonTS

- **Title**: Real-Time Bitcoin Price Prediction Using GluonTS

- **Difficulty**: 2

- **Tech Description**: GluonTS is a Python library for probabilistic time series modeling, built on top of MXNet. It provides tools for forecasting and supports various models, making it suitable for real-time data ingestion and analysis.

- **Project Idea**: Develop a real-time Bitcoin price ingestion system that fetches live price data from a cryptocurrency API, preprocesses the data, and uses GluonTS to create and update forecasting models dynamically.

- **Python libs**:
  - `GluonTS`
  - `pandas`
  - `requests`
  - `numpy`
  - `matplotlib` (for visualization)

- **Is it Free?**: Yes, GluonTS is open-source and free to use.
