### Project 1: Time Series Forecasting of Retail Sales
- **Difficulty**: 1
- **Tech Description**: GluonTS will be used to build and evaluate forecasting models for retail sales data.
- **Project Idea**: The goal of this project is to predict future sales for a retail store using historical sales data from the UCI Machine Learning Repository's "Store Sales - Time Series Forecasting" dataset. Students will preprocess the data, create time series features, and apply various forecasting models available in GluonTS, such as ARIMA and DeepAR. The project will include model evaluation using metrics like RMSE and MAE, and a comparison of the different models' performance.
- **Python libs**: GluonTS, pandas, NumPy, matplotlib, scikit-learn
- **Is it Free?**: Yes, the UCI dataset is freely available for public use.
- **Relevant tool (GluonTS) related Resource Links**: 
  - [GluonTS Documentation](https://gluon-ts.mxnet.io/)
  - [UCI Store Sales Dataset](https://archive.ics.uci.edu/ml/datasets/Store+Sales+-+Time+Series+Forecasting)

### Project 2: Anomaly Detection in Energy Consumption
- **Difficulty**: 2
- **Tech Description**: Utilize GluonTS to detect anomalies in electricity consumption time series data.
- **Project Idea**: This project aims to identify anomalies in energy consumption data from the "UCI Individual household electric power consumption Data Set." Students will use GluonTS to model the normal consumption patterns and then apply anomaly detection techniques to flag unusual consumption spikes or drops. The project will involve visualizing the results and discussing potential implications for energy management and sustainability.
- **Python libs**: GluonTS, pandas, NumPy, matplotlib, seaborn
- **Is it Free?**: Yes, the UCI dataset is publicly available for research purposes.
- **Relevant tool (GluonTS) related Resource Links**: 
  - [GluonTS Documentation](https://gluon-ts.mxnet.io/)
  - [UCI Electric Power Consumption Dataset](https://archive.ics.uci.edu/ml/datasets/Individual+household+electric+power+consumption)

### Project 3: Multi-Variate Time Series Forecasting for Air Quality
- **Difficulty**: 3
- **Tech Description**: Leverage GluonTS for advanced multi-variate forecasting of air quality indicators.
- **Project Idea**: The objective of this project is to forecast air quality metrics, including PM2.5 and PM10 levels, using the "Air Quality UCI" dataset. Students will implement multi-variate time series forecasting using GluonTS's capabilities to handle multiple related time series. The project will involve data preprocessing, feature engineering, and model selection, focusing on the use of advanced models like NBEATS. Students will evaluate the model's performance and discuss the potential impact of air quality forecasting on public health and policy.
- **Python libs**: GluonTS, pandas, NumPy, matplotlib, scikit-learn
- **Is it Free?**: Yes, the UCI dataset is available for free and can be used for research.
- **Relevant tool (GluonTS) related Resource Links**: 
  - [GluonTS Documentation](https://gluon-ts.mxnet.io/)
  - [UCI Air Quality Dataset](https://archive.ics.uci.edu/ml/datasets/Air+Quality)
