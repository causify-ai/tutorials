### Project Brief: Real-Time Bitcoin Data Ingestion with LakeFS

- **Title**: Real-Time Bitcoin Data Ingestion and Management with LakeFS

- **Difficulty**: 2

- **Tech Description**: LakeFS is an open-source data versioning tool that allows you to manage data lakes with Git-like capabilities. It enables efficient data ingestion, versioning, and management for large datasets.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, stores it in a LakeFS-managed data lake, and allows for version control and rollback of historical data.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `lakefs` (LakeFS Python client)
  - `schedule` (for scheduling data ingestion)

- **Is it Free?**: Yes, LakeFS is open-source and free to use.
