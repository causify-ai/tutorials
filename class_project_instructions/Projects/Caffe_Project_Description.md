### Project Brief: Real-Time Bitcoin Data Ingestion Using Caffe

- **Title**: Real-Time Bitcoin Price Prediction with Caffe
- **Difficulty**: 2
- **Tech Description**: Caffe is a deep learning framework that enables the training and deployment of neural networks. While primarily used for image classification, it can be adapted for time-series prediction tasks like Bitcoin price forecasting.
- **Project Idea**: Develop a system that ingests real-time Bitcoin price data from APIs, preprocesses it, and uses a Caffe model to predict future prices based on historical trends.
- **Python libs**: 
  - `requests` (for API calls)
  - `numpy` (for data manipulation)
  - `pandas` (for data handling)
  - `caffe` (for building and training the model)
  - `matplotlib` (for visualization)
- **Is it Free?**: Yes, Caffe is open-source and free to use.

  - [Caffe GitHub Repository](https://github.com/BVLC/caffe)
  - [Caffe Documentation](http://caffe.berkeleyvision.org/)
