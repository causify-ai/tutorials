### Project Brief: Real-Time Bitcoin Data Ingestion with Koalas

- **Title**: Real-Time Bitcoin Data Ingestion Using Koalas
- **Difficulty**: 2
- **Tech Description**: Koalas is a Python library that provides a pandas-like API on top of Apache Spark, allowing for scalable data processing and analysis. It is ideal for handling large datasets in a distributed environment.
- **Project Idea**: Build a real-time data ingestion pipeline that fetches Bitcoin price data from a public API, processes it using Koalas, and stores it in a distributed data storage system (e.g., Apache Parquet on AWS S3).
- **Python libs**: 
  - Koalas
  - Requests (for API calls)
  - PySpark (for Spark integration)
  - Pandas (for local data manipulation)
  - Boto3 (for AWS S3 interaction)
- **Is it Free?**: Yes, Koalas is open-source and free to use.
