### Project 1: Analyzing Global Air Quality Trends
- **Difficulty**: 1
- **Tech Description**: Koalas will be used to manage large-scale air quality datasets in a distributed manner, leveraging its DataFrame API similar to Pandas.
- **Project Idea**: This project aims to analyze air quality data from the OpenAQ API, which provides access to a vast collection of air quality measurements from around the world. Students will explore trends in air pollution over time, comparing data across different cities and countries. The analysis will include visualizations of pollution levels and their correlation with public health data, providing insights into the impact of air quality on health and policy decisions.
- **Python libs**: Koalas, Pandas, Matplotlib, Seaborn, Requests
- **Is it Free?**: Yes, the OpenAQ API is free to use and provides public air quality data.
- **Relevant tool (Koalas) related Resource Links**: 
  - [Koalas Documentation](https://koalas.readthedocs.io/en/latest/)
  - [OpenAQ API Documentation](https://docs.openaq.org/)

### Project 2: Customer Segmentation in E-commerce
- **Difficulty**: 2
- **Tech Description**: Koalas will facilitate handling big data for customer segmentation tasks by providing a familiar DataFrame interface for distributed data processing.
- **Project Idea**: This project focuses on segmenting customers of an e-commerce platform using the Retailrocket API. By analyzing user behavior data, such as page views, purchases, and time spent on site, students will apply clustering algorithms to identify distinct customer segments. The goal is to provide actionable insights for targeted marketing strategies and personalized recommendations to enhance customer engagement and sales.
- **Python libs**: Koalas, Scikit-learn, Matplotlib, Seaborn, Requests
- **Is it Free?**: Yes, the Retailrocket API offers free access to e-commerce data for analysis.
- **Relevant tool (Koalas) related Resource Links**: 
  - [Koalas Documentation](https://koalas.readthedocs.io/en/latest/)
  - [Retailrocket API Documentation](https://docs.retailrocket.net/)

### Project 3: Predicting Stock Market Trends Using News Sentiment
- **Difficulty**: 3
- **Tech Description**: Koalas will be used to process and analyze large volumes of news articles and stock prices in a scalable manner, enabling efficient data manipulation and analysis.
- **Project Idea**: This advanced project aims to predict stock market trends by analyzing the sentiment of news articles related to specific companies using the News API. Students will extract historical stock price data and corresponding news articles, then use pre-trained NLP models to determine sentiment scores. The project will involve building a predictive model that correlates sentiment with stock price movements, allowing for insights into how news affects market behavior.
- **Python libs**: Koalas, NLTK, Scikit-learn, Matplotlib, Requests
- **Is it Free?**: Yes, the News API offers a free tier for accessing news articles.
- **Relevant tool (Koalas) related Resource Links**: 
  - [Koalas Documentation](https://koalas.readthedocs.io/en/latest/)
  - [News API Documentation](https://newsapi.org/docs/get-started)
