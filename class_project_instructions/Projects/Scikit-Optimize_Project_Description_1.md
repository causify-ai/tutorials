### Title
Real-Time Anomaly Detection in Bitcoin Transactions Using Scikit-Optimize

### Difficulty
3

### Tech Description
Utilize Scikit-Optimize for hyperparameter tuning in a machine learning model that detects anomalies in real-time Bitcoin transaction data. This project leverages streaming data and requires robust model optimization to ensure high accuracy in identifying fraudulent transactions.

### Project Idea
- Ingest real-time Bitcoin transaction data from a blockchain API.
- Implement an anomaly detection algorithm (e.g., Isolation Forest or Autoencoder).
- Use Scikit-Optimize to fine-tune model hyperparameters for optimal performance.
- Visualize detected anomalies and provide alerts for potential fraud.

### Python libs
- `scikit-optimize`
- `pandas`
- `numpy`
- `scikit-learn`
- `requests` (for API calls)
- `matplotlib` or `seaborn` (for visualization)
- `streamlit` (for real-time dashboard)
