### Project Brief: Real-Time Bitcoin Data Ingestion with What-If Tool (WIT)

- **Title**: Real-Time Bitcoin Price Analysis using What-If Tool (WIT)

- **Difficulty**: 2

- **Tech Description**: The What-If Tool (WIT) is an interactive visualization tool that allows users to analyze machine learning models and datasets, providing insights through various scenarios and data manipulations. It can be integrated with real-time data sources for dynamic analysis.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes the data, and visualizes it using the What-If Tool. Users can manipulate variables (like price thresholds) and observe the impact on predictive models.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `matplotlib` or `plotly` (for visualization)
  - `witwidget` (to integrate WIT with Jupyter Notebooks)

- **Is it Free?**: Yes, the What-If Tool is free and open-source.
