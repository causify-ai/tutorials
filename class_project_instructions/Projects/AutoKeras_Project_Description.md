### Project 1: Predicting House Prices using AutoKeras
- **Difficulty**: 1
- **Tech Description**: AutoKeras is used for automated machine learning to build a regression model for predicting house prices based on various features.
- **Project Idea**: The goal of this project is to predict house prices using the California Housing dataset. Students will utilize AutoKeras to automatically search for the best model architecture and hyperparameters. The dataset includes features such as median income, house age, and proximity to the ocean. Students will preprocess the data, apply AutoKeras for model optimization, and evaluate the model’s performance using metrics like RMSE and R². The project aims to provide insights into the factors that influence housing prices in California.
- **Python libs**: AutoKeras, pandas, scikit-learn, NumPy, matplotlib
- **Is it Free?**: Yes, AutoKeras is an open-source library, and the California Housing dataset is freely available from the UCI Machine Learning Repository.
- **Relevant tool (AutoKeras) related Resource Links**: 
  - [AutoKeras Documentation](https://autokeras.com/)
  - [California Housing Dataset](https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html)

### Project 2: Image Classification of Fashion Items
- **Difficulty**: 2
- **Tech Description**: AutoKeras is leveraged to perform automated image classification on the Fashion MNIST dataset, which consists of clothing item images.
- **Project Idea**: This project aims to classify images of fashion items into categories such as T-shirts, trousers, and sneakers using the Fashion MNIST dataset. Students will utilize AutoKeras to streamline the model selection process and optimize performance. The project will involve data preprocessing, augmentation techniques, and model evaluation using accuracy and confusion matrices. The goal is to achieve a high classification accuracy while demonstrating the effectiveness of automated machine learning in image recognition tasks.
- **Python libs**: AutoKeras, TensorFlow, NumPy, matplotlib, PIL
- **Is it Free?**: Yes, both AutoKeras and the Fashion MNIST dataset are freely available for use.
- **Relevant tool (AutoKeras) related Resource Links**: 
  - [AutoKeras Image Classification Guide](https://autokeras.com/tutorial/image_classification/)
  - [Fashion MNIST Dataset](https://github.com/zalandoresearch/fashion-mnist)

### Project 3: Time Series Forecasting of Stock Prices
- **Difficulty**: 3
- **Tech Description**: AutoKeras is employed to automate the process of building a time series forecasting model for predicting stock prices using historical data.
- **Project Idea**: This project focuses on predicting future stock prices for a selected company using historical stock price data from Yahoo Finance. Students will use AutoKeras to handle the complexities of time series forecasting, including feature engineering and model selection. The project will involve preprocessing the time series data, creating lag features, and evaluating model performance using metrics like MAE and MAPE. The aim is to provide a robust forecasting model that can assist in stock market analysis and investment decisions.
- **Python libs**: AutoKeras, pandas, yfinance, NumPy, statsmodels
- **Is it Free?**: Yes, AutoKeras is open-source, and Yahoo Finance provides free access to historical stock price data.
- **Relevant tool (AutoKeras) related Resource Links**: 
  - [AutoKeras Time Series Forecasting Guide](https://autokeras.com/tutorial/time_series/)
  - [Yahoo Finance API](https://pypi.org/project/yfinance/)
