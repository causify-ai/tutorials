### Project Brief: Real-Time Bitcoin Data Ingestion with AutoKeras

- **Title**: Real-Time Bitcoin Price Prediction using AutoKeras

- **Difficulty**: 2

- **Tech Description**: AutoKeras is an open-source software library for automated machine learning (AutoML) that simplifies the process of building deep learning models. It allows users to focus on data preparation and model evaluation without needing extensive knowledge of neural network architectures.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, preprocesses the data, and uses AutoKeras to build and train a predictive model for future Bitcoin prices.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `AutoKeras` (for model building)
  - `matplotlib` (for visualization)
  - `scikit-learn` (for data preprocessing)

- **Is it Free?**: Yes, AutoKeras is free and open-source.
