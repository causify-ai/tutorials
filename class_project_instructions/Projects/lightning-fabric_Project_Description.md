### Project 1: Predicting Housing Prices with Regression
- **Difficulty**: 1
- **Tech Description**: Lightning-Fabric is used to manage the training process of a regression model for predicting housing prices, leveraging its lightweight framework for quick experiments.
- **Project Idea**: The goal of this project is to predict housing prices based on various features such as location, size, and number of bedrooms using the Boston Housing dataset. The student will preprocess the data, implement a regression model using a pre-trained model for feature extraction, and utilize Lightning-Fabric to streamline the training and validation process. The final model will be evaluated on its predictive accuracy and the impact of different features on housing prices will be analyzed.
- **Python libs**: pandas, scikit-learn, numpy, matplotlib, lightning-fabric
- **Is it Free?**: Yes, the Boston Housing dataset is publicly available and Lightning-Fabric is an open-source tool.
