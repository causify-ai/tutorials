### Project Brief: Real-Time Bitcoin Data Ingestion with Lightning-Fabric

- **Title**: Real-Time Bitcoin Data Ingestion Using Lightning-Fabric

- **Difficulty**: 2

- **Tech Description**: Lightning-Fabric is a framework that facilitates the construction of scalable, real-time data pipelines. It allows for efficient data ingestion and processing, making it suitable for handling streaming data like Bitcoin transactions.

- **Project Idea**: Develop a Python application that utilizes Lightning-Fabric to ingest real-time Bitcoin transaction data from various APIs. The application will process and store this data in a database for further analysis and visualization.

- **Python libs**:
  - `lightning-fabric`
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `SQLAlchemy` (for database interaction)
  - `matplotlib` or `plotly` (for data visualization)

- **Is it Free?**: Yes, Lightning-Fabric is an open-source framework.
