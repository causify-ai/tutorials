### Title
Automated Customer Feedback Analysis Using Whisper Large V3

### Difficulty: 
3

### Tech Description:
Whisper Large V3 is utilized for transcribing and analyzing customer feedback from audio recordings, enabling sentiment analysis and topic extraction.

### Project Idea:
The goal of this project is to automate the analysis of customer feedback collected through voice surveys. By leveraging the Whisper Large V3 model, we will transcribe audio recordings into text and then apply natural language processing techniques to extract sentiments and key topics. The project will involve collecting audio feedback via a public API from a customer service platform, transcribing the responses, and using libraries like Hugging Face's Transformers for sentiment analysis. This will provide insights into customer satisfaction and areas for improvement, ultimately enhancing the customer experience.

### Python libs:
- Whisper
- Hugging Face Transformers
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Is it Free?
Yes, Whisper Large V3 is open-source, and the other mentioned libraries are also free to use.
