### Project Brief: Real-Time Bitcoin Data Ingestion with Prefect

- **Title**: Real-Time Bitcoin Data Ingestion Pipeline using Prefect

- **Difficulty**: 2

- **Tech Description**: Prefect is a workflow orchestration tool that allows users to build, schedule, and monitor data pipelines. It simplifies the management of data flows and provides features for handling retries, logging, and parameterization.

- **Project Idea**: Create a data ingestion pipeline that fetches real-time Bitcoin price data from a public API (e.g., CoinGecko or Binance) and stores it in a database (e.g., PostgreSQL). Use Prefect to orchestrate the data fetching, transformation, and loading processes.

- **Python libs**: 
  - `prefect`
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `sqlalchemy` (for database interaction)

- **Is it Free?**: Yes, Prefect offers a free tier for open-source usage.
