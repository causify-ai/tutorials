### Title: Real-Time Bitcoin Price Prediction with Ray Tune

- **Difficulty:** 3
- **Tech Description:** Utilize Ray Tune for hyperparameter tuning of machine learning models to predict Bitcoin prices in real-time based on streaming data from multiple sources.
- **Project Idea:** Build a real-time Bitcoin price prediction system that ingests data from various cryptocurrency exchanges and news sentiment analysis. Use Ray Tune to optimize model parameters for better accuracy in forecasting price movements.
- **Python libs:** 
  - `ray[tune]`
  - `pandas`
  - `numpy`
  - `scikit-learn`
  - `requests`
  - `BeautifulSoup` (for web scraping)
  - `TensorFlow` or `PyTorch` (for model training)
  - `matplotlib` (for visualization)
- **Is it Free?** Yes, Ray Tune is open-source and free to use.
