### Project Brief: Real-Time Bitcoin Data Ingestion with Airflow

- **Title**: Real-Time Bitcoin Data Ingestion Pipeline using Airflow

- **Difficulty**: 2

- **Tech Description**: Apache Airflow is an open-source platform to programmatically author, schedule, and monitor workflows. It is particularly useful for orchestrating complex data pipelines.

- **Project Idea**: Build a data ingestion pipeline that fetches real-time Bitcoin price data from a public API (e.g., CoinGecko or Binance) and stores it in a database (e.g., PostgreSQL). Use Airflow to schedule and manage the data ingestion tasks.

- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `SQLAlchemy` (for database interaction)
  - `apache-airflow` (for workflow orchestration)

- **Is it Free?**: Yes, Apache Airflow is free and open-source.
