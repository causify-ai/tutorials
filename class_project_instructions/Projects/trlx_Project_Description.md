### Project 1: Title: "Sentiment Analysis of Movie Reviews"
- **Difficulty:** 1
- **Tech Description:** Utilize trlx to fine-tune a pre-trained language model for sentiment analysis on movie reviews.
- **Project Idea:** The goal of this project is to classify movie reviews from the IMDb dataset as positive or negative. Students will leverage trlx to fine-tune a pre-trained model on a subset of the dataset, using transfer learning techniques. The project will involve data preprocessing, model training, and evaluation of the sentiment classification accuracy. By the end of the project, students will create a simple web application to display the sentiment analysis results of user-provided movie reviews.
- **Python libs:** trlx, transformers, pandas, scikit-learn, Flask
- **Is it Free?** Yes, all required libraries and datasets are freely available.
- **Relevant tool (trlx) related Resource Links:** [TRLX Documentation](https://trlx.readthedocs.io/en/latest/), [IMDb Dataset](https://www.imdb.com/interfaces/)

### Project 2: Title: "News Article Topic Classification"
- **Difficulty:** 2
- **Tech Description:** Implement trlx to adapt a pre-trained transformer model for classifying news articles into predefined categories.
- **Project Idea:** This project aims to classify news articles from the News API into categories such as politics, sports, technology, and health. Students will use trlx to fine-tune a language model on a labeled dataset obtained from the News API. The project will include data extraction, model training, and performance evaluation using metrics like F1-score and accuracy. The final deliverable will be a classification tool that can categorize new articles based on user input.
- **Python libs:** trlx, transformers, requests, pandas, scikit-learn
- **Is it Free?** Yes, the News API offers a free tier for limited usage, and all libraries are open-source.
- **Relevant tool (trlx) related Resource Links:** [TRLX Documentation](https://trlx.readthedocs.io/en/latest/), [News API](https://newsapi.org/docs/getting-started)

### Project 3: Title: "Automated Code Generation from Natural Language Descriptions"
- **Difficulty:** 3
- **Tech Description:** Use trlx to fine-tune a language model for generating code snippets based on natural language prompts.
- **Project Idea:** The objective of this project is to create a system that can generate Python code from natural language descriptions using the CodeSearchNet dataset. Students will fine-tune a pre-trained model with trlx to improve its ability to translate user prompts into functional code. The project will involve data cleaning, model training, and testing the generated code for correctness. The final product will be an interactive command-line tool where users can input descriptions and receive corresponding code snippets.
- **Python libs:** trlx, transformers, pandas, PyGithub, pytest
- **Is it Free?** Yes, all libraries and the dataset are available for free.
- **Relevant tool (trlx) related Resource Links:** [TRLX Documentation](https://trlx.readthedocs.io/en/latest/), [CodeSearchNet Dataset](https://github.com/github/CodeSearchNet)
