### Project 1: Analyzing Customer Purchase Sequences

- **Difficulty**: 1
- **Tech Description**: seqlearn is utilized to model sequential data for customer purchase behaviors, enabling the prediction of future purchases based on past sequences.
- **Project Idea**: The goal of this project is to analyze customer transaction data from an e-commerce platform to predict future purchases. Using the publicly available "Online Retail" dataset from the UCI Machine Learning Repository, the student will preprocess transaction sequences to create a structured dataset. By applying seqlearn, the student will implement a sequence prediction model that identifies patterns in customer purchases and suggests future product recommendations. The project will also evaluate model performance using metrics such as accuracy and F1-score.
- **Python libs**: seqlearn, pandas, numpy, scikit-learn, matplotlib
- **Is it Free?**: Yes, the dataset is publicly available and can be downloaded without any cost.
- **Relevant tool (seqlearn) related Resource Links**:  
  - [seqlearn Documentation](https://seqlearn.readthedocs.io/en/latest/)  
  - [UCI Machine Learning Repository - Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 2: Predicting Music Genre from Listening Sequences

- **Difficulty**: 2
- **Tech Description**: seqlearn is employed to analyze sequential data of music listening habits to classify genres based on user behavior over time.
- **Project Idea**: This project aims to predict music genres based on users' listening sequences using the "Million Song Dataset," which contains a wealth of music-related data. The student will extract listening sequences from user profiles and preprocess the data for analysis. By leveraging seqlearn, the student will build a sequence classification model to predict the genre of music based on the order of songs listened to. The project will also involve visualizing the most common transitions between genres and evaluating the model's classification accuracy.
- **Python libs**: seqlearn, pandas, numpy, scikit-learn, seaborn
- **Is it Free?**: Yes, the Million Song Dataset is available for free access and use.
- **Relevant tool (seqlearn) related Resource Links**:  
  - [seqlearn Documentation](https://seqlearn.readthedocs.io/en/latest/)  
  - [Million Song Dataset](http://millionsongdataset.com/)

### Project 3: Anomaly Detection in Network Traffic Sequences

- **Difficulty**: 3
- **Tech Description**: seqlearn is used to detect anomalies in network traffic sequences, identifying unusual patterns that may indicate security threats.
- **Project Idea**: The objective of this project is to develop an anomaly detection system for network traffic using the "CICIDS 2017" dataset, which includes various types of network traffic. The student will preprocess the data to extract sequence patterns of normal and anomalous traffic. By implementing seqlearn, the student will create a model capable of identifying deviations from established patterns in the traffic data. The project will also explore the implications of detected anomalies and their potential impact on network security, as well as providing visualizations of the results.
- **Python libs**: seqlearn, pandas, numpy, scikit-learn, matplotlib
- **Is it Free?**: Yes, the CICIDS 2017 dataset is publicly available for research purposes at no cost.
- **Relevant tool (seqlearn) related Resource Links**:  
  - [seqlearn Documentation](https://seqlearn.readthedocs.io/en/latest/)  
  - [CICIDS 2017 Dataset](https://www.unb.ca/cic/datasets/malmem-2020.html)
