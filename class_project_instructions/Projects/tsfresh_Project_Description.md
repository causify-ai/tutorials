### Project Brief: Real-Time Bitcoin Data Ingestion using tsfresh

- **Title**: Real-Time Bitcoin Price Analysis with tsfresh

- **Difficulty**: 2

- **Tech Description**: tsfresh is a Python library designed for time series feature extraction. It automatically calculates a large number of time series characteristics, making it suitable for analyzing real-time Bitcoin data.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, processes the data using tsfresh to extract relevant features, and analyzes these features for predictive modeling or anomaly detection.

- **Python libs**: 
  - `tsfresh` for feature extraction
  - `pandas` for data manipulation
  - `requests` for API calls
  - `numpy` for numerical operations
  - `matplotlib` or `seaborn` for data visualization

- **Is it Free?**: Yes, tsfresh is an open-source library and is free to use.

  - [tsfresh GitHub Repository](https://github.com/blue-yonder/tsfresh)
