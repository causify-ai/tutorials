**Title**: Hyperparameter Optimization for Time Series Forecasting of Air Quality Index (AQI)

**Difficulty**: 2

**Tech Description**: Scikit-Optimize will be employed to perform hyperparameter tuning for a time series forecasting model that predicts the Air Quality Index (AQI) using historical data.

**Project Idea**: The goal of this project is to develop a robust time series forecasting model to predict future AQI levels based on historical data from various cities. We will utilize the OpenWeatherMap API to gather historical air quality data. The project will involve preprocessing the data, selecting appropriate features, and implementing a forecasting model (e.g., ARIMA or LSTM). Scikit-Optimize will be used to fine-tune the hyperparameters of the chosen model, enhancing its predictive performance. The final output will be a set of optimized parameters and a comparison of model performance before and after optimization.

**Python libs**: pandas, numpy, scikit-learn, scikit-optimize, statsmodels, requests, matplotlib

**Is it Free?**: Yes, the OpenWeatherMap API offers a free tier for accessing air quality data.
