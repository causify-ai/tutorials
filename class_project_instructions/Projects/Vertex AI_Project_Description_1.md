### Title
Real-time Bitcoin Price Prediction using Vertex AI

### Difficulty
3

### Tech Description
Vertex AI is a managed machine learning platform that enables users to build, deploy, and scale ML models efficiently. It integrates seamlessly with Google Cloud services and supports various ML frameworks.

### Project Idea
Develop a real-time Bitcoin price prediction system that ingests live market data from multiple cryptocurrency exchanges using WebSocket APIs. The system will utilize Vertex AI to train and deploy a time-series forecasting model that predicts future Bitcoin prices based on historical data and market sentiment analysis.

### Python libs
- `google-cloud-aiplatform` (for Vertex AI integration)
- `pandas` (data manipulation)
- `numpy` (numerical operations)
- `requests` (API calls)
- `websocket-client` (real-time data ingestion)
- `statsmodels` (time-series analysis)
- `scikit-learn` (data preprocessing)
- `matplotlib` (visualization)
