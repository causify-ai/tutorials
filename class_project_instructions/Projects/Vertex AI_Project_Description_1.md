**Title:** Predicting Movie Success Using Social Media Sentiment Analysis

**Difficulty:** 2

**Tech Description:** Vertex AI will be utilized to build and deploy a machine learning model that predicts movie box office success based on social media sentiment analysis.

**Project Idea:** The goal of this project is to analyze tweets related to upcoming movie releases and predict their box office performance. By leveraging the Twitter API, we will collect tweets containing specific movie titles and perform sentiment analysis using natural language processing techniques. The sentiment scores will be used as features in a regression model to forecast box office earnings. This project not only demonstrates the application of sentiment analysis but also explores the relationship between public perception and financial success in the film industry.

**Python libs:** pandas, numpy, tweepy, nltk, scikit-learn, matplotlib, seaborn

**Is it Free?** Yes, the Twitter API has a free tier for accessing tweets, and all other libraries mentioned are open-source.
