**Title**: Causal Analysis of Economic Indicators Using Tetrad

**Difficulty**: 3

**Tech Description**: Tetrad is utilized for causal discovery and graphical modeling, allowing researchers to identify and visualize causal relationships among economic indicators.

**Project Idea**: This project aims to explore the causal relationships between various economic indicators (such as unemployment rates, inflation, and GDP growth) using data obtained from the World Bank API. By employing Tetrad, we will construct causal graphs that depict the interdependencies among these indicators. The goal is to identify potential causal pathways and understand how changes in one indicator may affect others. We will also validate the causal relationships using statistical tests and analyze the implications for economic policy-making.

**Python libs**: Tetrad, pandas, requests, matplotlib, statsmodels
