### Title: Real-Time Anomaly Detection in Bitcoin Transactions Using Tetrad

- **Difficulty:** 3
- **Tech Description:** Tetrad is a tool for causal inference that can be used to model and analyze the relationships between variables. It can help identify causal relationships in complex datasets, making it suitable for anomaly detection in financial transactions.
- **Project Idea:** Implement a real-time anomaly detection system for Bitcoin transactions. Use Tetrad to model the causal relationships between transaction features and identify anomalies that may indicate fraudulent activities.
- **Python libs:** 
  - `tetrad`
  - `pandas`
  - `numpy`
  - `scikit-learn`
  - `matplotlib`
  - `requests`
  - `flask` (for real-time API)
- **Is it Free?** Yes, Tetrad is open-source and free to use.
