### Project Brief: Real-Time Bitcoin Data Ingestion Using RLlib

- **Title**: Real-Time Bitcoin Price Prediction with RLlib

- **Difficulty**: 2

- **Tech Description**: RLlib is a scalable reinforcement learning library built on top of Ray, designed for building and training reinforcement learning models. It provides a high-level API for defining environments and agents, making it suitable for real-time data ingestion and decision-making tasks.

- **Project Idea**: Develop a reinforcement learning model that ingests real-time Bitcoin price data and predicts future price movements. The model will use RLlib to train an agent that learns to make buy/sell decisions based on historical and real-time data.

- **Python libs**: 
  - `rllib` (for reinforcement learning)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `requests` (for API calls to fetch real-time Bitcoin data)
  - `matplotlib` (for data visualization)

- **Is it Free?**: Yes, RLlib is open-source and free to use.
