### Project Brief: Real-time Bitcoin Anomaly Detection with Dask

- **Title**: Real-time Anomaly Detection in Bitcoin Transactions
- **Difficulty**: 3
- **Tech Description**: Utilize Dask for distributed computing to process and analyze large volumes of Bitcoin transaction data in real-time, detecting anomalies that could indicate fraud or unusual activity.
- **Project Idea**: Create a real-time pipeline that ingests Bitcoin transaction data from various sources (e.g., blockchain APIs and web scraping) and applies machine learning techniques to identify anomalies using Dask’s parallel processing capabilities.
- **Python libs**: 
  - Dask
  - Pandas
  - Scikit-learn
  - Requests (for web scraping)
  - Matplotlib/Seaborn (for visualization)
- **Is it Free?**: Yes, Dask and the associated libraries are open-source and free to use.
