**Title:** Predicting Air Quality Index Using TFX

**Difficulty:** 2

**Tech Description:** TFX (TensorFlow Extended) is utilized to create a production-ready machine learning pipeline that ingests, processes, and serves predictions on air quality data in real-time.

**Project Idea:** The goal of this project is to predict the Air Quality Index (AQI) for various cities based on historical pollution data and meteorological factors. The project will involve collecting data from the OpenWeatherMap API, which provides real-time weather data, and combining it with historical AQI data from the U.S. Environmental Protection Agency (EPA). The TFX pipeline will include data validation, transformation, and model training using a regression approach. The final model will be deployed to serve real-time predictions, allowing users to understand air quality trends and make informed decisions.

**Python libs:** TensorFlow, TFX, Pandas, NumPy, Requests, Scikit-learn

**Is it Free?** Yes, both the OpenWeatherMap API (with limited free access) and EPA datasets are publicly available.
