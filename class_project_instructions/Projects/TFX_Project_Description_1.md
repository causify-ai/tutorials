### Title
Real-Time Bitcoin Price Prediction Using TFX

### Difficulty
3

### Tech Description
TFX (TensorFlow Extended) is an end-to-end platform for deploying production machine learning pipelines. It provides components for data ingestion, validation, transformation, model training, and serving.

### Project Idea
Develop a real-time Bitcoin price prediction system that ingests live market data, performs feature engineering, trains a forecasting model, and serves predictions through a REST API. The project will involve building a robust pipeline using TFX to automate the entire workflow.

### Python libs
- TensorFlow
- TFX
- Pandas
- NumPy
- Flask (for API)
- Requests (for data ingestion)
- Scikit-learn (for preprocessing)
- Apache Beam (for data processing)

### Is it Free?
Yes, TFX and its associated libraries are open-source and free to use.
