### Project Brief: Real-Time Causal Analysis of Bitcoin Price Movements Using LiNGAM

- **Title**: Causal Analysis of Bitcoin Price Influencers
- **Difficulty**: 3
- **Tech Description**: LiNGAM (Linear Non-Gaussian Acyclic Model) is a causal inference method that identifies causal relationships from observational data. It can be used to analyze how various factors influence Bitcoin price movements.
- **Project Idea**: Develop a real-time data ingestion pipeline that collects data from multiple sources (social media sentiment, economic indicators, and news articles) to analyze their causal impact on Bitcoin prices using LiNGAM.
- **Python libs**: 
  - `liNGAM`: For causal inference analysis
  - `pandas`: For data manipulation
  - `requests`: For web scraping and API calls
  - `BeautifulSoup`: For scraping news articles
  - `numpy`: For numerical operations
  - `matplotlib` or `seaborn`: For visualization
- **Is it Free?**: Yes, all mentioned libraries are open-source and free to use.

  - [LiNGAM GitHub Repository](https://github.com/py-causal/liNGAM)
  - [LiNGAM Documentation](https://lingam.readthedocs.io/en/latest/)
