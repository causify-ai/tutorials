### Project 1: Predicting Housing Prices with FLAML  
- **Difficulty**: 1  
- **Tech Description**: FLAML will be used for automated machine learning to optimize hyperparameters for regression models.  
- **Project Idea**: The goal of this project is to predict housing prices based on various features such as location, size, and amenities using the California Housing dataset. Students will utilize FLAML to automate the model selection and hyperparameter tuning process, allowing them to efficiently find the best-performing model. The project will involve data preprocessing, feature selection, and model evaluation using metrics like RMSE.  
- **Python libs**: FLAML, pandas, scikit-learn, numpy, matplotlib  
- **Is it Free?**: Yes, FLAML is an open-source library, and the California Housing dataset is freely available from the UCI Machine Learning Repository.  
- **Relevant tool (FLAML) related Resource Links**: [FLAML GitHub](https://github.com/microsoft/FLAML), [California Housing Dataset](https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html)

### Project 2: Customer Segmentation using E-commerce Data  
- **Difficulty**: 2  
- **Tech Description**: FLAML will assist in automating the selection of clustering algorithms and hyperparameter tuning for customer segmentation.  
- **Project Idea**: This project aims to segment customers based on their purchasing behavior using the Online Retail dataset from UCI. Students will apply FLAML to identify the optimal clustering algorithm (e.g., KMeans, DBSCAN) and its parameters to group customers into distinct segments. The focus will be on understanding customer profiles and tailoring marketing strategies for each segment. Visualization techniques will also be employed to present the results effectively.  
- **Python libs**: FLAML, pandas, scikit-learn, seaborn, matplotlib  
- **Is it Free?**: Yes, both FLAML and the Online Retail dataset are freely available.  
- **Relevant tool (FLAML) related Resource Links**: [FLAML GitHub](https://github.com/microsoft/FLAML), [Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/online+retail)

### Project 3: Anomaly Detection in Network Traffic  
- **Difficulty**: 3  
- **Tech Description**: FLAML will be utilized to automate the model selection and hyperparameter tuning for anomaly detection algorithms on network traffic data.  
- **Project Idea**: The objective of this project is to detect anomalies in network traffic using the UNSW-NB15 dataset. Students will leverage FLAML to explore various anomaly detection techniques, such as Isolation Forest and One-Class SVM, and optimize their parameters. The project will involve preprocessing the dataset, feature engineering, and evaluating model performance using metrics like precision, recall, and F1-score. The final deliverable will include a comprehensive analysis of the detected anomalies and their potential implications for network security.  
- **Python libs**: FLAML, pandas, scikit-learn, numpy, matplotlib  
- **Is it Free?**: Yes, FLAML is open-source, and the UNSW-NB15 dataset is publicly available for research purposes.  
- **Relevant tool (FLAML) related Resource Links**: [FLAML GitHub](https://github.com/microsoft/FLAML), [UNSW-NB15 Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset-2015)
