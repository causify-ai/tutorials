### Project Brief: Real-Time Bitcoin Data Ingestion with FLAML

- **Title**: Real-Time Bitcoin Price Prediction using FLAML
- **Difficulty**: 2
- **Tech Description**: FLAML (Fast Lightweight AutoML) is an open-source library that automates the process of machine learning model selection and hyperparameter tuning, making it suitable for real-time data ingestion and prediction tasks.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, preprocesses the data, and uses FLAML to automatically select and tune machine learning models for price prediction.
- **Python libs**:
  - `requests` (for API data ingestion)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `flaml` (for automated machine learning)
  - `matplotlib` (for data visualization)
- **Is it Free?**: Yes, FLAML is an open-source library and free to use.
- **Relevant tool (FLAML) related Resource Links**:
  - [FLAML GitHub Repository](https://github.com/microsoft/FLAML)
  - [FLAML Documentation](https://flaml.readthedocs.io/en/latest/)
  - [FLAML Examples](https://github.com/microsoft/FLAML/tree/main/examples)
