### Project Brief: Real-Time Bitcoin Data Ingestion using loralib

- **Title**: Real-Time Bitcoin Data Ingestion with loralib

- **Difficulty**: 2

- **Tech Description**: loralib is a Python library designed for efficient data ingestion and processing, particularly suited for real-time applications. It provides tools for handling streaming data, making it ideal for financial data like Bitcoin prices.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API (e.g., CoinGecko or Binance) using loralib. The application will process and store the data in a database for further analysis and visualization.

- **Python libs**: 
  - loralib
  - requests (for API calls)
  - pandas (for data manipulation)
  - SQLAlchemy (for database interaction)
  - matplotlib/seaborn (for visualization)

- **Is it Free?**: Yes, loralib is an open-source library.
