### Project 1: Sentiment Analysis of Poetry
- **Difficulty:** 1
- **Tech Description:** Haiku will be utilized to create a sentiment analysis model that evaluates the emotional tone of different poems.
- **Project Idea:** The goal of this project is to analyze a dataset of poems from various authors and classify them into positive, negative, or neutral sentiments. Using pre-trained NLP models, students will extract features from the text and apply classification algorithms to predict sentiment. The project will involve visualizing sentiment trends over time and comparing the emotional tones of different poets. The dataset will be sourced from Project Gutenberg, which offers a wide range of literary works in the public domain.
- **Python libs:** pandas, numpy, scikit-learn, nltk, matplotlib
- **Is it Free?** Yes, the dataset is available for free through Project Gutenberg.
- **Relevant tool (Haiku) related Resource Links:** [Haiku Documentation](https://haiku.readthedocs.io/en/latest/), [Project Gutenberg](https://www.gutenberg.org/)

### Project 2: Generating Haikus from News Headlines
- **Difficulty:** 2
- **Tech Description:** Haiku will be used to generate creative haikus based on trending news headlines using a pre-trained language model.
- **Project Idea:** This project aims to create a system that generates haikus inspired by the latest news articles. By scraping news headlines from a free API like NewsAPI.org, students will preprocess the text and use Haiku to create a model that generates haikus reflecting the essence of current events. The generated haikus will be evaluated for creativity and relevance, and a user interface will be developed to display the results. This project combines natural language processing with creative writing, providing insights into how AI can interpret human language.
- **Python libs:** requests, beautifulsoup4, transformers, tkinter, numpy
- **Is it Free?** Yes, both the NewsAPI and Haiku are free to use.
- **Relevant tool (Haiku) related Resource Links:** [Haiku Documentation](https://haiku.readthedocs.io/en/latest/), [NewsAPI](https://newsapi.org/)

### Project 3: Analyzing Themes in Classic Haikus
- **Difficulty:** 3
- **Tech Description:** Haiku will facilitate the thematic analysis of traditional haikus through clustering and topic modeling techniques.
- **Project Idea:** The objective of this project is to explore the thematic elements of classic haikus from renowned poets like Matsuo Bashō and Yosa Buson. Students will compile a dataset of haikus from various sources, such as the Haiku Society of America, and perform text preprocessing. Using Haiku, students will apply topic modeling techniques like Latent Dirichlet Allocation (LDA) to identify prevalent themes and cluster similar haikus. The findings will be visualized and discussed in the context of historical and cultural significance, providing a deeper understanding of haiku as a literary form.
- **Python libs:** pandas, numpy, gensim, matplotlib, seaborn
- **Is it Free?** Yes, the haiku dataset can be freely accessed through various literary sources online.
- **Relevant tool (Haiku) related Resource Links:** [Haiku Documentation](https://haiku.readthedocs.io/en/latest/), [Haiku Society of America](https://www.hsa-haiku.org/)
