### Project Brief: Real-Time Bitcoin Data Ingestion with Haiku

- **Title**: Real-Time Bitcoin Data Ingestion using Haiku
- **Difficulty**: 2
- **Tech Description**: Haiku is a lightweight, event-driven framework for building real-time data pipelines, making it suitable for ingesting live data streams such as Bitcoin price feeds.
- **Project Idea**: Develop a Python application that uses Haiku to ingest real-time Bitcoin price data from a public API, process it, and store it in a database for further analysis and visualization.
- **Python libs**: 
  - `haiku` (for building the data pipeline)
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `SQLAlchemy` (for database interaction)
- **Is it Free?**: Yes, Haiku is open-source and free to use.
- **Relevant tool (Haiku) related Resource Links**: 
  - [Haiku GitHub Repository](https://github.com/haiku/haiku)
  - [Haiku Documentation](https://haiku.readthedocs.io/en/latest/)
  - [Bitcoin API Documentation](https://www.coindesk.com/coindesk-api/)
