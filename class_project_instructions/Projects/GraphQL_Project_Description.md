### Project Brief: Real-Time Bitcoin Data Ingestion Using GraphQL

- **Title**: Real-Time Bitcoin Data Ingestion with GraphQL

- **Difficulty**: 2

- **Tech Description**: 
  - GraphQL is a query language for APIs that allows clients to request only the data they need. It provides a more efficient and flexible alternative to REST APIs, making it suitable for real-time data ingestion.

- **Project Idea**: 
  - Develop a Python application that uses GraphQL to fetch real-time Bitcoin price data from a cryptocurrency API. The application will allow users to query specific data points, such as current price, market cap, and volume, and display them in a user-friendly format.

- **Python libs**: 
  - `requests` (for making HTTP requests)
  - `graphqlclient` (for interacting with GraphQL APIs)
  - `pandas` (for data manipulation and analysis)
  - `flask` (for creating a web interface, if needed)

- **Is it Free?**: 
  - Yes, GraphQL itself is free to use, but the API you connect to may have usage limits or costs associated with it.

  - [Python GraphQL Client Documentation](https://graphql-python.org/)
