### Project Brief: Real-Time Bitcoin Data Ingestion with Skorch

- **Title**: Real-Time Bitcoin Data Ingestion and Analysis using Skorch
- **Difficulty**: 2
- **Tech Description**: Skorch is a high-level library that wraps PyTorch, providing a scikit-learn-like interface for training neural networks. It simplifies the process of building and training models, making it easier to integrate with data ingestion pipelines.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, preprocesses the data, and uses a neural network model built with Skorch to predict future Bitcoin prices.
- **Python libs**:
  - `skorch` (for model training)
  - `pandas` (for data manipulation)
  - `requests` (for API calls)
  - `numpy` (for numerical operations)
  - `matplotlib` (for data visualization)
- **Is it Free?**: Yes, Skorch is open-source and free to use.
