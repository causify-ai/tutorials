### Project 1: Predicting House Prices with Neural Networks
- **Difficulty**: 1
- **Tech Description**: Utilize skorch to wrap a PyTorch neural network model for regression tasks, specifically for predicting house prices.
- **Project Idea**: The goal of this project is to predict house prices based on various features such as location, size, and number of bedrooms using the Boston Housing Dataset. Students will preprocess the data, build a simple feedforward neural network with skorch, and evaluate its performance against traditional regression models. The project will emphasize the advantages of using neural networks for regression tasks in real estate.
- **Python libs**: skorch, torch, pandas, scikit-learn, numpy
- **Is it Free?**: Yes, the Boston Housing Dataset is publicly available and can be downloaded from the UCI Machine Learning Repository.
- **Relevant tool (skorch) related Resource Links**: [skorch Documentation](https://skorch.readthedocs.io/en/stable/), [Boston Housing Dataset](https://archive.ics.uci.edu/ml/datasets/Housing)

### Project 2: Customer Segmentation with Autoencoders
- **Difficulty**: 2
- **Tech Description**: Implement skorch to build an autoencoder model for unsupervised customer segmentation using a neural network.
- **Project Idea**: This project aims to segment customers based on their purchasing behavior using the Online Retail Dataset. Students will preprocess the transactional data and use skorch to create an autoencoder that captures the latent features of customer transactions. The segmented customers can be used for targeted marketing strategies. The project will also include performance evaluation metrics like reconstruction loss and clustering quality.
- **Python libs**: skorch, torch, pandas, scikit-learn, matplotlib
- **Is it Free?**: Yes, the Online Retail Dataset is available for free on the UCI Machine Learning Repository.
- **Relevant tool (skorch) related Resource Links**: [skorch Documentation](https://skorch.readthedocs.io/en/stable/), [Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/online+retail)

### Project 3: Text Classification with Transfer Learning
- **Difficulty**: 3
- **Tech Description**: Use skorch to fine-tune a pre-trained transformer model for text classification tasks.
- **Project Idea**: The goal of this project is to classify movie reviews as positive or negative using the IMDb dataset. Students will leverage a pre-trained BERT model and use skorch to build a classification pipeline. The project will involve data preprocessing, model fine-tuning, and performance evaluation using metrics such as accuracy and F1 score. This project will highlight the effectiveness of transfer learning in natural language processing tasks.
- **Python libs**: skorch, torch, transformers, pandas, scikit-learn
- **Is it Free?**: Yes, the IMDb dataset is freely available through various sources including Kaggle and the TensorFlow Datasets.
- **Relevant tool (skorch) related Resource Links**: [skorch Documentation](https://skorch.readthedocs.io/en/stable/), [IMDb Dataset](https://www.imdb.com/interfaces/)
