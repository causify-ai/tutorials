### Project Brief: Real-Time Bitcoin Data Ingestion using Kats

- **Title**: Real-Time Bitcoin Price Monitoring with Kats

- **Difficulty**: 2

- **Tech Description**: 
  - Kats is a toolkit for time series analysis and forecasting developed by Facebook. It provides functionalities for data ingestion, anomaly detection, forecasting, and more, making it suitable for real-time data applications.

- **Project Idea**: 
  - Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API (e.g., CoinGecko or Binance) and utilizes Kats to analyze trends, detect anomalies, and visualize price movements.

- **Python libs**: 
  - `kats`
  - `pandas`
  - `requests`
  - `matplotlib`
  - `numpy`

- **Is it Free?**: Yes, Kats is open-source and free to use.
