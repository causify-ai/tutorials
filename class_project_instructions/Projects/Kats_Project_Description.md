### Project 1: Time Series Anomaly Detection in Retail Sales
- **Difficulty:** 1 (Easy)
- **Tech Description:** Kats will be utilized to perform anomaly detection on retail sales data, identifying unusual patterns that may indicate issues or opportunities.
- **Project Idea:** The goal of this project is to analyze historical retail sales data from the UCI Machine Learning Repository to detect anomalies that could signify stock issues, promotions, or external factors affecting sales. Using Kats' built-in anomaly detection algorithms, students will preprocess the data, apply the algorithms, and visualize the results to understand the anomalies. The final deliverable will include a report summarizing findings and recommendations for the retail business based on the detected anomalies.
- **Python libs:** Kats, Pandas, Matplotlib, NumPy, Scikit-learn
- **Is it Free?** Yes, the UCI dataset is publicly available and Kats is an open-source library.
- **Relevant tool (Kats) related Resource Links:** 
  - [Kats GitHub Repository](https://github.com/facebookresearch/Kats)
  - [UCI Retail Sales Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 2: Forecasting Air Quality Index (AQI) Levels
- **Difficulty:** 2 (Medium)
- **Tech Description:** Kats will be used to build forecasting models for predicting future Air Quality Index levels based on historical data.
- **Project Idea:** This project aims to forecast the Air Quality Index (AQI) for a specific city using historical AQI data obtained from the OpenWeatherMap API. Students will employ Kats to implement various forecasting methods such as ARIMA and Prophet, comparing their effectiveness in predicting future AQI levels. The project will include visualizations of the forecasted data alongside actual AQI measurements to assess model performance. The final report will discuss implications for public health and potential policy recommendations.
- **Python libs:** Kats, Pandas, Matplotlib, Requests, Statsmodels
- **Is it Free?** Yes, OpenWeatherMap provides a free tier API for accessing AQI data.
- **Relevant tool (Kats) related Resource Links:** 
  - [Kats Documentation](https://facebookresearch.github.io/Kats/)
  - [OpenWeatherMap API](https://openweathermap.org/api)

### Project 3: Seasonal Decomposition of Energy Consumption Data
- **Difficulty:** 3 (Hard)
- **Tech Description:** Kats will be utilized to decompose energy consumption time series data into seasonal, trend, and residual components to gain insights into consumption patterns.
- **Project Idea:** This project focuses on analyzing energy consumption data from the UCI Machine Learning Repository to understand seasonal trends and patterns. Using Kats, students will apply seasonal decomposition techniques to break down the time series data into its constituent parts. The project will involve data cleaning, decomposition analysis, and visualization of the results. Students will also explore potential correlations with external factors such as weather data or economic indicators. The final deliverable will be a comprehensive analysis report detailing findings and implications for energy management.
- **Python libs:** Kats, Pandas, Matplotlib, NumPy, Statsmodels
- **Is it Free?** Yes, the UCI dataset is publicly available, and Kats is an open-source library.
- **Relevant tool (Kats) related Resource Links:** 
  - [Kats GitHub Repository](https://github.com/facebookresearch/Kats)
  - [UCI Energy Consumption Dataset](https://archive.ics.uci.edu/ml/datasets/Energy+efficiency)
