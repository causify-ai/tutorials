- **Title**: Anomaly Detection in E-commerce Transactions Using Kats

- **Difficulty**: 2

- **Tech Description**: Kats is utilized for time series analysis and anomaly detection in transaction data, enabling the identification of unusual spending patterns.

- **Project Idea**: This project aims to detect fraudulent transactions in e-commerce by analyzing time series data of customer purchases. We will collect transaction data from a public e-commerce dataset, focusing on the timestamp and transaction amount. Using Kats, we will apply anomaly detection techniques to identify outliers that may indicate fraudulent activity. The project will involve preprocessing the data, visualizing trends, and implementing Kats' anomaly detection algorithms to highlight suspicious transactions.

- **Python libs**: Kats, pandas, numpy, matplotlib, scikit-learn
