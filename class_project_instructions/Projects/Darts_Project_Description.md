### Project Brief: Real-Time Bitcoin Data Ingestion using Darts

- **Title**: Real-Time Bitcoin Price Forecasting with Darts
- **Difficulty**: 2
- **Tech Description**: Darts is a Python library designed for easy handling of time series data, providing tools for forecasting and evaluation. It supports various models and allows for seamless integration with real-time data sources.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, processes it using Darts, and generates short-term price forecasts. The application will visualize the data and predictions using interactive plots.
- **Python libs**: 
  - `darts` (for time series forecasting)
  - `pandas` (for data manipulation)
  - `requests` (for API calls)
  - `matplotlib` or `plotly` (for data visualization)
- **Is it Free?**: Yes, Darts is open-source and free to use.
