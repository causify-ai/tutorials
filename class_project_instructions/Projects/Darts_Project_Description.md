**Title**: Predicting Movie Success Using Social Media Sentiment Analysis

**Difficulty**: 2

**Tech Description**: Darts is utilized in this project for time series forecasting of movie box office revenues based on sentiment scores derived from social media data.

**Project Idea**: The goal of this project is to predict the box office success of upcoming movies by analyzing sentiment from social media platforms like Twitter. By scraping tweets related to the movies, we can derive sentiment scores using natural language processing techniques. These sentiment scores will then be used as features in a time series forecasting model built with Darts to predict future box office revenues. This project will not only explore the correlation between social media sentiment and movie performance but also provide insights into how public perception can influence financial outcomes in the film industry.

**Python libs**: Darts, Tweepy, NLTK, Pandas, NumPy, Matplotlib, Scikit-learn
