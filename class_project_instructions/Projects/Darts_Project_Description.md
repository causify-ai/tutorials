### Project 1: Time Series Forecasting of Retail Sales
- **Difficulty:** 1
- **Tech Description:** Darts will be used for its intuitive API to handle time series forecasting tasks, allowing for easy model selection and evaluation.
- **Project Idea:** The goal of this project is to forecast future retail sales for a local store using historical sales data. Students will collect sales data from Kaggle's "Store Sales - Time Series Forecasting" dataset and apply various forecasting models provided by Darts, such as ARIMA and Exponential Smoothing. Students will evaluate the models based on RMSE and visualize the results using Matplotlib. The final deliverable will be a report detailing the forecasting accuracy and recommendations for inventory management.
- **Python libs:** Darts, Pandas, Matplotlib, NumPy, Scikit-learn
- **Is it Free?** Yes, the Darts library and the dataset from Kaggle are freely available.
- **Relevant tool (Darts) related Resource Links:** 
  - [Darts Documentation](https://github.com/unit8co/darts)
  - [Kaggle Store Sales Dataset](https://www.kaggle.com/c/store-sales-time-series-forecasting/data)

### Project 2: Anomaly Detection in Energy Consumption
- **Difficulty:** 2
- **Tech Description:** Darts will be utilized to implement and compare different anomaly detection models on energy consumption time series data.
- **Project Idea:** This project aims to identify anomalies in energy consumption data from the UCI Machine Learning Repository's "Individual household electric power consumption" dataset. Using Darts, students will apply models like Seasonal Decomposition and Prophet to detect outliers in the data. They will preprocess the data for seasonal trends and visualize the identified anomalies. The project will culminate in a presentation of findings, including insights on energy usage patterns and potential causes of anomalies.
- **Python libs:** Darts, Pandas, Matplotlib, NumPy, Statsmodels
- **Is it Free?** Yes, both the Darts library and the dataset from the UCI repository are freely accessible.
- **Relevant tool (Darts) related Resource Links:** 
  - [Darts Documentation](https://github.com/unit8co/darts)
  - [UCI Individual Household Electric Power Consumption Dataset](https://archive.ics.uci.edu/ml/datasets/individual+household+electric+power+consumption)

### Project 3: Multi-Model Ensemble for Stock Price Prediction
- **Difficulty:** 3
- **Tech Description:** Darts will be employed to create an ensemble of multiple forecasting models to improve stock price prediction accuracy.
- **Project Idea:** The objective of this project is to predict stock prices using historical data from Yahoo Finance. Students will gather data for a selected stock and implement an ensemble approach using Darts to combine predictions from different models, such as ARIMA, Prophet, and LSTM. They will evaluate the ensemble's performance against individual models using metrics like MAE and MAPE. The project will involve extensive experimentation with hyperparameters and model selection to optimize prediction accuracy, culminating in a comprehensive analysis and visualizations of the results.
- **Python libs:** Darts, Yahoo Finance, Pandas, Matplotlib, NumPy
- **Is it Free?** Yes, the Darts library and Yahoo Finance data are freely available.
- **Relevant tool (Darts) related Resource Links:** 
  - [Darts Documentation](https://github.com/unit8co/darts)
  - [Yahoo Finance API](https://pypi.org/project/yfinance/)
