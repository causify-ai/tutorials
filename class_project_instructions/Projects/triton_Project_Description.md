### Project Brief: Real-Time Bitcoin Data Ingestion with Triton

- **Title**: Real-Time Bitcoin Data Ingestion using Triton
- **Difficulty**: 2 (Medium, ~10 days to complete)
- **Tech Description**: Triton is a high-performance inference server that can handle real-time data processing and model serving. It supports various frameworks and can be integrated with Python for seamless data ingestion and processing.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, processes it using Triton for model inference (e.g., price prediction), and stores the results in a database for further analysis.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `tritonclient` (for interacting with Triton Inference Server)
  - `SQLAlchemy` (for database interactions)
- **Is it Free?**: Triton is open-source and free to use, but may require cloud resources for deployment.
- **Relevant tool (Triton) related Resource Links**:
  - [NVIDIA Triton Inference Server GitHub](https://github.com/triton-inference-server/server)
  - [Triton Documentation](https://docs.nvidia.com/deeplearning/triton-inference-server/user_guide/index.html)
  - [Triton Client Python Library](https://github.com/triton-inference-server/client)
