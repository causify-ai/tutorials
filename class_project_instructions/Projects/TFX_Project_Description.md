### Project 1: Predicting House Prices with TFX
- **Difficulty:** 1
- **Tech Description:** TFX will be used to create a robust pipeline for preprocessing, training, and validating a model to predict house prices.
- **Project Idea:** The goal of this project is to develop a machine learning model that predicts house prices based on various features such as location, size, and number of bedrooms. Using the Boston Housing dataset, students will build a TFX pipeline that includes data validation, preprocessing, and model training. The pipeline will ensure data quality and reproducibility by implementing components like ExampleGen, SchemaGen, and Trainer. The final model will be evaluated on a test set to assess its performance.
- **Python libs:** TensorFlow, TFX, Pandas, NumPy, Scikit-learn
- **Is it Free?** Yes, TFX and the Boston Housing dataset are both freely available.
- **Relevant tool (TFX) related Resource Links:** 
  - [TFX Documentation](https://www.tensorflow.org/tfx)
  - [Boston Housing Dataset](https://www.kaggle.com/c/boston-housing)

### Project 2: Sentiment Analysis on Movie Reviews
- **Difficulty:** 2
- **Tech Description:** TFX will be utilized to build a pipeline for processing text data and deploying a sentiment analysis model based on pre-trained embeddings.
- **Project Idea:** This project aims to analyze movie reviews to classify them as positive or negative. Using the IMDb Movie Reviews dataset, students will create a TFX pipeline incorporating text preprocessing, feature extraction using pre-trained word embeddings, and model training using a simple neural network architecture. The pipeline will include components for data validation and model evaluation, ensuring the model's performance is robust before deployment.
- **Python libs:** TensorFlow, TFX, NLTK, Pandas, Scikit-learn
- **Is it Free?** Yes, TFX and the IMDb dataset are freely accessible.
- **Relevant tool (TFX) related Resource Links:** 
  - [TFX Documentation](https://www.tensorflow.org/tfx)
  - [IMDb Movie Reviews Dataset](https://ai.stanford.edu/~amaas/data/sentiment/)

### Project 3: Anomaly Detection in Network Traffic
- **Difficulty:** 3
- **Tech Description:** TFX will be employed to create a comprehensive pipeline for anomaly detection in time-series network traffic data.
- **Project Idea:** This project focuses on detecting anomalies in network traffic to identify potential security threats. Using the UNSW-NB15 dataset, students will build a TFX pipeline to preprocess the data, apply feature engineering, and implement an anomaly detection model using an unsupervised learning approach. The pipeline will include components for data validation, model training, and evaluation, ensuring that the model can accurately identify anomalies in unseen data. The final deliverable will be a report detailing model performance and insights into detected anomalies.
- **Python libs:** TensorFlow, TFX, Pandas, NumPy, Scikit-learn
- **Is it Free?** Yes, TFX and the UNSW-NB15 dataset are both freely available.
- **Relevant tool (TFX) related Resource Links:** 
  - [TFX Documentation](https://www.tensorflow.org/tfx)
  - [UNSW-NB15 Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset-2020)
