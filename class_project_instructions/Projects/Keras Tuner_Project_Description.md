### Project Brief: Real-Time Bitcoin Data Ingestion with Keras Tuner

- **Title**: Real-Time Bitcoin Price Prediction using Keras Tuner
- **Difficulty**: 2
- **Tech Description**: Keras Tuner is a library for hyperparameter tuning of Keras models, allowing for efficient optimization of machine learning models. It can be integrated with real-time data ingestion to enhance model performance.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data using an API, preprocesses the data, and utilizes Keras Tuner to optimize a neural network model for predicting future Bitcoin prices.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `keras` (for building neural networks)
  - `keras-tuner` (for hyperparameter tuning)
  - `matplotlib` (for visualization)
- **Is it Free?**: Yes, Keras Tuner and the associated libraries are open-source and free to use.
