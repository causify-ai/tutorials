- **Title**: Anomaly Detection in E-Commerce Transactions Using Koalas

- **Difficulty**: 2

- **Tech Description**: Koalas is utilized to provide a pandas-like API on top of Apache Spark, enabling efficient handling and processing of large-scale e-commerce transaction datasets.

- **Project Idea**: The goal of this project is to identify fraudulent transactions in an e-commerce dataset using anomaly detection techniques. We will utilize a publicly available dataset from the UCI Machine Learning Repository containing transaction records. By leveraging Koalas, we will preprocess the data and apply clustering algorithms, such as DBSCAN, to detect outliers that may indicate fraudulent behavior. The project will also involve visualizing the results to better understand the distribution of transactions and the characteristics of anomalies.

- **Python libs**: koalas, pandas, scikit-learn, matplotlib, seaborn

- **Is it Free?**: Yes
