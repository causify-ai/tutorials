### Project Brief: Real-Time Bitcoin Price Prediction Using Prophet

- **Title**: Real-Time Bitcoin Price Forecasting with Prophet

- **Difficulty**: 2

- **Tech Description**: 
  - Prophet is an open-source forecasting tool developed by Facebook, designed to handle time series data with daily observations that may contain missing values and outliers. It is particularly effective for seasonal trends and can be easily integrated with Python.

- **Project Idea**: 
  - Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes the data, and uses Prophet to forecast future Bitcoin prices. The application will visualize the predictions and provide insights into price trends.

- **Python libs**: 
  - `pandas` (for data manipulation)
  - `requests` (for API calls)
  - `prophet` (for time series forecasting)
  - `matplotlib` (for visualization)
  - `numpy` (for numerical operations)

- **Is it Free?**: Yes, Prophet is free and open-source.
