- **Title**: Sentiment Analysis of Movie Reviews Using NLTK

- **Difficulty**: 2

- **Tech Description**: NLTK is utilized for natural language processing tasks, including tokenization, stopword removal, and sentiment classification of movie reviews.

- **Project Idea**: The goal of this project is to analyze the sentiment of movie reviews collected from the IMDB API. By leveraging NLTK, we will preprocess the text data, extract features, and build a sentiment classification model to categorize reviews as positive, negative, or neutral. The project will involve data collection, cleaning, and applying a machine learning algorithm (e.g., Naive Bayes) to classify the sentiments. Additionally, we will visualize the results to understand the sentiment distribution across different movie genres.

- **Python libs**: NLTK, pandas, scikit-learn, matplotlib, requests
