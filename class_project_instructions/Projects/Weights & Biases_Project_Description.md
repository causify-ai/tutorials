### Project 1: Predicting House Prices with Gradient Boosting
- **Difficulty**: 1
- **Tech Description**: Weights & Biases is used for tracking experiments, visualizing model performance, and managing hyperparameters during the training of a gradient boosting model.
- **Project Idea**: The goal of this project is to predict house prices based on features such as location, size, and amenities using the popular Ames Housing dataset. The student will implement a gradient boosting regression model, utilizing Weights & Biases to log hyperparameters and visualize the training process. The project will focus on feature engineering and model evaluation, allowing students to understand the impact of various features on house pricing.
- **Python libs**: pandas, scikit-learn, numpy, matplotlib, wandb
- **Is it Free?**: Yes, Weights & Biases offers a free tier for individual users, which is sufficient for academic projects.
- **Relevant tool (Weights & Biases) related Resource Links**:

### Project 2: Anomaly Detection in Credit Card Transactions
- **Difficulty**: 2
- **Tech Description**: Weights & Biases is utilized for logging experiments and visualizing the performance of an autoencoder model for detecting anomalies in credit card transactions.
- **Project Idea**: This project aims to identify fraudulent transactions in credit card data using an autoencoder for anomaly detection. The student will work with the Credit Card Fraud Detection dataset from Kaggle. By employing Weights & Biases, they can track model performance metrics and visualize the reconstruction error to identify outliers. The project will also involve evaluating the model's precision and recall to assess its effectiveness in detecting fraud.
- **Python libs**: pandas, scikit-learn, keras, numpy, wandb
- **Is it Free?**: Yes, Weights & Biases provides a free tier that is ideal for academic use.

### Project 3: Sentiment Analysis of Twitter Data
- **Difficulty**: 3
- **Tech Description**: Weights & Biases is employed for managing and visualizing the training process of a pre-trained BERT model fine-tuned for sentiment analysis on Twitter data.
- **Project Idea**: The objective of this project is to analyze public sentiment towards a specific topic on Twitter by fine-tuning a pre-trained BERT model. The student will gather Twitter data using the Twitter API and label the data for positive, negative, or neutral sentiment. Using Weights & Biases, they will track the training of the model, visualize loss and accuracy curves, and perform hyperparameter tuning to optimize performance. This project will enhance understanding of NLP techniques and model evaluation.
- **Python libs**: tweepy, transformers, pandas, numpy, wandb
- **Is it Free?**: Yes, Weights & Biases offers a free tier, and the Twitter API has free access options for developers.
- **Relevant tool (Weights & Biases) related Resource Links**: 
  - [Weights & Biases for NLP](https://docs.wandb.ai/guides/integrations/huggingface)
  - [Twitter API Documentation](https://developer.twitter.com/en/docs/twitter-api)
