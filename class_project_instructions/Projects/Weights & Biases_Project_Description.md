### Project Brief: Real-Time Bitcoin Data Ingestion with Weights & Biases

- **Title**: Real-Time Bitcoin Data Ingestion and Monitoring using Weights & Biases

- **Difficulty**: 2

- **Tech Description**: Weights & Biases (W&B) is a tool for tracking experiments, visualizing metrics, and sharing results. It can be integrated into Python applications to log real-time data and monitor performance.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API (e.g., CoinGecko or Binance) and logs the data using W&B for visualization and analysis. The application will allow users to monitor price fluctuations and trends over time.

- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `weights_and_biases` (for logging and visualization)
  - `matplotlib` (for additional plotting, if needed)

- **Is it Free?**: Yes, W&B offers a free tier with limited features suitable for individual projects.
