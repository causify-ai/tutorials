### Project Brief: Real-Time Bitcoin Data Ingestion with LIME

- **Title**: Real-Time Bitcoin Price Prediction Using LIME for Model Interpretability

- **Difficulty**: 2

- **Tech Description**: LIME (Local Interpretable Model-agnostic Explanations) is a tool that helps interpret machine learning models by approximating them locally with interpretable models. This project will utilize LIME to explain predictions made by a model trained on real-time Bitcoin data.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, preprocesses it, and trains a machine learning model to predict future prices. Use LIME to provide interpretability on the model's predictions, helping users understand the factors influencing Bitcoin price movements.

- **Python libs**:
  - `pandas` for data manipulation
  - `requests` for API calls
  - `scikit-learn` for machine learning
  - `lime` for model interpretability
  - `matplotlib` for data visualization

- **Is it Free?**: Yes, LIME and the other mentioned libraries are open-source and free to use.
