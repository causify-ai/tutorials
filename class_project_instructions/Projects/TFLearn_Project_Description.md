### Project Brief: Real-Time Bitcoin Data Ingestion with TFLearn

- **Title**: Real-Time Bitcoin Price Prediction using TFLearn
- **Difficulty**: 2
- **Tech Description**: TFLearn is a high-level library built on top of TensorFlow that simplifies the process of building and training deep learning models. It provides an easy-to-use interface for defining neural networks and training them with minimal code.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a public API, preprocesses the data, and uses TFLearn to build a predictive model for Bitcoin prices based on historical trends.
- **Python libs**: 
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical computations)
  - `TFLearn` (for building the model)
  - `matplotlib` (for data visualization)
- **Is it Free?**: Yes, TFLearn is open-source and free to use.
