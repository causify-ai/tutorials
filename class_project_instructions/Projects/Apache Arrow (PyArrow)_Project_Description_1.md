### Title
Real-Time Anomaly Detection in Bitcoin Transactions Using Apache Arrow

### Difficulty
3

### Tech Description
Utilize Apache Arrow (PyArrow) for efficient in-memory columnar data processing and real-time data ingestion from multiple Bitcoin transaction sources, enabling high-performance anomaly detection.

### Project Idea
Develop a system that ingests real-time Bitcoin transaction data from various sources (e.g., blockchain APIs, web scraping from cryptocurrency exchanges) and applies anomaly detection algorithms to identify suspicious transactions, leveraging Apache Arrow for fast data processing.

### Python libs
- PyArrow
- Pandas
- Scikit-learn
- Requests (for API calls)
- Beautiful Soup (for web scraping)
- Numpy

### Is it Free?
Yes, Apache Arrow and the mentioned Python libraries are open-source and free to use.
