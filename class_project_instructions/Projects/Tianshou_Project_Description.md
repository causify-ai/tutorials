### Project Brief: Real-Time Bitcoin Data Ingestion Using Tianshou

- **Title**: Real-Time Bitcoin Price Tracker with Tianshou
- **Difficulty**: 2
- **Tech Description**: Tianshou is a reinforcement learning framework that can be adapted for real-time data ingestion and processing tasks. It can efficiently manage data streams and facilitate the integration of real-time data into machine learning models.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from various APIs, processes the data using Tianshou, and stores it for analysis. The application will also visualize price trends and alerts for significant price changes.
- **Python libs**:
  - `tianshou` (for data processing)
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `matplotlib` or `plotly` (for visualization)
- **Is it Free?**: Yes, Tianshou is an open-source library and free to use.
