### Project 1: Image Classification of Plant Diseases
- **Difficulty:** 1
- **Tech Description:** Fastai will be employed to leverage transfer learning for image classification tasks using pre-trained models.
- **Project Idea:** The goal of this project is to develop a model that can classify images of plants and identify common diseases. The dataset will be sourced from the PlantVillage dataset, which contains thousands of images of healthy and diseased crops. Students will preprocess the images, apply data augmentation techniques, and use fastai's built-in functionalities for training a model with transfer learning. The final model will provide predictions on unseen images, assisting farmers in disease identification.
- **Python libs:** fastai, torchvision, pandas, matplotlib, scikit-learn
- **Is it Free?** Yes, the PlantVillage dataset is publicly available for free.
- **Relevant tool (fastai) related Resource Links:** [Fastai Documentation](https://docs.fast.ai/), [PlantVillage Dataset](https://github.com/spMohanty/PlantVillage-Dataset)

### Project 2: Sentiment Analysis of Movie Reviews
- **Difficulty:** 2
- **Tech Description:** Fastai will be utilized to build a sentiment analysis model using pre-trained NLP models for text classification.
- **Project Idea:** This project aims to analyze the sentiment of movie reviews from the IMDb dataset. Students will employ fastai's NLP capabilities to preprocess the text data, tokenize it, and fine-tune a pre-trained language model for sentiment classification. The goal is to predict whether the reviews are positive or negative. Students will evaluate the model's performance using various metrics and visualize the results to understand sentiment trends in movie reviews over time.
- **Python libs:** fastai, pandas, numpy, matplotlib, seaborn
- **Is it Free?** Yes, the IMDb dataset is publicly available for free.
- **Relevant tool (fastai) related Resource Links:** [Fastai NLP Documentation](https://docs.fast.ai/nlp.html), [IMDb Dataset](https://www.imdb.com/interfaces/)

### Project 3: Time Series Forecasting of Energy Consumption
- **Difficulty:** 3
- **Tech Description:** Fastai will be used to leverage its time series capabilities for forecasting energy consumption using historical data.
- **Project Idea:** The objective of this project is to forecast future energy consumption based on historical energy usage data from the UCI Machine Learning Repository’s Individual household electric power consumption dataset. Students will explore various time series forecasting techniques, including the use of fastai’s time series learner to train models. The project will involve data cleaning, feature engineering, and model evaluation, ultimately providing insights into energy consumption trends and aiding in energy management.
- **Python libs:** fastai, pandas, numpy, matplotlib, statsmodels
- **Is it Free?** Yes, the energy consumption dataset is publicly available for free.
- **Relevant tool (fastai) related Resource Links:** [Fastai Time Series Documentation](https://docs.fast.ai/timeseries.html), [UCI Energy Consumption Dataset](https://archive.ics.uci.edu/ml/datasets/individual+household+electric+power+consumption)
