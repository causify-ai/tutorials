### Project Brief: Real-time Bitcoin Data Ingestion using Gensim

- **Title**: Real-time Bitcoin Data Ingestion and Analysis with Gensim

- **Difficulty**: 2

- **Tech Description**: Gensim is a Python library for topic modeling and document similarity analysis. It can be leveraged to process and analyze real-time Bitcoin data streams, particularly for sentiment analysis and trend detection.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data and news articles, processes the text using Gensim for topic modeling, and provides insights on market sentiment and emerging trends.

- **Python libs**: 
  - Gensim
  - Pandas
  - Requests
  - Numpy
  - Matplotlib (for visualization)

- **Is it Free?**: Yes, Gensim is an open-source library and free to use.
