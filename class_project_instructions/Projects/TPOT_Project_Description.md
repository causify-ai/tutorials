### Project Brief: Real-Time Bitcoin Data Ingestion Using TPOT

- **Title**: Automated Bitcoin Price Prediction with TPOT
- **Difficulty**: 2
- **Tech Description**: TPOT is an automated machine learning tool that optimizes machine learning pipelines using genetic programming. It can be used to preprocess and model real-time Bitcoin data for predictive analytics.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, preprocesses it, and uses TPOT to automatically generate the best predictive model for future Bitcoin prices.
- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
  - `TPOT` (for automated machine learning)
  - `matplotlib` (for data visualization)
- **Is it Free?**: Yes, TPOT is open-source and free to use.
