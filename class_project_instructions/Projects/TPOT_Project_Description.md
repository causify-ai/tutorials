### Project 1: Predicting Housing Prices
- **Difficulty**: 1
- **Tech Description**: TPOT will be used for automated machine learning to create a predictive model for housing prices based on various features.
- **Project Idea**: The goal of this project is to predict housing prices using the California Housing dataset from the UCI Machine Learning Repository. Students will leverage TPOT's genetic programming capabilities to automatically optimize and select the best machine learning pipeline. The dataset includes features such as median income, housing age, and location, allowing for a comprehensive analysis of factors influencing home prices. The project will involve data preprocessing, feature selection, and model evaluation using TPOT to find the optimal model configuration.
- **Python libs**: TPOT, pandas, scikit-learn, numpy, matplotlib
- **Is it Free?**: Yes, TPOT and the California Housing dataset are both freely available.
- **Relevant tool (TPOT) related Resource Links**: 
  - [TPOT Documentation](http://epistasislab.github.io/tpot/)
  - [California Housing Dataset](https://www.dcc.fc.up.pt/~ltorgo/Regression/cal_housing.html)

### Project 2: Customer Segmentation for E-Commerce
- **Difficulty**: 2
- **Tech Description**: TPOT will be utilized to automate the selection of clustering algorithms for customer segmentation based on e-commerce transaction data.
- **Project Idea**: This project aims to segment customers of an e-commerce platform using the Online Retail dataset from the UCI Machine Learning Repository. Students will apply TPOT to identify distinct customer groups based on purchasing behavior, such as frequency, recency, and monetary value (RFM). The project will involve preprocessing the transaction data, transforming it into a suitable format for clustering, and using TPOT to optimize the clustering algorithms. The outcome will be actionable insights for targeted marketing strategies.
- **Python libs**: TPOT, pandas, scikit-learn, seaborn, numpy
- **Is it Free?**: Yes, both TPOT and the Online Retail dataset are publicly accessible.
- **Relevant tool (TPOT) related Resource Links**: 
  - [TPOT Documentation](http://epistasislab.github.io/tpot/)
  - [Online Retail Dataset](https://archive.ics.uci.edu/ml/datasets/Online+Retail)

### Project 3: Predicting Credit Card Fraud
- **Difficulty**: 3
- **Tech Description**: TPOT will be employed to automate the feature engineering and selection process for building an effective fraud detection model.
- **Project Idea**: The aim of this project is to develop a robust credit card fraud detection model using the Credit Card Fraud Detection dataset available on Kaggle. Students will utilize TPOT to optimize various classification algorithms and identify the best features for predicting fraudulent transactions. The project will focus on handling class imbalance through techniques like SMOTE and will evaluate the model's performance using metrics such as precision, recall, and F1-score. The ultimate goal is to create a reliable model that minimizes false positives while effectively detecting fraud.
- **Python libs**: TPOT, pandas, scikit-learn, imbalanced-learn, numpy
- **Is it Free?**: Yes, TPOT and the Credit Card Fraud Detection dataset are freely available on Kaggle.
- **Relevant tool (TPOT) related Resource Links**: 
  - [TPOT Documentation](http://epistasislab.github.io/tpot/)
  - [Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/dalpozz/creditcard-fraud)
