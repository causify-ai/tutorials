### Project Brief: Real-Time Bitcoin Data Ingestion with CausalPy

- **Title**: Real-Time Bitcoin Price Tracking and Analysis

- **Difficulty**: 2

- **Tech Description**: CausalPy is a Python library designed for causal inference and data analysis. It can be utilized to analyze the impact of various factors on Bitcoin prices while ingesting real-time data.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, processes it using CausalPy to identify causal relationships, and visualizes the findings. The application will allow users to monitor price changes and understand factors influencing Bitcoin's market behavior.

- **Python libs**:
  - `CausalPy` (for causal analysis)
  - `requests` (for API data ingestion)
  - `pandas` (for data manipulation)
  - `matplotlib` or `seaborn` (for data visualization)

- **Is it Free?**: Yes, CausalPy is an open-source library and is free to use.
