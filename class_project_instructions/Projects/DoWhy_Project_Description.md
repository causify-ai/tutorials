### Project Brief: Real-Time Bitcoin Data Ingestion with DoWhy

- **Title**: Causal Analysis of Real-Time Bitcoin Price Movements Using DoWhy

- **Difficulty**: 2

- **Tech Description**: DoWhy is a Python library for causal inference that allows users to model causal relationships and perform causal reasoning. It can be integrated with real-time data sources to analyze the impact of various factors on Bitcoin prices.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, uses DoWhy to establish causal relationships between Bitcoin prices and external factors (e.g., news sentiment, trading volume), and visualizes the results.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `matplotlib` or `seaborn` (for visualization)
  - `DoWhy` (for causal inference)
  - `numpy` (for numerical operations)

- **Is it Free?**: Yes, DoWhy is an open-source library and free to use.
