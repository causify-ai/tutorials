### Project Brief: Real-Time Bitcoin Data Ingestion with TorchRL

- **Title**: Real-Time Bitcoin Price Prediction using TorchRL
- **Difficulty**: 2
- **Tech Description**: TorchRL is a reinforcement learning library built on PyTorch, designed for developing and training RL models. It can be utilized for real-time data ingestion and decision-making processes.
- **Project Idea**: Create a system that ingests real-time Bitcoin price data, processes it, and uses reinforcement learning to predict future price movements and suggest trading actions.
- **Python libs**: 
  - `torch` (for deep learning)
  - `torchrl` (for reinforcement learning)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical computations)
  - `requests` or `websocket-client` (for real-time data ingestion)
- **Is it Free?**: Yes, TorchRL is open-source and free to use.
- **Relevant tool (TorchRL) related Resource Links**:
  - [TorchRL Documentation](https://pytorch.org/rl/)
  - [TorchRL GitHub Repository](https://github.com/pytorch/rl)
  - [Reinforcement Learning with PyTorch Tutorial](https://pytorch.org/tutorials/intermediate/reinforcement_q_learning.html)
