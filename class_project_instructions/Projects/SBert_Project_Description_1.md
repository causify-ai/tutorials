### Title
Real-Time Sentiment Analysis of Bitcoin News Using SBert

### Difficulty
3

### Tech Description
Utilize SBert (Sentence-BERT) to perform real-time sentiment analysis on news articles related to Bitcoin, enabling traders to gauge market sentiment based on textual data.

### Project Idea
- Scrape live news articles from multiple cryptocurrency news websites.
- Use SBert to encode the text and classify sentiment (positive, negative, neutral).
- Integrate results with real-time Bitcoin price data to analyze correlations between sentiment and price movements.

### Python libs
- `requests` (for web scraping)
- `BeautifulSoup` (for HTML parsing)
- `sentence-transformers` (for SBert)
- `pandas` (for data manipulation)
- `numpy` (for numerical operations)
- `matplotlib` or `seaborn` (for visualization)
- `Flask` or `FastAPI` (for creating a web service)

### Is it Free?
Yes, all mentioned libraries and tools are open-source and free to use.
