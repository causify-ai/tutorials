### Project 1: Understanding Factors Influencing Student Performance
- **Difficulty**: 1
- **Tech Description**: bnlearn is used to create and analyze Bayesian networks that model the relationships between factors affecting student performance.
- **Project Idea**: The goal of this project is to identify key factors that influence student academic performance using a Bayesian network. Students will analyze a publicly available dataset, such as the “Student Performance Data Set” from UCI Machine Learning Repository, which includes attributes like study time, parental education, and attendance. By constructing a Bayesian network, students will visualize dependencies and perform inference to predict student outcomes based on various inputs. The project will also involve sensitivity analysis to see how changes in certain factors impact performance.
- **Python libs**: bnlearn, pandas, numpy, matplotlib, seaborn
- **Is it Free?**: Yes, the bnlearn library and the dataset are freely available.
- **Relevant tool(bnlearn) related Resource Links**: 
  - [bnlearn GitHub Repository](https://github.com/pgmpy/bnlearn)
  - [Student Performance Data Set - UCI ML Repository](https://archive.ics.uci.edu/ml/datasets/Student+Performance)

### Project 2: Analyzing Risk Factors for Heart Disease
- **Difficulty**: 2
- **Tech Description**: bnlearn will be employed to build a Bayesian network that models the relationships between various risk factors and heart disease outcomes.
- **Project Idea**: This project aims to explore and model the risk factors associated with heart disease using the “Heart Disease UCI” dataset. Students will construct a Bayesian network to analyze how different factors such as age, cholesterol levels, and blood pressure correlate with the likelihood of heart disease. The project will involve parameter learning and inference to identify the most significant predictors, as well as visualization of the network structure. Additionally, students will evaluate the model's accuracy using cross-validation techniques.
- **Python libs**: bnlearn, pandas, numpy, scikit-learn, matplotlib
- **Is it Free?**: Yes, both the bnlearn library and the dataset are publicly accessible at no cost.
- **Relevant tool(bnlearn) related Resource Links**: 
  - [bnlearn Documentation](https://pgmpy.org/)
  - [Heart Disease UCI Dataset](https://archive.ics.uci.edu/ml/datasets/heart+Disease)

### Project 3: Predicting Customer Churn in Telecommunications
- **Difficulty**: 3
- **Tech Description**: bnlearn will be utilized to develop a complex Bayesian network for predicting customer churn based on service usage and customer demographics.
- **Project Idea**: This advanced project focuses on predicting customer churn in the telecommunications sector using a dataset like the “Telco Customer Churn” dataset from Kaggle. Students will construct a Bayesian network to model the relationships among various factors, such as service usage, payment methods, and customer demographics. The project will include advanced techniques for structure learning, parameter estimation, and predictive analysis. Students will also explore the impact of different customer segments on churn rates and provide actionable insights for retention strategies.
- **Python libs**: bnlearn, pandas, numpy, matplotlib, scikit-learn
- **Is it Free?**: Yes, the bnlearn library and the dataset from Kaggle are freely available upon account registration.
- **Relevant tool(bnlearn) related Resource Links**: 
  - [bnlearn Documentation](https://pgmpy.org/)
  - [Telco Customer Churn Dataset - Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
