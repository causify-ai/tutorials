### Project Brief: Real-Time Bitcoin Data Ingestion Using bnlearn

- **Title**: Real-Time Bitcoin Price Prediction with Bayesian Networks

- **Difficulty**: 2

- **Tech Description**: 
  - bnlearn is a Python library for learning the structure and parameters of Bayesian networks from data. It can be used to model the probabilistic relationships between various factors influencing Bitcoin prices.

- **Project Idea**: 
  - Develop a system that ingests real-time Bitcoin price data and other relevant features (e.g., trading volume, social media sentiment) to build a Bayesian network model. The model will predict future Bitcoin prices based on the learned relationships.

- **Python libs**: 
  - `bnlearn`: for Bayesian network modeling
  - `pandas`: for data manipulation
  - `numpy`: for numerical operations
  - `requests`: for API calls to fetch real-time Bitcoin data
  - `matplotlib`: for data visualization

- **Is it Free?**: Yes, bnlearn is an open-source library and free to use.
