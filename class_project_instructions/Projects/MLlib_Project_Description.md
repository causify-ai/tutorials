### Project Brief: Real-Time Bitcoin Data Ingestion with MLlib

- **Title**: Real-Time Bitcoin Price Prediction using MLlib
- **Difficulty**: 2
- **Tech Description**: MLlib is Apache Spark's scalable machine learning library that provides various algorithms for classification, regression, clustering, and more. It can handle large datasets and perform distributed computing, making it suitable for real-time data ingestion and processing.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from a cryptocurrency API, processes the data using MLlib for feature extraction, and builds a predictive model to forecast future Bitcoin prices.
- **Python libs**: 
  - `pyspark` (for MLlib)
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical operations)
- **Is it Free?**: Yes, MLlib is part of Apache Spark, which is open-source and free to use.
