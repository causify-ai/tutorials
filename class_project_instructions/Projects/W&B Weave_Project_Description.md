### Project Brief: Real-Time Bitcoin Data Ingestion with W&B Weave

- **Title**: Real-Time Bitcoin Price Tracker using W&B Weave

- **Difficulty**: 2

- **Tech Description**: W&B Weave is a tool for visualizing and analyzing machine learning experiments. It can be leveraged to ingest and visualize real-time Bitcoin data, providing insights into price trends and patterns.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from an API, processes it, and visualizes the data using W&B Weave. The application will update the visualizations in real-time as new data comes in.

- **Python libs**:
  - `requests` (for API calls)
  - `pandas` (for data manipulation)
  - `matplotlib` or `plotly` (for additional visualization if needed)
  - `wandb` (for integrating with W&B Weave)

- **Is it Free?**: Yes, W&B offers a free tier for individual users.
