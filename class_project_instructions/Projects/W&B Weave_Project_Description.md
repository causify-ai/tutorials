### Project 1: Predicting House Prices with Regression Analysis
- **Difficulty**: 1
- **Tech Description**: W&B Weave is utilized for visualizing and tracking the regression analysis process, including feature importance and model performance metrics.
- **Project Idea**: The goal of this project is to predict house prices in a specific region using a regression model. The student will utilize the Boston Housing dataset, performing exploratory data analysis (EDA) and feature engineering to improve model accuracy. W&B Weave will be employed to visualize the regression results, compare different models, and track performance metrics such as RMSE and R² in an interactive dashboard. This will help in understanding the impact of various features on house prices.
- **Python libs**: pandas, scikit-learn, seaborn, matplotlib, wandb
- **Is it Free?**: Yes, W&B offers a free tier for individual users and educational purposes.
- **Relevant tool (W&B Weave) related Resource Links**: [W&B Weave Documentation](https://docs.wandb.ai/guides/weave), [W&B Regression Guide](https://docs.wandb.ai/guides/track/regression)

### Project 2: Anomaly Detection in Network Traffic
- **Difficulty**: 2
- **Tech Description**: W&B Weave is used to visualize the results of anomaly detection algorithms on network traffic data, providing insights into traffic patterns and anomalies.
- **Project Idea**: This project focuses on detecting anomalies in network traffic data using unsupervised learning techniques. The student will utilize the UNSW-NB15 dataset, which contains a variety of network traffic types. After preprocessing the data, they will apply clustering algorithms such as DBSCAN or Isolation Forest. W&B Weave will be leveraged to visualize the clusters formed, highlight anomalies, and track the performance of the model through metrics like precision and recall. This project aims to provide a comprehensive analysis of network security threats.
- **Python libs**: pandas, scikit-learn, numpy, matplotlib, wandb
- **Is it Free?**: Yes, W&B provides a free version that is accessible for educational projects and individual use.
- **Relevant tool (W&B Weave) related Resource Links**: [W&B Weave Overview](https://docs.wandb.ai/guides/weave), [W&B Anomaly Detection](https://docs.wandb.ai/guides/track/anomaly)

### Project 3: Sentiment Analysis on Twitter Data
- **Difficulty**: 3
- **Tech Description**: W&B Weave is used for visualizing the sentiment analysis results and model performance metrics over time, allowing for dynamic exploration of sentiment trends.
- **Project Idea**: The objective of this project is to perform sentiment analysis on tweets related to a specific topic, such as a recent event or product launch. The student will use the Twitter API to collect tweets and leverage a pre-trained transformer model (like BERT) for sentiment classification. W&B Weave will be utilized to track the sentiment trends over time and visualize the distribution of sentiments using interactive plots. The project aims to provide insights into public opinion and sentiment dynamics, enhancing understanding of social media trends.
- **Python libs**: tweepy, transformers, pandas, matplotlib, wandb
- **Is it Free?**: Yes, W&B offers free access for educational use, and the Twitter API has free access tiers for developers.
- **Relevant tool (W&B Weave) related Resource Links**: [W&B Weave for NLP](https://docs.wandb.ai/guides/weave/nlp), [W&B Twitter Analysis](https://docs.wandb.ai/guides/track/twitter)
