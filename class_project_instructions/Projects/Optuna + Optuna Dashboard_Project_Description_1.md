### Project Brief: Real-Time Bitcoin Price Prediction with Optuna and Optuna Dashboard

- **Title**: Hyperparameter Optimization for Bitcoin Price Forecasting
- **Difficulty**: 3
- **Tech Description**: Utilize Optuna for hyperparameter optimization in a machine learning model that predicts Bitcoin prices based on real-time data ingestion. The Optuna Dashboard will visualize the optimization process and results.
- **Project Idea**: Build a predictive model that ingests real-time Bitcoin price data from multiple cryptocurrency exchanges, optimizes hyperparameters using Optuna, and forecasts future prices. The model will incorporate features such as trading volume, market sentiment from social media, and historical price trends.
- **Python libs**: 
  - `optuna` (for hyperparameter optimization)
  - `pandas` (for data manipulation)
  - `numpy` (for numerical computations)
  - `requests` (for API calls)
  - `matplotlib` (for visualization)
  - `scikit-learn` (for machine learning algorithms)
  - `ccxt` (for cryptocurrency exchange data)
- **Is it Free?**: Yes, all mentioned libraries are open-source and free to use.

  - [Optuna GitHub Repository](https://github.com/optuna/optuna)
