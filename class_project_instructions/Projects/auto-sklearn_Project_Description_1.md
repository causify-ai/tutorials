### Title
Real-Time Anomaly Detection in Bitcoin Transactions Using auto-sklearn

### Difficulty
3

### Tech Description
Utilize auto-sklearn for automated machine learning to detect anomalies in real-time Bitcoin transaction data, leveraging advanced feature selection and model optimization capabilities.

### Project Idea
Develop a system that ingests real-time Bitcoin transaction data from multiple sources (e.g., blockchain APIs, transaction feeds), preprocesses the data, and applies auto-sklearn to identify unusual transaction patterns indicative of fraud or market manipulation.

### Python libs
- auto-sklearn
- pandas
- numpy
- requests (for data ingestion)
- scikit-learn
- matplotlib (for visualization)
- Flask or FastAPI (for real-time API)

### Is it Free?
Yes, auto-sklearn is an open-source library and can be used for free.
