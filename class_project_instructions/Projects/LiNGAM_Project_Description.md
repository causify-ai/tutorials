### Project Brief: Real-Time Bitcoin Data Ingestion Using LiNGAM

- **Title**: Real-Time Bitcoin Price Prediction with LiNGAM
- **Difficulty**: 2
- **Tech Description**: LiNGAM (Linear Non-Gaussian Acyclic Model) is a causal inference method that can be used to model the relationships between variables. In this project, it will be applied to analyze and predict Bitcoin price movements based on real-time data ingestion.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin price data from various APIs, processes the data using LiNGAM to identify causal relationships, and predicts future price trends.
- **Python libs**:
  - `pandas` for data manipulation
  - `numpy` for numerical operations
  - `requests` for API calls
  - `lingam` for causal inference modeling
  - `matplotlib` for data visualization
- **Is it Free?**: Yes, all mentioned libraries are open-source and free to use.
- **Relevant tool (LiNGAM) related Resource Links**:
  - [LiNGAM GitHub Repository](https://github.com/py-causal/lingam)
  - [LiNGAM Documentation](https://py-causal.github.io/lingam/)
  - [Research Paper on LiNGAM](https://www.jmlr.org/papers/volume7/shimizu06a/shimizu06a.pdf)
