### Title
Real-Time Bitcoin Price Prediction using Apache TVM

### Difficulty
3

### Tech Description
Apache TVM is an open-source machine learning compiler stack that enables efficient deployment of deep learning models on various hardware platforms. It optimizes models for performance and supports multiple backends.

### Project Idea
Develop a real-time Bitcoin price prediction system that ingests live market data from various cryptocurrency exchanges. Use Apache TVM to optimize a deep learning model for predicting price trends based on historical data and real-time sentiment analysis from social media.

### Python libs
- `tvm`
- `numpy`
- `pandas`
- `requests`
- `tensorflow` or `pytorch` (for model development)
- `scikit-learn` (for data preprocessing)
- `tweepy` (for Twitter API access)

### Is it Free?
Yes, Apache TVM is free and open-source.
