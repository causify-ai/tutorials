### Project Brief: Real-Time Bitcoin Data Ingestion with spaCy

- **Title**: Real-Time Bitcoin Sentiment Analysis using spaCy
- **Difficulty**: 2
- **Tech Description**: spaCy is an open-source library for advanced natural language processing in Python. It can be utilized to analyze and extract insights from real-time Bitcoin-related news and social media data.
- **Project Idea**: Develop a Python application that ingests real-time Bitcoin data from news articles and social media posts, processes the text using spaCy, and performs sentiment analysis to gauge market sentiment.
- **Python libs**:
  - spaCy
  - requests (for API calls)
  - pandas (for data manipulation)
  - matplotlib or seaborn (for visualization)
  - nltk or textblob (for sentiment analysis)
- **Is it Free?**: Yes, spaCy is free and open-source.
