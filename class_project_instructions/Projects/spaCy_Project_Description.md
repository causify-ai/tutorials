### Project 1: Sentiment Analysis of Movie Reviews
- **Difficulty:** 1
- **Tech Description:** spaCy will be used for natural language processing tasks, including tokenization and named entity recognition, to analyze movie reviews.
- **Project Idea:** The goal of this project is to perform sentiment analysis on a dataset of movie reviews to classify them as positive, negative, or neutral. Students will use the IMDb dataset, which contains thousands of user-generated reviews. By leveraging spaCy's pre-trained models for text classification and sentiment scoring, students will preprocess the text data, extract features, and build a simple classification model using logistic regression. The final output will include visualizations of sentiment trends over time.
- **Python libs:** spaCy, pandas, scikit-learn, matplotlib, seaborn
- **Is it Free?** Yes, the IMDb dataset is publicly available and spaCy is an open-source library.
- **Relevant tool (spaCy) related Resource Links:**
  - [spaCy Documentation](https://spacy.io/usage)
  - [IMDb Dataset on Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

### Project 2: Topic Modeling of News Articles
- **Difficulty:** 2
- **Tech Description:** spaCy will be used for preprocessing text data and extracting noun phrases from news articles to facilitate topic modeling.
- **Project Idea:** This project aims to identify and visualize the main topics covered in a collection of news articles using the GNews API, which provides access to current news articles. Students will utilize spaCy to preprocess the text, extract key phrases, and then apply Latent Dirichlet Allocation (LDA) for topic modeling. The results will be presented through interactive visualizations that highlight the most prominent topics and their evolution over time.
- **Python libs:** spaCy, pandas, gensim, pyLDAvis, matplotlib
- **Is it Free?** Yes, GNews API offers a free tier for accessing news articles, and spaCy is open-source.
- **Relevant tool (spaCy) related Resource Links:**
  - [spaCy Topic Modeling Tutorial](https://towardsdatascience.com/topic-modeling-with-spacy-and-gensim-8a7b4d9c4a3d)
  - [GNews API Documentation](https://gnews.io/docs/)

### Project 3: Named Entity Recognition for Scientific Papers
- **Difficulty:** 3
- **Tech Description:** spaCy will be utilized for advanced named entity recognition to extract relevant entities from scientific papers.
- **Project Idea:** The objective of this project is to develop a named entity recognition (NER) system to analyze a dataset of scientific papers from the arXiv repository. Students will use spaCy's custom NER capabilities to identify and classify entities such as authors, institutions, and research topics. The project will involve fine-tuning a pre-trained spaCy model on a small annotated dataset of scientific abstracts. The final deliverable will include a web application that allows users to upload a paper and visualize the extracted entities.
- **Python libs:** spaCy, pandas, Flask, matplotlib, requests
- **Is it Free?** Yes, the arXiv dataset is publicly accessible, and spaCy is an open-source library.
- **Relevant tool (spaCy) related Resource Links:**
  - [spaCy Named Entity Recognition](https://spacy.io/usage/linguistic-features#named-entities)
  - [arXiv Dataset](https://arxiv.org/help/api/index)
