- **Title**: Sentiment Analysis of Real-Time Twitter Data on Climate Change

- **Difficulty**: 2

- **Tech Description**: spaCy will be utilized for natural language processing tasks, including tokenization, part-of-speech tagging, and named entity recognition, to analyze sentiments in tweets related to climate change.

- **Project Idea**: This project aims to perform sentiment analysis on real-time Twitter data concerning climate change discussions. By leveraging the Twitter API, we will collect tweets containing specific hashtags related to climate change. The goal is to classify the sentiments expressed in these tweets as positive, negative, or neutral. We will preprocess the text data using spaCy, extract relevant features, and apply a supervised machine learning model to predict sentiments. The insights gained can help understand public perception and trends in climate change discourse.

- **Python libs**: spaCy, Tweepy, pandas, scikit-learn, matplotlib

- **Is it Free?**: Yes, both spaCy and the Twitter API (with limitations) are free to use.
