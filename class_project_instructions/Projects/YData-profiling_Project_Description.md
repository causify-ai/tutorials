### Project Brief: Real-Time Bitcoin Data Ingestion with YData-Profiling

- **Title**: Real-Time Bitcoin Data Ingestion and Profiling using YData-Profiling

- **Difficulty**: 2

- **Tech Description**: YData-Profiling is a Python library that generates profile reports from a pandas DataFrame, providing insights into the data structure, data types, and statistics. It can be integrated with real-time data ingestion processes to analyze Bitcoin transaction data.

- **Project Idea**: Develop a Python application that ingests real-time Bitcoin transaction data from a public API (e.g., CoinGecko or Binance), processes the data into a pandas DataFrame, and uses YData-Profiling to generate and visualize data profiles for ongoing analysis.

- **Python libs**: 
  - `pandas`
  - `requests`
  - `ydata-profiling`
  - `matplotlib` (for visualizations)

- **Is it Free?**: Yes, YData-Profiling is an open-source library and is free to use.
