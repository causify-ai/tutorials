# Bitcoin API Module

This module demonstrates the use of a Python-based API client to fetch real-time Bitcoin price data, transform it, and push it to Power BI.

## Key Features

- Real-time price ingestion using `requests`
- Calculates 7-point moving average in real-time
- Sends JSON to Power BI streaming dataset via HTTP POST

## Technologies Used

- Python (requests, datetime)
- Power BI Push Dataset API
- CoinGecko/CryptoCompare or mock data

Refer to `bitcoin_api.ipynb` for working examples.
