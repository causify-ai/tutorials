# Real-Time Bitcoin Dashboard Example

This notebook walks through a full example of setting up:

- Real-time data ingestion
- Data cleaning and transformation
- Dashboard creation in Power BI
- Visualization of time series trends and moving averages

The full dashboard includes:
- Price in USD (Card)
- Moving average (Line chart)
- Percentage change (Secondary axis)
- Market cap (Optional card)

See `bitcoin_example.ipynb` for implementation.
