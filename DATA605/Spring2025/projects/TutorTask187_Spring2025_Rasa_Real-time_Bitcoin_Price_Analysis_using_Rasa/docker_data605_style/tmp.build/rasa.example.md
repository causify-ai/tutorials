## 1. Custom Action

### 1.1 `actions.py`

Defining a Rasa action that calls the `BitcoinAPI`:

```python
from rasa_sdk import Action, Tracker
from rasa_sdk.executor import CollectingDispatcher
from rasa_utils import BitcoinAPI

class ActionGetBtcPrice(Action):
    def name(self) -> str:
        return "action_get_btc_price"

    def run(self, dispatcher: CollectingDispatcher, tracker: Tracker, domain: dict) -> list:
        api = BitcoinAPI(vs_currency="usd")
        price = api.get_current_price()
        dispatcher.utter_message(text=f"The current Bitcoin price is ${price:,.2f}")
        return []
```

### 2. Domain Definition
Configuring the intents, actions and responses in the domain.yml:
```yaml
version: "2.0"

intents:
  - ask_btc_price

actions:
  - action_get_btc_price

responses:
  utter_greet:
    - text: "Hey! Ask me for the Bitcoin price."
  utter_fallback:
    - text: "Sorry, I didn't get that. Try asking: 'What's the bitcoin price?'"
```

### 3. NLU Examples
Example utterances for intent classification in data/nlu.yml:

### 4. Conversation Stories
Defining conversation flow in data/stories.yml:
```yaml
version: "2.0"
stories:
- story: ask_bitcoin_price
  steps:
  - intent: ask_btc_price
  - action: action_get_btc_price
```

### 5. Running the Assistant
Starting the action server and the shell in separate terminals:

``` bash
# Terminal 1
rasa run actions

# Terminal 2
rasa shell
```
Then interacting with:
```vbnet

```
