# Project files

- Author: Yuyun Zhen
- Date: May 1, 2025

This project contains the following files:

- `README.md`: This file
- `Redis.API.ipynb`: A notebook demonstrating the native API of Redis and CoinGecko
- `Redis.API.md`: Documentation of the Redis API and the software layer built on top of it
- `Redis.example.ipynb`: A notebook implementing Bitcoin price analytics using Redis
- `Redis.example.md`: A markdown description of the Bitcoin price analytics implementation
- `Redis_utils.py`: Reusable utility functions and wrappers around the Redis and CoinGecko APIs
- `test_redis_utils.py`: Script to test Redis connection and basic functionality
- `collect_bitcoin_data.py`: Script to collect Bitcoin price data at regular intervals
- `analyze_bitcoin_data.py`: Script to analyze Bitcoin price data and generate statistics
- `monitor_bitcoin_price.py`: Real-time monitoring script using Redis Pub/Sub
