# Spring2025_txtai_search

This project is part of the DATA605 course at the University of Maryland, Spring 2025.
The goal of this project is to implement a local AI-powered semantic search engine using `txtai`.  
txtai is an open-source platform that builds AI-powered semantic search engines based on embeddings.

## Project Structure

- `code/` - Contains the Dockerfile and the Jupyter notebook for implementation.
- `outputs/` - Will store generated outputs like indexed data or search results.
- `README.md` - Project description and instructions.

## Objectives
- Set up txtai inside a Docker container.
- Build a small document database.
- Create a search interface to find similar documents.

## Tools
- Python 3
- txtai
- Docker
- Jupyter Notebook
